## 🔧 **Способы решения:**

### 1. **Создать шаблон архива для рубрик в Elementor (рекомендуется)**
В Elementor Pro есть функция **Theme Builder** → **Archive**:

- Зайдите в **Elementor → Theme Builder**.
- Создайте новый шаблон типа **Archive** (или **Posts Archive**).
- Настройте его так же, как ваша страница блога (используйте те же виджеты, структуру).
- В условиях шаблона укажите **«Archive of Taxonomy» → «Category»** (или конкретные рубрики).
- Опубликуйте шаблон.

**Теперь все страницы рубрик будут использовать этот шаблон Elementor.**

---

### 2. **Переназначить страницу блога как архив рубрик (через настройки чтения)**
Иногда помогает:
- Зайдите **Настройки → Чтение**.
- Убедитесь, что на странице «Блог» выбран **статическая страница**, созданная в Elementor.
- Но это работает только для главной страницы блога, не для отдельных рубрик.

---

### 3. **Плагины для кастомных архивов**
- **Custom Post Type UI** + **Toolset** или **Advanced Custom Fields** — для тонкой настройки.
- **Archive Template for Elementor** (если есть в репозитории).
- **“Post Grid” виджеты Elementor Pro** могут использоваться в Theme Builder для создания архива.

---

### 4. **Ручное создание шаблона архива в дочерней теме**
Если готовы редактировать файлы темы:
- Скопируйте `archive.php` из родительской темы в дочернюю.
- Переделайте его, вставив шорткод или шаблон Elementor.
- Или создайте `category.php` (для всех рубрик) или `category-{slug}.php` (для конкретной рубрики).

Пример вставки шорткода Elementor в `category.php`:
```php
<?php echo do_shortcode('[elementor-template id="123"]'); ?>
```
где `123` — ID шаблона Elementor, созданного для архива.

---

### 5. **Использовать плагин “Custom Post Type Archives for Elementor”**
Есть плагины, расширяющие возможности Elementor для архивов.

---

## ✅ **Рекомендация:**
Лучший путь — **Elementor Theme Builder → Archive**.  
Если у вас нет Elementor Pro, можно использовать **виджет “Posts”** на обычной странице, но тогда рубрики должны вести не на стандартный архив, а на эту страницу с фильтром (через параметры запроса).
