# ТЕХНИЧЕСКОЕ ЗАДАНИЕ (КЛЮЧЕВАЯ ЛОГИКА)

## **8. АЛГОРИТМ СМЕНЫ ЦВЕТОВ - КРИТИЧЕСКИ ВАЖНЫЙ РАЗДЕЛ**

### 8.1 Основной принцип
**Ключевой момент:** Показателем для смены цветов служит **ИСКЛЮЧИТЕЛЬНО фактическая суммарная занятая площадь**, а НЕ положение индикатора на шкале или процент заполнения.

### 8.2 Детальный алгоритм по этапам

#### **🔘 ЭТАП 1: Нулевое состояние**
- **Условие:** Не выбрано ни одного растения (`общая площадь = 0 м²`)
- **Шкала заполнения:** Пустая (0% ширины)
- **Цвет шкалы:** Нет (невидима)
- **Фон текста:** Белый (или прозрачный)
- **Текст:** "Введите количество растений"

#### **🟢 ЭТАП 2: Начало заполнения малой системы**
- **Условие:** `0 < площадь ≤ 1.8 м²`
- **Логика:** Добавлено первое растение, началось заполнение малой системы
- **Шкала заполнения:** Сдвигается вправо, процент = `(площадь / 1.8) × 100`
- **Цвет шкалы:** Светло-зеленый (`#81c784`) **МГНОВЕННО** при первой вставке
- **Фон текста:** Светло-зеленый (`#d4edda`) **МГНОВЕННО** при первой вставке
- **Текст:** "Растения помещаются в малую систему."

#### **🟢🟢 ЭТАП 3: Превышение малой системы**
- **Условие:** `1.8 < площадь ≤ 2.8 м²`
- **Критерий смены:** Момент, когда `площадь > 1.8 м²`
- **Шкала заполнения:** Процент = `(площадь / 2.8) × 100` (пересчет относительно новой системы)
- **Цвет шкалы:** Темно-зеленый (`#2e7d32`) **МГНОВЕННО** при пересечении 1.8 м²
- **Фон текста:** Зеленый темнее (`#b8d8be`) **МГНОВЕННО** при пересечении 1.8 м²
- **Текст:** "Количество растений превышает площадь малой системы. Необходима большая система."

#### **🟡 ЭТАП 4: Временный перегруз (агротехническая норма)**
- **Условие:** `2.8 < площадь ≤ 3.08 м²`
- **Критерий смены:** Момент, когда `площадь > 2.8 м²`
- **Шкала заполнения:** Процент = `(площадь / 3.08) × 100`
- **Цвет шкалы:** Желтый (`#fbc02d`) **МГНОВЕННО** при пересечении 2.8 м²
- **Фон текста:** Светло-желтый (`#fff3cd`) **МГНОВЕННО** при пересечении 2.8 м²
- **Текст:** "Количество растений превышает площадь большой системы. Для комфортного состояния на поздних этапах роста рассады её количество нужно сократить."

#### **🟠 ЭТАП 5: Критическое превышение**
- **Условие:** `площадь > 3.08 м²`
- **Критерий смены:** Момент, когда `площадь > 3.08 м²`
- **Шкала заполнения:** 100% (максимум)
- **Цвет шкалы:** Оранжевый (`#f57c00`) **МГНОВЕННО** при пересечении 3.08 м²
- **Фон текста:** Светло-оранжевый (`#ffe5d0`) **МГНОВЕННО** при пересечении 3.08 м²
- **Текст:** "Превышение площади более чем на 10%. Рекомендуется значительно сократить количество растений."

### 8.3 Техническая реализация (псевдокод)

```javascript
function updateVisuals(totalArea) {
    // 1. ОПРЕДЕЛЯЕМ СОСТОЯНИЕ ПО ФАКТИЧЕСКОЙ ПЛОЩАДИ
    let state;
    if (totalArea === 0) state = 'empty';
    else if (totalArea <= 1.8) state = 'small';
    else if (totalArea <= 2.8) state = 'large';
    else if (totalArea <= 3.08) state = 'overload';
    else state = 'critical';
    
    // 2. МГНОВЕННО МЕНЯЕМ ЦВЕТА НЕЗАВИСИМО ОТ ШКАЛЫ
    switch(state) {
        case 'empty':
            fill.style.background = 'transparent';
            container.style.background = 'white';
            break;
        case 'small':
            fill.style.background = '#81c784'; // МГНОВЕННО
            container.style.background = '#d4edda'; // МГНОВЕННО
            break;
        case 'large':
            fill.style.background = '#2e7d32'; // МГНОВЕННО при >1.8
            container.style.background = '#b8d8be'; // МГНОВЕННО при >1.8
            break;
        case 'overload':
            fill.style.background = '#fbc02d'; // МГНОВЕННО при >2.8
            container.style.background = '#fff3cd'; // МГНОВЕННО при >2.8
            break;
        case 'critical':
            fill.style.background = '#f57c00'; // МГНОВЕННО при >3.08
            container.style.background = '#ffe5d0'; // МГНОВЕННО при >3.08
            break;
    }
    
    // 3. РАСЧЕТ ШКАЛЫ (ОТДЕЛЬНО ОТ ЦВЕТОВ)
    let scalePercent;
    switch(state) {
        case 'small': scalePercent = (totalArea / 1.8) * 100; break;
        case 'large': scalePercent = (totalArea / 2.8) * 100; break;
        default: scalePercent = (totalArea / 3.08) * 100; break;
    }
    fill.style.width = Math.min(scalePercent, 100) + '%';
}
```

### 8.4 Контрольные точки для тестирования

**Точка A:** `площадь = 0 → 0.01 м²`
- ✅ Шкала: появляется светло-зеленая полоса
- ✅ Фон: становится светло-зеленым
- ✅ НЕТ задержки

**Точка B:** `площадь = 1.799 → 1.801 м²` (пересечение 1.8)
- ✅ Шкала: мгновенно темно-зеленая
- ✅ Фон: мгновенно зеленый темнее
- ✅ Текст: мгновенно меняется
- ❌ НЕ ждем заполнения шкалы до 100%
