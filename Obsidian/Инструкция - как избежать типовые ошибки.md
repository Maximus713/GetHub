# **🎯 ПРАКТИЧЕСКАЯ ИНСТРУКЦИЯ: КАК НЕ СДЕЛАТЬ ТИПОВЫЕ ОШИБКИ**

## **⚠️ ПЕРЕД НАЧАЛОМ РАБОТЫ ПРОЧТИ ЭТО ЗА 3 МИНУТЫ**

### **1. САМАЯ ГЛАВНАЯ ОШИБКА: "0.30% не входит в optimal"**
**ЧАТ ДУМАЕТ:** "В БД optimal = [0.25, 0.35). 0.35? Наверное опечатка! Исправлю на 0.36" ❌

**ПРАВИЛЬНО:** 
```
optimal: [0.25, 0.35) ← означает: 0.25 ≤ X < 0.35
Проверяем 0.30%: 0.30 ≥ 0.25 = true, 0.30 < 0.35 = true
Результат: 0.30% ∈ optimal ✅ (ВСЁ ВЕРНО!)
```
**ДЕЙСТВИЕ:** Не меняй БД! Математика корректна.

---

### **2. ВТОРАЯ ОШИБКА: AJAX без JSON**
**ЧАТ ДЕЛАЕТ:** 
```javascript
// ❌ НЕПРАВИЛЬНО
fetch(url, {
    body: new FormData(form) // ИЛИ new URLSearchParams()
})
```

**ПРАВИЛЬНО (ТЗ Приложение А):**
```javascript
// ✅ ПРАВИЛЬНО
fetch(ajaxurl, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ // ТОЛЬКО так!
        action: 'npk_concentration_calculate',
        fertilizer_id: 1,
        concentration: 0.3,
        water_volume: 10.0,
        ground_type: 'wet'
    })
})
```

**ПРОВЕРЬ СЕБЯ:** В твоём коде НЕТ `URLSearchParams` и `FormData`?

---

### **3. ТРЕТЬЯ ОШИБКА: State в JavaScript**
**ЧАТ ДЕЛАЕТ:** Пишет в JS логику определения состояния ❌

**ПРАВИЛЬНО (Дополняющее ТЗ B.2):**
- `State` определяется **ТОЛЬКО** в `Calculation_Engine` (PHP)
- JavaScript может только **предварительно определить** для UX
- Источник истины — всегда сервер

**ПРАВИЛЬНЫЙ КОД JS:**
```javascript
// Только для предварительного отображения
function getPreviewState(concentration, profile) {
    // Используем ТЕ ЖЕ диапазоны из БД
    for (let state of profile.states) {
        if (concentration >= state.range[0] && concentration < state.range[1]) {
            return state; // Только для UX!
        }
    }
}
// Финальный state придёт с сервера и заменит этот
```

### **4. ЧЕТВЁРТАЯ ОШИБКА: Data_Adapter считает массу**
**ЧАТ ДЕЛАЕТ:** `Data_Adapter` содержит формулы расчёта ❌

**ПРАВИЛЬНО:**
- `Data_Adapter` = только подготовка данных для UI
- `Calculation_Engine` = только формулы и логика
- Никогда не пересекаются!

1. Все ID из JS → есть в HTML?
2. Все классы из CSS → используются в HTML/JS?
3. Все методы из PHP → вызываются где-то?

### **Шаблон AJAX (копируй целиком):**
```javascript
async function calculateOnServer(data) {
    const controller = new AbortController();
    
    try {
        const response = await fetch(window.ajaxurl, {
            method: 'POST',
            headers: { 'Content-Type': 'application/json' },
            body: JSON.stringify({
                action: 'npk_concentration_calculate',
                nonce: window.NPK_Concentration_Ajax?.nonce || '',
                ...data
            }),
            signal: controller.signal
        });
        
        if (!response.ok) throw new Error('Network error');
        return await response.json();
    } catch (error) {
        // Fallback на локальные расчёты по ТЗ п.7.4
        return { success: false, data: { message: 'Используем локальные данные' } };
    }
}
```

### **Шаблон определения предварительного state (копируй):**
```javascript
function getPreviewState(concentration, profile) {
    const states = profile.states;
    
    for (let i = 0; i < states.length; i++) {
        const state = states[i];
        const isLast = i === states.length - 1;
        
        // Правила из ТЗ п.4.3
        if (isLast) {
            // Последнее состояние: lower ≤ X ≤ upper
            if (concentration >= state.range[0] && concentration <= state.range[1]) {
                return state; // ТОЛЬКО для UX!
            }
        } else {
            // Обычное состояние: lower ≤ X < upper
            if (concentration >= state.range[0] && concentration < state.range[1]) {
                return state; // ТОЛЬКО для UX!
            }
        }
    }
    
    return states[states.length - 1];
}
```
