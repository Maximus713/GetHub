### **ШАГ 1: ПРОВЕРКА НАЧАЛЬНОЙ ЛОГИКИ МОДУЛЯ 2**
**Перед любым кодированием проверить:**
1. Беру первую культуру по алфавиту из БД (например, 'cucumber')
2. Беру первую фазу этой культуры ('seedling')
3. Получаю эталонный NPK: [1.0, 2.0, 1.0]
4. Рассчитываю соответствие с Азофоской [16, 16, 16] по алгоритму Отиаи
5. Результат должен быть ~83% (в зоне orange)

**Если логика не сходится:**
❌ СТОП! Нарушение логики. Запросить решение у Заказчика.
