## 🎯 **СОСТАВИМ СПИСОК ТРЕБОВАНИЙ К ШАБЛОННОЙ СТРАНИЦЕ**

### **1. ОБЯЗАТЕЛЬНЫЕ ТРЕБОВАНИЯ (MUST HAVE)**

**Защита от Elementor:**
- [ ] Полное отключение стилей Elementor на этой странице
- [ ] Сохранение только полезных частей Elementor (иконки, шрифты)
- [ ] Предотвращение любых reset-стилей

**Структура страницы:**
- [ ] Минимальный HTML-скелет (header → калькулятор → footer)
- [ ] Поддержка стандартной темы WordPress
- [ ] Корректное подключение CSS/JS плагина

**Изоляция:**
- [ ] CSS containment для калькулятора
- [ ] Предотвращение утечек стилей наружу
- [ ] Защита от глобальных стилей темы

### **2. ОЧЕНЬ ЖЕЛАТЕЛЬНО (SHOULD HAVE)**

**Производительность:**
- [ ] Ленивая загрузка ненужных скриптов
- [ ] Минимизация HTTP-запросов
- [ ] Кэширование статических ресурсов

**Адаптивность:**
- [ ] Поддержка мобильных устройств
- [ ] Корректное масштабирование
- [ ] Сохранение функциональности на touch-устройствах

**SEO и доступность:**
- [ ] Правильные HTML-теги (h1, main, section)
- [ ] ARIA-атрибуты для доступности
- [ ] Мета-теги для поисковиков

### **3. ДОПОЛНИТЕЛЬНЫЕ ВОЗМОЖНОСТИ (NICE TO HAVE)**

**Кастомизация:**
- [ ] Возможность добавлять прелоадер
- [ ] Настройка цветовой схемы через CSS-переменные
- [ ] Поддержка тёмной темы

**Аналитика:**
- [ ] Интеграция с Google Analytics
- [ ] События для отслеживания использования
- [ ] Логирование ошибок

**Интеграции:**
- [ ] Поддержка кэширующих плагинов (WP Rocket)
- [ ] Совместимость с CDN
- [ ] Поддержка переводов (i18n)

## ❓ **ВОПРОСЫ ДЛЯ УТОЧНЕНИЯ:**

### **1. Контекст использования:**
- Это будет публичная страница для пользователей?
- Или админ-страница для настроек?

### **2. Навигация:**
- Нужна ли кнопка "Назад" или хлебные крошки?
- Должна ли быть ссылка на документацию?

### **3. Брендинг:**
- Нужно ли добавлять логотип?
- Ссылки на другие инструменты?
- Контактную информацию?

### **4. Состояния:**
- Страница загрузки (skeleton screen)?
- Сообщения об ошибках?
- Оффлайн-режим?

### **5. Безопасность:**
- Нужна ли защита от копирования результатов?
- Ограничение частоты запросов?
- Защита от ботов?
