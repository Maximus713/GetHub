# **🎯 ИНСТРУКЦИЯ ПО РАБОТЕ С ПРОМПТОМ АУДИТОРА**

## **📋 КАК ИСПОЛЬЗОВАТЬ ЭТОТ ПРОМПТ В ЧАТЕ (ПОШАГОВО)**

### **🔹 ШАГ 1: НАЧАЛО РАБОТЫ**
```
1. Откройте новый чат с ИИ (ChatGPT/DeepSeek/Claude)
2. Скопируйте ВЕСЬ промпт "Аудитор-Верификатор" (который выше)
3. Вставьте его в первое сообщение чата
4. Добавьте команду активации:
```

**Текст для отправки:**
```
[ВСТАВИТЬ ВЕСЬ ПРОМПТ АУДИТОРА ЗДЕСЬ]

---

**ЗАДАНИЕ:** Активируй роль Аудитора-Верификатора. 
Подтверди, что готов к получению документов для проверки.
```

### **🔹 ШАГ 2: ПЕРЕДАЧА ДОКУМЕНТОВ**
```
5. Дождитесь подтверждения от чата
6. Отправьте ТРИ документа ОТДЕЛЬНЫМИ сообщениями:
```

**Сообщение 2 (Исходное ТЗ):**
```
## ДОКУМЕНТ 1: ИСХОДНОЕ ТЗ
[вставить полный текст исходного ТЗ]
```

**Сообщение 3 (Дополнение):**
```
## ДОКУМЕНТ 2: ДОПОЛНЕНИЕ К ТЗ
[вставить полный текст дополнения]
```

**Сообщение 4 (Новое ТЗ):**
```
## ДОКУМЕНТ 3: НОВОЕ ТЗ (ОБЪЕДИНЁННАЯ ВЕРСИЯ)
[вставить полный текст нового ТЗ]
```

**⚠️ ВАЖНО:** Отправляйте документы именно в такой последовательности и с такими заголовками.

### **🔹 ШАГ 3: ЗАПУСК ПРОВЕРКИ**
```
7. После отправки всех трёх документов дайте команду:
```

**Сообщение 5:**
```
Проведи полный аудит корректности объединения документов по методологии промпта.

ТРЕБУЕМЫЕ ДЕЙСТВИЯ:
1. Создай матрицу соответствий всех требований
2. Проведи попунктный анализ всех трёх документов
3. Выяви все типы ошибок (A-E)
4. Сформируй детальный отчёт по шаблону
5. Укажи индекс корректности и рекомендации

Начинай работу.
```

### **🔹 ШАГ 4: РАБОТА С РЕЗУЛЬТАТАМИ**
```
8. Дождитесь полного отчёта от чата (это займёт 3-10 минут)
9. Проанализируйте отчёт:
   - Посмотрите "Критические ошибки"
   - Проверьте "Индекс корректности"
   - Изучите рекомендации
```

### **🔹 ШАГ 5: УТОЧНЕНИЯ И ДОРАБОТКИ**
```
10. Если нужно уточнить какие-то моменты:
```

**Примеры уточняющих вопросов:**
```
"Детализируй ошибку #3. Покажи точные цитаты из всех документов."

"Почему требование из п.6.6.1 Дополнения отмечено как частично выполнено?"

"Предложи точное исправление для раздела 7.3.2 Нового ТЗ."

"Есть ли противоречия между исправленными пунктами?"
```

## **🔄 ЧТО ДЕЛАТЬ ПОСЛЕ ПОЛУЧЕНИЯ ОТЧЁТА**

### **СЦЕНАРИЙ 1: Высокий индекс корректности (>85%)**
```
1. Исправьте отмеченные мелкие ошибки
2. Примените рекомендации чата
3. Новое ТЗ готово к использованию
```

### **СЦЕНАРИЙ 2: Средний индекс корректности (70-85%)**
```
1. Исправьте ВСЕ серьёзные ошибки
2. Запросите у чата детализацию по спорным моментам
3. Проведите повторный аудит после исправлений
```

### **СЦЕНАРИЙ 3: Низкий индекс корректности (<70%)**
```
1. Приостановите использование Нового ТЗ
2. Систематически исправляйте все ошибки по списку
3. Рассмотрите возможность переделки объединения
```

## **🚨 ТИПИЧНЫЕ ПРОБЛЕМЫ И РЕШЕНИЯ**

### **ПРОБЛЕМА: Чат путает документы**
**РЕШЕНИЕ:**
```
Уточните: "Вернись к документу 2 (Дополнение), пункт 3.1.
Сравни его с пунктом 6.6.1 Нового ТЗ."
```

### **ПРОБЛЕМА: Неполный анализ**
**РЕШЕНИЕ:**
```
Запросите: "Проведи углублённый анализ раздела 7.
Покажи матрицу соответствий только для этого раздела."
```

### **ПРОБЛЕМА: Слишком общие рекомендации**
**РЕШЕНИЕ:**
```
Уточните: "Предложи КОНКРЕТНОЕ исправление для п.6.6.1.
Покажи diff: что удалить, что добавить."
```

## **📊 КАК ИНТЕРПРЕТИРОВАТЬ РЕЗУЛЬТАТЫ**

### **Ключевые метрики для принятия решения:**
```
✅ ИНДЕКС КОРРЕКТНОСТИ > 90% → Документ готов
⚠️ ИНДЕКС 80-90% → Требуются незначительные правки
🔴 ИНДЕКС < 80% → Требуется серьёзная доработка

✅ КРИТИЧЕСКИХ ОШИБОК: 0 → Можно использовать
⚠️ КРИТИЧЕСКИХ ОШИБОК: 1-3 → Исправить перед использованием  
🔴 КРИТИЧЕСКИХ ОШИБОК: >3 → Переделать документ
```

## **🎯 КОРОТКАЯ ИНСТРУКЦИЯ НА ОДНОМ ЭКРАНЕ:**

```
1. КОПИРУЙ промпт в чат + команду активации
2. ЖДИ подтверждения роли
3. ОТПРАВЬ 3 документа отдельно с правильными заголовками
4. ДАЙ команду "Проведи полный аудит"
5. ЖДИ отчёт (3-10 минут)
6. АНАЛИЗИРУЙ индекс корректности и критические ошибки
7. ИСПРАВЛЯЙ по рекомендациям
```

```
0-2 мин: Активация и отправка документов
2-5 мин: Первичный анализ (чат работает)
5-15 мин: Получение полного отчёта
15-20 мин: Анализ результатов и планирование исправлений
```
