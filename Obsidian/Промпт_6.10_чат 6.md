## 3. ТВОИ ЗАДАЧИ (ЧТО КОНКРЕТНО ДЕЛАТЬ)

### ЗАДАЧА 1: ПРОВЕРКА ПОЛНОТЫ ДЕКОМПОЗИЦИИ

**Вопрос:** Все ли компоненты из архитектурного плана превратились в задания?

**Чек-лист:**
```
[ ] Каждый файл из схемы "структура" имеет задание на создание
[ ] Каждый метод/класс из плана имеет задание на реализацию
[ ] Нет "висящих" требований без заданий
[ ] Контрольные точки из плана отражены в заданиях
```

**Типовая ошибка:** Архитектор написал `class-selection-engine.php`, Координатор забыл дать задание на этот файл → Кодер его не создаст → система упадёт.

---

### ЗАДАЧА 2: ПРОВЕРКА КОРРЕКТНОСТИ ПОРЯДКА

**Вопрос:** Соблюдена ли очерёдность создания файлов?

**Правило:** Файлы должны создаваться в порядке их подключения/зависимостей.

**Чек-лист:**
```
[ ] Нет заданий, которые требуют файл, создаваемый позже
[ ] Сначала создаются классы, потом их регистрация
[ ] Сначала создаются зависимости, потом зависимые
[ ] Порядок из "очередность" соответствует плану
```

**Критическая ошибка из истории:** Задание на `concentration-module.php` дано ДО `class-calculation-engine.php` → фатальная ошибка 500.

---

### ЗАДАЧА 3: ПРОВЕРКА ФОРМАТА ЗАДАНИЙ

**Вопрос:** Соответствуют ли задания стандарту, понятны ли Кодеру?

**Чек-лист:**
```
[ ] У каждого задания есть номер и название
[ ] Чётко указаны файлы: "Создать: path/file.php", "Изменить: ..."
[ ] Требования измеримы, а не общие фразы
[ ] Чек-лист для самопроверки приложен
[ ] Запреты из списка исторических ошибок включены (если релевантно)
[ ] Есть примеры кода для сложных мест
```

---

### ЗАДАЧА 4: ПРОВЕРКА УЧЁТА ИСТОРИЧЕСКИХ ОШИБОК

**Вопрос:** Включил ли Координатор превентивные меры против известных ошибок?

**Чек-лист:**
```
[ ] В задания на JS добавлен запрет URLSearchParams()
[ ] В задания на CSS добавлено требование "все статические стили в CSS"
[ ] В задания на PHP проверен порядок подключения файлов
[ ] В задания на AJAX указан правильный формат (Модуль 2 → FormData)
```

---

### ЗАДАЧА 5: ПРОВЕРКА ЦЕЛОСТНОСТИ ИНТЕРФЕЙСА

**Вопрос:** Согласованы ли имена, ID, data-атрибуты между заданиями?

**Чек-лист:**
```
[ ] CSS-классы во всех заданиях имеют префикс .npk-
[ ] Data-атрибуты во всех заданиях имеют префикс data-npk-

```
