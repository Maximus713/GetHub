### **ЭТАП 2: РЕАЛИЗАЦИЯ КЛАССА**
Реализовать класс `NPK_Concentration_Calculation_Engine`:

#### **Обязательные публичные методы:**
```php
/**
 * Основной расчётный метод
 * @param int $fertilizer_id ID удобрения из БД
 * @param float $concentration Целевая концентрация, %
 * @param float $water_volume Объём воды, л
 * @param string $ground_type Тип грунта ('dry', 'medium', 'wet')
 * @return array Результат расчёта
 */
public static function calculate(int $fertilizer_id, float $concentration, float $water_volume, string $ground_type): array

/**
 * Определение состояния концентрации
 * @param float $concentration Концентрация, %
 * @param string $ground_type Тип грунта
 * @return array Данные состояния
 */
public static function get_concentration_state(float $concentration, string $ground_type): array
```

#### **Обязательный protected метод:**
```php
/**
 * Валидация растворимости
 * @param mixed $value Значение растворимости из БД
 * @return float Валидированное значение
 */
protected static function validate_solubility_total($value): float
```

### **ЭТАП 3: РЕАЛИЗАЦИЯ ЛОГИКИ**

#### **3.1 Формула расчёта массы:**
```
масса_г = (концентрация / 100) × объём_воды_л × 1000 × (100 / растворимость_из_бд)
```

#### **3.2 Алгоритм определения состояния:**
- Получить профиль грунта из `NPK_Database::get_concentration_profiles()`
- Для каждого состояния проверять:
  - Последнее состояние: `min ≤ концентрация ≤ max`
  - Остальные состояния: `min ≤ концентрация < max`

#### **3.3 Коррекция ввода:**
- Концентрация: 0.05% — 1.5%
- Объём воды: 0.5 л — `water_volume_max` л (максимум 200 по ТЗ)
- Округление объёма воды: до одного знака после запятой

### **ЭТАП 4: ОБРАБОТКА ОШИБОК**
- Проверять существование `NPK_Database`: `if (!class_exists('NPK_Database'))`
- При отсутствии удобрения или профиля возвращать структуру с предупреждениями
- Всегда возвращать корректную структуру результата
