Система состоит из пяти основных модулей, каждый из которых выполняет чёткую функцию.

1.  **Несущая платформа.** Широкая стальная основа с вертикальной стойкой. Задача — обеспечить устойчивость и задать вертикальную ось для регулировок.
2.  **Регулируемый каркас.** Включает центральную крестовину (узел, перемещающийся по стойке) и набор выдвижных штанг (продольных и поперечных). Это «скелет» системы, определяющий её высоту и занимаемую площадь.
3.  **Световой модуль.** Набор из шести светодиодных прожекторов на подвижных креплениях. Создаёт первичный световой поток.
4.  **Отражающая оболочка.** Съёмный чехол из светоотражающей плёнки, который крепится на каркас. Формирует замкнутый «световой кокон», многократно переотражая свет внутрь рабочего объёма.
5.  **Модуль автоматизации.** Внешнее реле времени (таймер). Не встроен в конструкцию, но является необходимым аксессуаром для автономной работы по заданному графику включения/выключения.

Эти модули работают вместе: платформа и каркас создают пространство, световой модуль его заполняет, а отражающая оболочка удерживает свет, формируя равномерную среду для растений.
