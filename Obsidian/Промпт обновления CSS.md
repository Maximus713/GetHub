## 🛠 **ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ**

### **✅ ОБЯЗАТЕЛЬНО:**
1. **Сохранить ВСЕ оригинальные классы** — не переименовывать
2. **Сохранить порядок медиа-запросов** — если в оригинале 768px потом 480px, так и оставить
3. **Сохранить все состояния** — :hover, :active, :focus
4. **Добавить комментарии к каждому исправлению** — `/* Исправление #1: Чёткий текст кнопок */`
5. **Использовать специфичные селекторы для Elementor:**
   ```css
   /* ВАРИАНТ 1 (рекомендуемый) */
   body .npk-concentration-calculator .npk-ground-button { ... }
   
   /* ВАРИАНТ 2 (если не работает) */
   body .elementor-page .npk-concentration-calculator .npk-ground-button { ... }
   ```

### **🚫 СТРОГИЕ ЗАПРЕТЫ:**
1. **НЕ удалять рабочие стили** — только реструктуризировать
2. **НЕ использовать `all: unset` или `all: initial`** — это ломает Elementor
3. **НЕ создавать новые классы или ID** — работать только с существующими
4. **НЕ менять логику отображения** — display, position, flex-direction только если в ТЗ
5. **НЕ перемешивать исправления** — каждое в своей секции
6. **НЕ добавлять лишние `!important`** — только где Elementor конфликтует

### **🔧 ДЛЯ КАЖДОГО ИСПРАВЛЕНИЯ:**
1. Найти в оригинале соответствующие стили
2. Перенести их в правильную секцию
3. Усилить специфичность
4. Добавить `!important` только если необходимо
5. Прокомментировать: `/* ТЗ пункт X: описание */`

## 🆘 **ЕСЛИ ВОЗНИКНУТ ПРОБЛЕМЫ С ELEMENTOR**
Если после рефакторинга Elementor всё равно перебивает стили:
1. Усилить специфичность селекторов
2. Добавить `!important` для критичных свойств
3. Предложить минимальный JavaScript-фикс ТОЛЬКО для инлайн-стилей:
   ```javascript
   // Только если Elementor добавляет style="..."
   document.querySelectorAll('.npk-ground-button').forEach(btn => {
       btn.style.cssText += 'color: #3c3c3c !important;';
   });
   ```
