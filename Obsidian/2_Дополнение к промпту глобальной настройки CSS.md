# 🎯 **ДОРАБОТКА CSS ДЛЯ NPK КАЛЬКУЛЯТОРА**

## 🏗️ **ЦЕЛЬ**
Улучшить архитектуру и визуальную гармонию CSS калькулятора, сделав его **единым целым**, при этом **максимально сохранив стабильность работы** в Elementor.

## 📏 **ГРАНИЦЫ ИЗМЕНЕНИЙ**

### **✅ ЧТО МОЖНО МЕНЯТЬ (до 70% кода):**
- Вводить **CSS Custom Properties** (макс 12 переменных)
- Реструктурировать **порядок селекторов** для логичности
- Оптимизировать **дублирующиеся свойства**
- Устанавливать **единые пропорции и ритмы**
- Усиливать **специфичность селекторов** против Elementor

### **🚫 ЧТО НЕЛЬЗЯ МЕНЯТЬ:**
- **Имена классов** и структуру HTML
- **Медиа-запросы** (можно оптимизировать, но не удалять)
- **Основные цвета бренда** (#227d51, #f9f5f0, #3c3c3c)
- **Существующие функциональные фиксы** (слайдер, поля ввода, кнопки)

### **⚖️ ПРИОРИТЕТЫ:**
1. **Стабильность работы** (35%) — ничего не ломаем
2. **Защита от Elementor** (35%) — стили держатся при любых условиях  
3. **Визуальная гармония** (30%) — красота как бонус, а не цель

## 🎨 **КОНКРЕТНЫЕ ЗАДАЧИ ГАРМОНИЗАЦИИ**

### **1. ЦВЕТОВАЯ СИСТЕМА** (создать палитру из 6-8 цветов)
```
Базовые:
- primary: #227d51 (зелёный)
- secondary: #f9f5f0 (бежевый фон)
- text: #3c3c3c (тёмный текст)

Акцентные:
- dry: #e6b400 (жёлтый)
- medium: #63b3ed (голубой)  
- wet: #3182ce (синий)
- error: #e53e3e (красный)
- success: #227d51 (зелёный)
```

### **2. ТИПОГРАФИЧЕСКАЯ ШКАЛА** (на основе 1.25)
```
Заголовок: 1.26em
Подзаголовок: 1em
Текст: 1em
Метки: 0.95em
Мелкий текст: 0.85em
```

### **3. ПРОСТРАНСТВЕННЫЙ РИТМ** (база 4px)
```
Отступы: 4px, 8px, 12px, 16px, 20px, 24px
Скругления: 4px, 8px, 12px, 16px
Толщины рамок: 1px, 2px, 3px
```

### **4. ЭЛЕМЕНТНЫЕ ПРОПОРЦИИ**
```
Кнопки грунта: высота = ширина × 0.6
Поля ввода: высота 44px
Блоки результатов: высота зависит от контента
```

## 🛡️ **ЗАЩИТА ОТ ELEMENTOR (критические точки)**

### **УСИЛИТЬ СПЕЦИФИЧНОСТЬ ДЛЯ:**
1. **Кнопки выбора грунта** — Elementor постоянно их ломает
2. **Блоки результатов** — добавляет инлайн-стили высоты
3. **Поля ввода** — меняет отступы и рамки
4. **Слайдер** — вмешивается в позиционирование

### **СТРАТЕГИЯ ЗАЩИТЫ:**
```css
/* УРОВЕНЬ 1: Базовая защита (для всех) */
body .npk-concentration-calculator .element {
  /* свойства */
}

/* УРОВЕНЬ 2: Усиленная (для критичных) */  
body .elementor-widget .npk-concentration-calculator .critical-element {
  /* свойства с !important где Elementor нападает */
}

/* УРОВЕНЬ 3: Ядерная (последнее средство) */
#specific-calculator-id .element {
  /* ID-based защита */
}
```
