### **📌 КОНТЕКСТ И ЦЕЛЬ**
Я создаю систему из 7 взаимосвязанных LLM-агентов для разработки WordPress плагина "NPK Calculators". Каждый агент — узкий специалист. Система построена на принципах:
1. Разделения обязанностей
2. Незаинтересованных контроллеров
3. Раннего обнаружения ошибок
4. Самокорректировки

### **📋 ОБЩИЕ ТРЕБОВАНИЯ КО ВСЕМ ПРОМПТАМ:**

#### **СТРУКТУРА КАЖДОГО ПРОМПТА (обязательные разделы):**
1. **ИДЕНТИФИКАЦИЯ:** Кто ты (одно предложение)
2. **ЕДИНСТВЕННАЯ ЗАДАЧА:** Чем занимаешься (максимум 2 предложения)
3. **ГРАНИЦЫ:** Что НЕ делаешь (четкий список запретов)
4. **КОНТЕКСТ:** Какие документы видишь (точные ссылки на разделы)
5. **ФОРМАТ ВХОДА:** Как с тобой общаются (шаблон)
6. **ФОРМАТ ВЫХОДА:** Как ты отвечаешь (строгий шаблон с маркерами `---НАЧАЛО---/---КОНЕЦ---`)
7. **КРИТЕРИИ КАЧЕСТВА:** Как проверить твою работу
8. **ОБРАБОТКА ОШИБОК:** Что делать, если прислали исправления
9. **ПРИМЕР:** Пример правильного ответа

#### **КРИТИЧЕСКИЕ ПРИНЦИПЫ (проверить для каждого промпта):**
- [ ] **Узкая специализация:** Агент делает ТОЛЬКО свою работу
- [ ] **Непересекающиеся обязанности:** Никакого дублирования с другими агентами
- [ ] **Минимальный контекст:** Только необходимые документы (не все 6!)
- [ ] **Жесткий формат:** Выход всегда структурирован, парсится однозначно
- [ ] **Незаинтересованность контроллеров:** Они НЕ создают контент, только проверяют
- [ ] **Идемпотентность:** При одинаковом входе — одинаковый выход
- [ ] **Обработка ошибок:** Четкий протокол при получении `СТАТУС: ❌`

### **🎭 ТРЕБОВАНИЯ К КОНКРЕТНЫМ РОЛЯМ:**

#### **1. ДЛЯ СОЗДАЮЩИХ АГЕНТОВ (Стратег, Архитектор, Диспетчер, Исполнитель):**
- [ ] Имеют творческую/созидательную функцию
- [ ] Получают ввод от предыдущего агента или контроллера
- [ ] Их вывод проверяется соответствующим контроллером
- [ ] Могут получать обратную связь и исправлять

#### **2. ДЛЯ КОНТРОЛЛИРУЮЩИХ АГЕНТОВ (3 контроллера):**
- [ ] **НЕ создают контент** — это принципиально!
- [ ] Проверяют только по своим документам
- [ ] Имеют четкие чек-листы проверки
- [ ] Формат ответа: `СТАТУС: ✅/❌` + список ошибок + рекомендации
- [ ] Ошибки подтверждаются цитатами из документов
- [ ] Объективны — не заинтересованы в "проталкивании" работы

### **🔀 ТРЕБОВАНИЯ К ВЗАИМОДЕЙСТВИЮ:**


- **Возврат на исправление:** `СТАТУС: ❌`, `ОРИГИНАЛ: [фрагмент]`, `ИСПРАВЛЕНИЕ: [что сделать]`
