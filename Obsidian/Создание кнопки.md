В Elementor есть два основных способа создания кнопок:

---

## **🎯 Способ 1: Виджет "Кнопка" (самый простой)**

1. **Перетащите виджет "Кнопка"** из левой панели.
2. **Настройте во вкладке "Содержимое":**
   - **Текст кнопки:** "Узнать подробнее", "Заказать" и т.д.
   - **Ссылка:** URL или выбор страницы
   - **Иконка:** можно добажать справа/слева от текста

3. **Стиль во вкладке "Стиль":**
   - **Типография:** шрифт, размер, цвет текста
   - **Цвет фона:** основной и при наведении
   - **Граница:** толщина, цвет, скругление углов
   - **Тень:** при желании
   - **Анимация при наведении**

---

## **🎯 Способ 2: Создать свою кнопку из контейнера (гибкий вариант)**

1. **Создайте контейнер** с направлением Row.
2. **Добавьте в него:**
   - **Виджет "Иконка"** (опционально, слева)
   - **Виджет "Заголовок"** или "Текст" (надпись на кнопке)
   - **Виджет "Иконка"** (опционально, справа)
3. **Настройте контейнер как кнопку:**
   - **Стиль → Фон:** цвет, градиент
   - **Стиль → Граница:** скругление (Border Radius) 5-10px
   - **Стиль → Отступы:** Padding 15px 30px
   - **Дополнительно → Курсор:** Pointer (рука при наведении)

4. **Добавьте ссылку:** во вкладке "Расширенные" → "Атрибуты" → `href="ваша-ссылка"`

---
Отлично! Вот как добавить эти эффекты к вашей кастомной кнопке:

---

## **🎯 1. Изменение цвета при наведении и нажатии**

### **Для фона кнопки:**
1. **Кликните на ваш контейнер-кнопку**.
2. Перейдите во вкладку **"Стиль"**.
3. Найдите раздел **"Фон"** (Background).
4. **Нажмите на вкладку "При наведении"** (Hover):
   - Выберите другой цвет фона
   - Или добавьте затемнение: установите прозрачность (Opacity) 0.8

5. **Для нажатия (активного состояния)** нужно добавить CSS:
   - Перейдите во вкладку **"Дополнительно"** → **"Custom CSS"**
   - Добавьте:
   ```css
   /* При нажатии (активное состояние) */
   selector:active {
       background-color: #155724 !important;
       transform: scale(0.98);
   }
   ```

### **Для текста внутри кнопки:**
1. **Кликните на виджет "Текст"** внутри контейнера.
2. **"Стиль"** → **"Цвет текста"**.
3. **Нажмите на иконку карандаша** → выберите **"При наведении"**.
4. Установите цвет текста при наведении.

---

## **🎯 2. Добавление ссылки (3 способа)**

### **Способ 1: Через настройки контейнера (рекомендуется)**
1. Кликните на **контейнер-кнопку**.
2. **"Дополнительно"** → **"Атрибуты"**.
3. Добавьте атрибут:
   - **Название:** `onclick`
   - **Значение:** `window.location.href='https://ваш-сайт.ru'`

### **Способ 2: С помощью HTML**
1. Кликните на **контейнер-кнопку**.
2. **"Дополнительно"** → **"Custom CSS"**.
3. Добавьте:
   ```css
   selector {
       cursor: pointer;
   }
   selector:hover {
       /* ваши hover-стили */
   }
   ```
4. **В атрибуты контейнера добавьте:**
   - `onclick="window.open('https://ваш-сайт.ru', '_blank')"` (в новой вкладке)
   - `onclick="location.href='https://ваш-сайт.ru'"` (в этой же вкладке)

### **Способ 3: Обернуть в ссылку (самый правильный)**
1. **Выделите весь контейнер-кнопку**.
2. **Правой кнопкой** → **"Обернуть в"** (Wrap) → **"Ссылка"**.
   *Если такой опции нет:*
3. **"Дополнительно"** → **"Custom HTML"** перед контейнером:
   ```html
   <a href="https://ваш-сайт.ru" style="text-decoration: none; display: inline-block;">
   ```
4. После контейнера добавьте `</a>`

## **🛠️ Полный набор настроек для кнопки-контейнера:**

### **Вкладка "Стиль" контейнера:**
```
Фон:
- Обычный: #28a745
- При наведении: #218838 (темнее на 15%)

Граница:
- Скругление: 5px

Курсор (в Advanced): Pointer
```

### **Вкладка "Дополнительно" контейнера:**
```
Custom CSS:
selector {
    cursor: pointer;
    transition: all 0.3s ease;
}
selector:hover {
    background-color: #218838 !important;
    transform: translateY(-2px);
    box-shadow: 0 5px 15px rgba(0,0,0,0.1);
}
selector:active {
    background-color: #155724 !important;
    transform: translateY(0);
}
```

**Атрибуты:**
```
onclick: window.location.href='https://ваш-сайт.ru'
```

## **💡 Готовый код для копирования:**

### **Для фона при наведении:**
```css
/* В Custom CSS контейнера */
selector:hover {
    background-color: #218838 !important;
}

selector:active {
    background-color: #155724 !important;
    transform: scale(0.98);
}
```

### **Для ссылки через JavaScript:**
```html
<!-- В атрибутах контейнера -->
onclick="window.open('https://ваш-сайт.ru', '_blank')"
```

---

## **⚠️ Важные моменты:**

1. **Курсор должен стать "рукой":**
   - В настройках контейнера: **"Дополнительно"** → **"Курсор"** → `Pointer`

2. **Плавные переходы:**
   ```css
   selector {
       transition: background-color 0.3s, transform 0.2s;
   }
   ```

3. **Доступность:**
   - Добавьте атрибут `role="button"` в контейнер
   - Или `tabindex="0"` для фокусировки с клавиатуры

## **🎨 Дополнительные эффекты:**

### **Эффект "нажатия":**
```css
selector:active {
    transform: translateY(2px);
    box-shadow: 0 2px 5px rgba(0,0,0,0.2);
}
```

### **Эффект "пульсации" при наведении:**
```css
selector:hover {
    animation: pulse 0.3s;
}
@keyframes pulse {
    0% { transform: scale(1); }
    50% { transform: scale(1.05); }
    100% { transform: scale(1); }
}
```

## **📱 Для текста внутри кнопки:**

Не забудьте настроить и текст:
1. Кликните на **текстовый виджет** внутри.
2. **"Стиль"** → **"Типографика"**.
3. **Цвет текста** → **"При наведении"**: белый или контрастный.

---

**Самый простой путь:** Используйте **Способ 3** (обернуть в ссылку) — это семантически правильно и работает на всех устройствах. Если нет опции "Обернуть в", добавьте onclick в атрибуты контейнера.
