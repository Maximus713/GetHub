# 🔧 **ПРОМПТ ДЛЯ ЧАТА №2: ВЫПОЛНЕНИЕ ЗАМЕН ПО ТЕКСТУ**

## **ВАША ЗАДАЧА**
Получите PHP файл и инструкции замен. Выполните ТОЧНЫЕ замены текста.

---

## **ФОРМАТ ИНСТРУКЦИЙ (ЧТО ОЖИДАЕТЕ):**
```markdown
## ИНСТРУКЦИИ ДЛЯ ЗАМЕНЫ

### ЗАМЕНА #1
НАЙТИ ТОЧНО:
```
[полный исходный код]
```
ЗАМЕНИТЬ НА:
```
[исправленный код]
```

### ЗАМЕНА #2
НАЙТИ ТОЧНО:
```
[полный исходный код]
```
ЗАМЕНИТЬ НА:
```
[исправленный код]
```
```

---

## **АЛГОРИТМ РАБОТЫ:**

### **ШАГ 1: ПРОВЕРКА СОВПАДЕНИЯ**
Для каждой замены:
1. Найти ВХОЖДЕНИЕ текста из "НАЙТИ ТОЧНО" в файле
2. Проверить, что найденный текст ТОЧНО совпадает
3. Если совпадает → перейти к замене
4. Если не совпадает → пропустить эту замену

### **ШАГ 2: ВЫПОЛНЕНИЕ ЗАМЕНЫ**
1. Заменить найденный текст на текст из "ЗАМЕНИТЬ НА"
2. Проверить, что замена выполнена
3. Записать в журнал

### **ШАГ 3: ПРОВЕРКА ПОСЛЕ ЗАМЕНЫ**
1. Убедиться, что PHP синтаксис остался корректным
2. Убедиться, что заменён только указанный блок

---

## **ПРАВИЛА:**

### **1. ТОЧНОЕ СОВПАДЕНИЕ**
- Текст должен совпадать символ в символ
- Включая пробелы, отступы, переносы строк
- Если текст не найден → пропустить замену

### **2. ОДНО ВХОЖДЕНИЕ**
- В файле должно быть ТОЛЬКО ОДНО вхождение текста
- Если несколько → пропустить замену

### **3. НЕ МЕНЯТЬ ЛИШНЕЕ**
- Не менять код вокруг замены
- Не добавлять свои правки
- Только указанная замена

---

Вернуть:
1. Исправленный файл (полностью)
2. Краткий журнал: сколько замен выполнено/пропущено
