## 🛠️ **Практические рекомендации по выбору**

### **Для начинающих: стартовый набор**
1. **`sai_xl_canny_256lora`** — для контроля контуров
2. **`diffusers_xl_depth_full`** — для контроля композиции
3. **`sdxl_openpose_full`** — для контроля поз

### **Сила влияния (strength) для SDXL ControlNet:**
- **Canny/Lineart:** 0.4-0.7 (слишком высокое значение даёт "зажатый" результат)
- **Depth:** 0.5-0.8 (можно сильнее, так как depth менее агрессивна)
- **OpenPose:** 0.6-0.9 (для точного следования позе)
- **Scribble:** 0.7-1.0 (можно максимальное, так как скетч очень абстрактный)

### **Важные технические моменты:**
1. **Совместимость:** Все перечисленные модели работают **только с SDXL checkpoint'ами**
2. **Разрешение:** SDXL ControlNet часто ожидает изображения 1024x1024 или кратные 128
3. **Предобработка:** Используйте предобработчики из `ComfyUI-ControlNet-Aux` с пометкой "SDXL" или "XL"
4. **Память:** SDXL ControlNet потребляет больше VRAM, чем для SD1.5. На 8ГБ можно работать с 1024px, но лучше иметь 12+ ГБ

## 🔗 **Примеры рабочих связок (в ComfyUI)**

**Для портрета с точной позой:**
- Основная модель: `SDXL 1.0 Base`
- ControlNet 1: `sdxl_openpose_full` (strength: 0.8) — для позы
- ControlNet 2: `sai_xl_canny_256lora` (strength: 0.5) — для черт лица

**Для интерьера с сохранением перспективы:**
- Основная модель: `Realistic Vision SDXL`
- ControlNet: `controlnet-zoe-depth-sdxl-1.0` (strength: 0.7) — для глубины

**Для арта по скетчу:**
- Основная модель: `DynaVision XL`
- ControlNet: `sdxl_controlnet_scribble` (strength: 0.9) — для следования наброску

## ⚠️ **Частые проблемы и решения**

1. **"ControlNet не работает, результат игнорирует карту"**
   - Проверьте, что модель ControlNet совместима с SDXL
   - Убедитесь, что к `Apply ControlNet` подключена именно **карта** (image output), а не preview

2. **"Изображение получается слишком контрастным/искажённым"**
   - Снизьте `strength` (особенно для Canny)
   - Попробуйте модель с суффиксом `256lora` — они часто работают мягче

3. **"Не хватает памяти"**
   - Используйте `--medvram` флаг при запуске ComfyUI
   - Генерируйте в разрешении 1024x1024 вместо 1280x1280
   - Используйте только один ControlNet за раз

**Лучший способ найти "свои" модели** — тестировать на конкретных задачах. Скачайте 2-3 варианта для каждого типа (например, разные depth-модели) и сравните результаты на ваших промптах.
