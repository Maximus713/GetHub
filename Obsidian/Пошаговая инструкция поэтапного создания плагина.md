# **📋 ПОШАГОВАЯ ИНСТРУКЦИЯ: КАК СОЗДАВАТЬ МОДУЛЬ 2**

## **🎯 ЦЕЛЕВОЕ СОСТОЯНИЕ**
У вас есть **работающий Модуль 1** (калькулятор концентрации).  
Нужно создать **Модуль 2** (подбор удобрений) без нарушения первого.

---

## **🔄 ВАША СХЕМА РАБОТЫ:**

```
1. ЧАТ 1 (Ты сейчас) → Архитектор и ТЗ-мейкер
   ↓ Создает ТЗ и промпты
   
2. ЧАТ 2 (Новый чат) → Разработчик
   ↓ Получает промпт и ТЗ → создает файлы
   
3. ЧАТ 3 (Еще чат) → Проверщик
   ↓ Проверяет результат
```

---

## **🚀 ШАГ 1: ПОДГОТОВКА (ТЫ СЕЙЧАС)**

### **1.1. Собери ВСЕ документы:**
```
✅ У ВАС УЖЕ ЕСТЬ:
1. Основное ТЗ Модуля 1 (эталон структуры)
2. БД v4.0 (npk-database.php) с методами для модуля 2
3. Эталонная архитектура (разделение ответственности)
4. Архитектурные ограничения (дополняющее ТЗ)
5. Функциональное описание модуля 2 (алгоритм Отиаи, 75%)
6. ТЗ_1 (лучший вариант ТЗ для модуля 2)
```

### **1.2. Открой НОВЫЙ ЧАТ для ЧАТ 2:**
```
1. Откройте новое окно/вкладку ChatGPT
2. Это будет ваш "Разработчик" (ЧАТ 2)
3. Держите этот чат открытым (ЧАТ 1)
```

## **📋 ШАГ 2: СОЗДАНИЕ ТЗ-0 ДЛЯ МОДУЛЯ 2**

### **2.1. В ЭТОМ ЧАТЕ (ЧАТ 1):**
**Отправьте мне (как архитектору):**
```
"Создай ТЗ-0 для Модуля 2: Архитектурный скелет"
```

Я использую **адаптированный промпт "Создатель ТЗ-Х"** чтобы создать:
```

- Все 9 файлов в module-fertilizer-selector/
- Пустые классы с сигнатурами методов
- WordPress хуки с префиксами npk_fs_
- Структура как у Модуля 1, но с уникальными именами
```

### **2.3. Вы получите:**
Готовое ТЗ-0, которое можно передать ЧАТ 2.
