║                        КОМАНДА №1 ДЛЯ ИСПОЛНИТЕЛЯ                           ║

2.  **Внутри неё создайте:**    `shared/config/`

3.  **Поместите файл БД:**      `shared/config/npk-database.php` (уже существует)

## **СХЕМА, КОТОРУЮ НЕЛЬЗЯ НАРУШАТЬ:**

```
npk-calculators/
├── npk-calculators.php                       ← Главный файл плагина
│
├── shared/config/npk-database.php            ← БАЗА ДАННЫХ (НЕ ПЕРЕМЕЩАТЬ!)
│
└── module-concentration/                     ← ЗДЕСЬ ВЕСЬ КОД МОДУЛЯ КОНЦЕНТРАЦИИ!
    ├── concentration-module.php
    ├── includes/                             [4 файла]
    │   ├── class-calculation-engine.php      ← ЧИСТАЯ логика расчёта
    │   ├── class-ajax-handler.php            ← Транспорт данных
    │   ├── class-data-adapter.php            ← Адаптация для UI
    │   └── class-shortcode.php               ← HTML обёртка
    ├── assets/                               [2 файла]
    │   ├── js/calculator.js                  ← UI логика
    │   └── css/calculator.css                ← Стили модуля
    └── templates/                            [1 файл]
        └── calculator-template.php           ← HTML шаблон
```

**⚡ ПРОВЕРЬТЕ СЕБЯ:** Если у вас есть классы концентрации вне папки `module-concentration/` — ВЫ ДЕЛАЕТЕ НЕПРАВИЛЬНО. Начинайте заново.
