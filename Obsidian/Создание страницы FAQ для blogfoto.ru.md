# Как создать SEO-оптимизированную страницу FAQ

**WordPress + Elementor Pro + Rank Math**

---

## ШАГ 1. Создаём страницу FAQ в WordPress

1. **Страницы → Добавить новую**
2. Название страницы:
    
    ```
    FAQ — вопросы об интерьерной фотосъёмке
    ```
    (или проще: **Вопросы и ответы**)
1. URL (slug):
    ```
    /faq-interior-photography/
    ```
    или
    ```
    /faq/
    ```

📌 Короткий URL — лучше.

---

## ШАГ 2. Открываем страницу в Elementor

Нажимаем **«Редактировать в Elementor»**.

---

## ШАГ 3. Структура страницы (очень важно для SEO)

### 1️⃣ Заголовок страницы

Добавь виджет **Heading**:

- **H1**:
```
    Часто задаваемые вопросы об интерьерной фотосъёмке
    ```
    
- Ниже — **Text Editor** (2–3 предложения):
    
    ```
    Здесь вы найдёте ответы на самые частые вопросы о подготовке,
    организации и стоимости интерьерной фотосъёмки квартир,
    домов, отелей и коммерческих объектов.
    ```
    

📌 Это усиливает релевантность страницы.

---

## ШАГ 4. Добавляем FAQ через Elementor Pro

### Лучший вариант — **Toggle** или **Accordion**

Используй:

- **Accordion** — если вопросы важные;
    
- **Toggle** — если их много.
    

📌 SEO-разницы нет, выбирай по удобству.

---

### Пример структуры в Elementor:

**H2:** Стоимость и условия съёмки

➡️ Accordion:

- Вопрос: _Сколько стоит интерьерная фотосъёмка?_  
    Ответ: текст 2–4 абзаца
    
- Вопрос: _Что входит в стоимость съёмки интерьера?_
    

---

**H2:** Подготовка интерьера

➡️ Accordion:

- _Нужно ли убирать личные вещи перед съёмкой?_
    
- _Нужен ли декоратор для интерьерной фотосъёмки?_
    

---

📌 **Важно:**  
Каждый вопрос = **реальный поисковый запрос**.

---

## ШАГ 5. Подключаем FAQ Schema через Rank Math

🔥 Ключевой момент

### В Elementor:

1. Кликни **по любому FAQ-блоку**
    
2. Внизу панели Elementor открой:  
    **Advanced → Rank Math**
    
3. Включи:  
    **Schema → FAQ Page**
    

(Если не видно — убедись, что Rank Math активен и обновлён)

---

### Как правильно заполнить Schema:

Rank Math автоматически:

- берёт вопросы из Accordion;
    
- превращает их в FAQ Schema;
    
- добавляет разметку в код страницы.
    

⚠️ **Важно правило Google**  
В Schema можно добавлять **ТОЛЬКО те вопросы, которые видны пользователю на странице**.  
(Accordion — ок, скрытый текст — нет)

---

## ШАГ 6. SEO-настройки страницы (Rank Math)

Под контентом страницы (в редакторе):

### 1️⃣ Title:

```
FAQ об интерьерной фотосъёмке — вопросы и ответы фотографа
```

### 2️⃣ Description:

```
Ответы на частые вопросы об интерьерной фотосъёмке:
стоимость, подготовка квартиры, сроки, организация съёмки.
```

### 3️⃣ Фокус-ключ:

```
интерьерная фотосъёмка FAQ
```

---

## ШАГ 7. Что НЕ нужно делать ❌

🚫 Не делай отдельный плагин FAQ  
🚫 Не вставляй Schema вручную  
🚫 Не копируй вопросы с конкурентов слово в слово  
🚫 Не пиши короткие ответы «да / нет»

---

## Идеальная длина FAQ-ответов

- 300–600 знаков — оптимально
    
- 2–4 абзаца
    
- простой, экспертный язык
    

Ты фотограф → **говоришь как специалист**, не как маркетолог.
