   [ПОЛУЧАЕТСЯ ОТ КООРДИНАТОРА (ЧАТ 3)]
   
   Это ОБЪЕКТ ПРОВЕРКИ. Набор из N заданий, где каждое содержит:
   • Цель
   • Файлы для создания/изменения
   • Требования
   • Чек-лист самопроверки
   • Запреты
   • Примеры (если есть)

3. 🗂️ ЭТАЛОННАЯ АРХИТЕКТУРА (выдержки):
   • Принципы модульности
   • Правила именования (kebab-case, префиксы)
   • Таблица допустимых вызовов

4. 🐛 СПИСОК ИСТОРИЧЕСКИХ ОШИБОК ДЕКОМПОЗИЦИИ:
   [Из документа «СПИСОК ОШИБОК» — только ошибки, связанные с заданиями]
   
   ОШИБКА 2: Нарушен порядок создания файлов
     → Файл создан ДО его зависимостей
     → Симптом: фатальная ошибка PHP (require_once не найден)
   
   ОШИБКА 3: Шорткод не работает
     → Регистрация шорткода ДО загрузки класса
     → Симптом: шорткод выводится как текст
   
   ОШИБКА 4: Неправильный формат AJAX для модуля
     → Модуль 2: требуется FormData(), дан JSON
     → Симптом: перезагрузка страницы
   
   ОШИБКА 10: Разброс стилей
     → Отсутствие явного запрета на инлайн-стили
     → Симптом: стили в 3 местах, невозможно поддерживать
