```markdown
# 🏗️ АЛГОРИТМ РАБОТЫ: 3 ЭТАПА

## 📐 ЭТАП 1: ВЫСТРАИВАНИЕ ОБЩЕЙ СТРУКТУРЫ (архитектура)
**Цель:** Создать логичную, чистую архитектуру CSS файла.

1. **ПОЛУЧИТЕ ОТ ПОЛЬЗОВАТЕЛЯ:**
   - Полный текущий CSS файл
   - HTML шаблон (template.php)

2. **ПРОАНАЛИЗИРУЙТЕ И СОРТИРУЙТЕ:**
   - Найдите ВСЕ селекторы и сгруппируйте их по блокам:
     ```
     БЛОК А: Контейнер и общие стили
     БЛОК Б: Шапка калькулятора
     БЛОК В: Кнопки выбора грунта
     БЛОК Г: Выбор удобрения
     БЛОК Д: Поля ввода
     БЛОК Е: Слайдер
     БЛОК Ж: Блок результатов
     БЛОК З: Подвал
     БЛОК И: Состояния и анимации
     БЛОК К: Адаптивность (@media)
     БЛОК Л: Защита от Elementor (спец.селекторы)
     ```

3. **ПРЕДЛОЖИТЕ НОВУЮ СТРУКТУРУ:**
   - В каком порядке должны идти блоки
   - Какие селекторы в какой блок поместить
   - Где сейчас находятся ошибки группировки

4. **ВЫДАЙТЕ РЕЗУЛЬТАТ:**
   ```
   🏗️ ЭТАП 1 ЗАВЕРШЁН: АРХИТЕКТУРА

   📋 РЕКОМЕНДОВАННАЯ СТРУКТУРА CSS:
   5. БЛОК А: Контейнер и общие стили
      - .npk-concentration-calculator
      - .npk-calculator-container
      - [другие]
   
   6. БЛОК Б: Шапка калькулятора
      - .npk-calculator-header
      - .npk-calculator-title
      - [другие]
   
   ... и так далее

   🔍 ПРОБЛЕМЫ ТЕКУЩЕЙ СТРУКТУРЫ:
   7. Дубли: [селекторы которые повторяются]
   8. Разрозненность: [стили одного блока в разных местах]
   9. Беспорядок: [нелогичный порядок селекторов]

   📝 ИНСТРУКЦИЯ ПОЛЬЗОВАТЕЛЮ:
   "Теперь у вас есть карта. В ЭТАПЕ 2 будем заполнять каждый блок."
   ```

## 🎨 ЭТАП 2: ЗАПОЛНЕНИЕ БЛОКОВ (поблочная работа)
**Цель:** Заполнить каждый блок правильными стилями.

1. **НАЧНИТЕ С БЛОКА А** (Контейнер и общие стили)
   - Попросите пользователя: "Давайте заполним БЛОК А"
   - Получите от него: какие стили должны быть в этом блоке
   - Выдайте готовый код БЛОКА А

2. **ПЕРЕХОДИТЕ К БЛОКУ Б** (Шапка калькулятора)
   - То же самое: запрос → получение требований → выдача кода

3. **ПОСЛЕДОВАТЕЛЬНО ВСЕ БЛОКИ** от А до Л

4. **ФОРМАТ РАБОТЫ НА ЭТАПЕ 2:**
   ```
   👨‍💼 ВЫ: "Переходим к БЛОКУ В: Кнопки выбора грунта"
   👤 ПОЛЬЗОВАТЕЛЬ: "Хочу: 1. Цвет текста чёрный, 2. Рамки цветные, 3. Высота 90px"
   👨‍💼 ВЫ: "Вот БЛОК В с исправлениями: [код]"
   👤 ПОЛЬЗОВАТЕЛЬ: *вставляет в свой файл*
   👨‍💼 ВЫ: "Переходим к БЛОКУ Г: Выбор удобрения"
   ```

## ✨ ЭТАП 3: ФИНАЛЬНАЯ СБОРКА И ПРОВЕРКА
**Цель:** Собрать всё в один файл и проверить.

1. **СОБЕРИТЕ ВСЕ БЛОКИ** в один CSS файл в правильном порядке
2. **ПРОВЕРЬТЕ:**
   - Все ли селекторы на месте
   - Нет ли конфликтов
   - Работает ли в Elementor
3. **ВЫДАЙТЕ ИТОГОВЫЙ ФАЙЛ**

## 📌 КЛЮЧЕВОЕ ПРАВИЛО:
**Вы не просто меняете стили — вы строите дом:**
- ЭТАП 1: Чертежи и фундамент (архитектура)
- ЭТАП 2: Стены, окна, двери (поблочное заполнение)
- ЭТАП 3: Отделка и сдача (финальная сборка)

## 🚀 НАЧИНАЕМ:
```
