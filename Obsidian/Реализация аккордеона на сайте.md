## 🎯 **ВАРИАНТЫ КОМПОНОВКИ "ФОТО + ТЕКСТ РЯДОМ":**

### **Вариант 1: Чёткое соответствие (рекомендую)**
```
### 4.1. Вертикальная стойка

┌─────────────────────────────────────┐
│                                     │
│  [ФОТО: Стойка с отверстиями]       │ │  **Технические характеристики:** │
│                                     │ │  • Длина: 1200 мм                │
│  *Крупный план отверстий через      │ │  • Материал: алюминий 20×20 мм   │
│   100 мм для точной фиксации*       │ │  • Фиксация: штифтовой болт М8   │
│                                     │ │  • Отверстия: шаг 100 мм         │
└─────────────────────────────────────┘ │                                    │
                                         └────────────────────────────────────┘
```

### **Вариант 2: Галерея с подписями под каждой фото**
```
### 4.1. Регулируемый каркас

[Галерея из 3 фото с подписями]

┌─────────────┐  ┌─────────────┐  ┌─────────────┐
│             │  │             │  │             │
│   ФОТО 1    │  │   ФОТО 2    │  │   ФОТО 3    │
│  Вертикальная│  │ Горизонталь-│  │  Крепление  │
│    стойка    │  │   ные штанги│  │   болтами   │
└─────────────┘  └─────────────┘  └─────────────┘

**Подробное описание каждого элемента:**
1. **Вертикальная стойка** - 1200 мм, отверстия через 100 мм...
2. **Горизонтальные штанги** - 1000 мм, регулируются...
3. **Крепления** - штифтовые и прижимные болты...
```

## 🔧 **ТЕХНИЧЕСКИ РЕАЛИЗУЕМО В АККОРДЕОНЕ/ТАБАХ:**

### **В Elementor (просто):**
1. Создаёшь **ряд (Row)**
2. В него добавляешь **2 колонки (Columns)**:
   - Левая: Виджет "Изображение" или "Галерея"
   - Правая: Виджет "Текст редактор"
3. Повторяешь для каждой пары фото+текст

```
В аккордеоне это выглядит так:
▼ Каркас [раскрывается]
   ┌──────────────┬──────────────┐
   │  ФОТО 1      │  ТЕКСТ 1     │
   ├──────────────┼──────────────┤
   │  ФОТО 2      │  ТЕКСТ 2     │
   └──────────────┴──────────────┘
```

### **Пример структуры в аккордеоне:**
```html
<div class="accordion-item">
  <h3>4.1. Регулируемый каркас</h3>
  <div class="content">
    
    <!-- Блок 1: Стойка -->
    <div class="photo-text-pair">
      <img src="стойка.jpg" alt="Вертикальная стойка">
      <div class="text">
        <h4>Вертикальная стойка</h4>
        <p>1200 мм, алюминиевый профиль...</p>
      </div>
    </div>
    
    <!-- Блок 2: Штанги -->
    <div class="photo-text-pair">
      <img src="штанги.jpg" alt="Горизонтальные штанги">
      <div class="text">
        <h4>Горизонтальные штанги</h4>
        <p>1000 мм, стальная труба...</p>
      </div>
    </div>
    
  </div>
</div>
```

## 📱 **АДАПТАЦИЯ ДЛЯ МОБИЛЬНЫХ:**

### **На десктопе (широком экране):**
```
[ФОТО] [ТЕКСТ] — рядом, в одну строку
```

### **На мобильном (узком экране):**
```
[ФОТО]
[ТЕКСТ] — под фото, в колонку
```

**Технически:** Используй CSS Grid или Flexbox с `@media` запросами.

## 💡 **ПРАКТИЧЕСКИЕ СОВЕТЫ:**

### **1. Используй подписи к фото:**
```html
<figure>
  <img src="стойка.jpg" alt="Вертикальная стойка">
  <figcaption>Рис. 1: Вертикальная стойка с отверстиями через 100 мм</figcaption>
</figure>
```

### **2. Добавь визуальные связи:**
- **Цветные рамки** вокруг связанных блоков
- **Стрелки** от фото к тексту
- **Одинаковые иконки** у связанных элементов
- **Номера** на фото и в тексте

### **3. Сделай интерактивным:**
```
При наведении на фото → соответствующий текст подсвечивается
При наведении на текст → соответствующее фото увеличивается
```

---

## 🚀 **РЕАЛИЗАЦИЯ В ELEMENTOR (пошагово):**

1. **Добавляешь аккордеон**
2. **В каждый пункт аккордеона:**
   - Добавляешь **ряд (Row)**
   - Настраиваешь **2 колонки 50%/50%**
   - **В левую:** Изображение
   - **В правую:** Текстовый редактор
   - **Дублируешь ряд** для следующей пары фото+текст
3. **Для мобильных:** В настройках ряда меняешь колонки на **100%** (стеком)

**Результат:** Чёткие пары "фото-текст" внутри каждого раздела аккордеона.

## ✅ **ИТОГ:**

**Да, это полностью реализуемо и даже стандартная практика.** Аккордеон/табы — это просто контейнеры, внутри которых ты можешь делать любую вёрстку: фото рядом с текстом, галереи, таблицы и т.д.

**Рекомендую:** Аккордеон → внутри него для каждого компонента делать отдельные блоки "фото слева + текст справа" с чёткими подзаголовками.
