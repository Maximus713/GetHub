## **1. ПРЕАМБУЛА**

В процессе реализации модуля «Калькулятор концентрации рабочего раствора» выявлена **фундаментальная несовместимость** между требованиями ТЗ и архитектурой WordPress.

### **1.1. Обнаруженная проблема:**
Требования ТЗ п.6.6.1, п.7.3.2, Приложение A.1 предписывают использование исключительно:
```
Content-Type: application/json
body: JSON.stringify()
```

**Однако** стандартная система AJAX WordPress (`admin-ajax.php`):
1. **Не читает** данные из `php://input` для JSON
2. **Ожидает** данные в `$_POST` или `$_GET`
3. **Автоматически** обрабатывает только `application/x-www-form-urlencoded` и `multipart/form-data`

### **1.2. Проведённый эксперимент:**
- ✅ Тестовый запрос с `$_POST['action']` → работает
- ❌ Запрос с `application/json` → HTTP 400 Bad Request
- ✅ Формат `FormData()` → работает корректно

**Вывод:** Строгое следование п.6.6.1 делает AJAX функционал **неработоспособным**.

## **2. ИЗМЕНЕНИЯ В ТРЕБОВАНИЯХ**

### **2.1. Разрешённые AJAX форматы (вместо п.6.6.1):**

| Формат | Разрешено | Примечание |
|--------|-----------|------------|
| `application/json` | ❌ **Запрещено** | Не работает в WordPress AJAX |
| `FormData()` | ✅ **Разрешено** | При условии Nonce проверки |
| `application/x-www-form-urlencoded` | ✅ **Разрешено** | При условии Nonce проверки |

### **2.2. Новый п.6.6.1 AJAX-запросы (ЕДИНСТВЕННЫЙ допустимый формат):**

```javascript
// ✅ НОВЫЙ СТАНДАРТ (работающий)
const formData = new FormData();
formData.append('action', 'npk_concentration_calculate');
formData.append('nonce', window.NPK_Concentration_Ajax?.nonce || '');
formData.append('fertilizer_id', currentState.fertilizerId);
formData.append('concentration', currentState.concentration);
formData.append('water_volume', currentState.waterVolume);
formData.append('ground_type', currentState.groundType);

fetch(window.ajaxurl || window.NPK_Concentration_Ajax?.url, {
    method: 'POST',
    // Content-Type НЕ указывается - браузер добавит автоматически
    body: formData,
    signal: controller.signal
})
```

## **3. ТРЕБОВАНИЯ К БЕЗОПАСНОСТИ (ОБЯЗАТЕЛЬНЫ)**

В связи с изменением формата данных, **усилены требования к безопасности**:

### **3.1. Nonce проверка (ОБЯЗАТЕЛЬНА):**
```php
// В AJAX обработчике ПЕРВОЙ строкой:
if (!isset($_POST['nonce']) || !wp_verify_nonce($_POST['nonce'], 'npk_concentration_calculate')) {
    wp_send_json_error('Security check failed', 403);
    wp_die();
}
```

### **3.2. Валидация всех входных данных (ОБЯЗАТЕЛЬНА):**
```php
// Проверка каждого параметра:
$fertilizer_id = isset($_POST['fertilizer_id']) ? (int)$_POST['fertilizer_id'] : 0;
if ($fertilizer_id <= 0) {
    wp_send_json_error('Invalid fertilizer ID', 400);
}

// Проверка существования удобрения в БД
$fertilizer_exists = NPK_Database::fertilizer_exists($fertilizer_id);
if (!$fertilizer_exists) {
    wp_send_json_error('Fertilizer not found', 400);
}
```

### **3.3. Rate limiting (РЕКОМЕНДУЕМО):**
```php
// Защита от DDoS атак:
$ip = $_SERVER['REMOTE_ADDR'];
$transient_key = 'npk_rate_limit_' . $ip;
$request_count = get_transient($transient_key) ?: 0;

if ($request_count > 30) { // 30 запросов в минуту
    wp_send_json_error('Rate limit exceeded. Please wait.', 429);
}

set_transient($transient_key, $request_count + 1, MINUTE_IN_SECONDS);
```
