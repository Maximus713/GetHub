
Да, **абсолютно точно можно создать такой шаблон записи**. Это стандартная и очень популярная структура для блога, и реализовать её проще всего с помощью **Elementor Pro** и его **Theme Builder**.

### 🎯 Как создать этот шаблон с Elementor Pro

Вот пошаговая стратегия, соответствующая вашему описанию:

1.  **Создайте новый шаблон** в **Elementor → Theme Builder** типа **"Single Post"**.
2.  **Выберите макет**. При создании шаблона выберите или создайте макет с двумя колонками (например, 70% / 30%), где широкая колонка — основной контент, узкая — сайдбар.
3.  **Соберите структуру, перетаскивая виджеты**. Вот как будут соотноситься ваши пункты и виджеты Elementor:

#### **Левая колонка (Основной контент, ~70% ширины):**
| Ваш пункт | Виджет Elementor (в разделе "Theme Elements") | Примечание |
| :--- | :--- | :--- |
| **Рубрика записи** | `Post Info` | В его настройках можно оставить только "Categories". |
| **Заголовок записи (H1)** | `Post Title` | В настройках виджета выберите HTML-тег `H1`. |
| **Подзаголовок (H2)** | **Проблема:** Нет отдельного поля для подзаголовка. | **Решение 1:** Использовать виджет `Post Excerpt` (краткое описание). **Решение 2:** Добавлять подзаголовок вручную в редакторе каждой записи. |
| **Текстовый блок** | `Post Content` | Этот виджет **автоматически** выведет весь ваш основной текст, фотографии и подзаголовки, которые вы добавляете в редакторе WordPress при создании записи. Вам не нужно добавлять их отдельно в шаблон. |
| **Фотография** | (Часть `Post Content`) | Фотографии вставляются прямо в контент записи. |
| **Кнопки соцсетей** | `Share Buttons` | Находится в виджетах "Прочее" (или "Социальные"). |
| **"Последние записи"** | `Posts` | В настройках источника данных выберите "Posts", порядок "Newest First", ограничьте 6 записями. |

#### **Правая колонка (Сайдбар, ~30% ширины):**
| Ваш пункт | Виджет Elementor | Настройка |
| :--- | :--- | :--- |
| **"Записи из той же рубрики"** | `Posts` | Ключевой момент: в настройках виджета для **"Фильтры"** выберите "Related". В дополнительных настройках укажите, что связь должна быть по `Categories`. |
| **Метки (облако/список)** | **Проблема:** В Elementor нет нативного виджета для облака меток. | **Решение 1:** Использовать стандартный виджет WordPress "Облако меток". Для этого в редакторе шаблона Elementor добавьте виджет **"Шорткод"** и вставьте в него `[wp_tag_cloud]`. <br> **Решение 2:** Установить легкий плагин для виджетов, который добавит такой элемент в Elementor. |

### 💡 Критически важные детали

*   **Динамический контент (`Post Content`)**: Это сердце шаблона. Вы наполняете статью (текст, подзаголовки `H2/H3`, фото) в стандартном редакторе WordPress (Гутенберг или Elementor). Виджет `Post Content` в шаблоне — это просто "окно", которое отображает всё, что вы создали для конкретной записи. **Не нужно дублировать структуру в шаблоне.**
*   **Адаптивность**: После создания обязательно проверьте, как шаблон выглядит на мобильных. Часто на маленьких экранах сайдбар переносится под основной контент (это нормально). В Elementor можно отдельно настроить отображение для мобильных.
*   **"Последние записи" внизу**: Чтобы этот блок отображался **только в конце основной статьи**, а не на всех страницах, поместите виджет `Posts` **внутрь виджета `Post Content`**. Для этого:
    1.  В редакторе шаблона добавьте виджет `Post Content`.
    2.  **Кликните на него правой кнопкой мыши** и выберите **"Редактировать макет содержимого"**.
    3.  В открывшемся мини-редакторе в самый низ перетащите виджет `Posts` с настройками "Последние записи".

### 🛠️ Альтернатива без Elementor Pro

Если у вас нет Pro-версии, эту структуру можно собрать, комбинируя:
1.  **Настройки темы** для создания макета с сайдбаром.
2.  **Редактор записей** (Гутенберг) для основного контента.
3.  **Область виджетов сайдбара** в WordPress (`Внешний вид → Виджеты`), куда нужно перетащить:
    *   Виджет **"Записи"** (и настроить его на показ записей из той же рубрики через фильтры, если тема позволяет).
    *   Виджет **"Облако меток"**.

**Итог**: Ваша структура полностью реализуема. С Elementor Pro это делается наглядно и гибко в Theme Builder. Без него — через комбинацию настроек темы и стандартных виджетов WordPress.
