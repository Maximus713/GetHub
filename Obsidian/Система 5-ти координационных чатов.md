**Понимаю!** Вам нужна система **координированных AI-агентов**, где каждый чат выполняет строго определенную роль в разработке. Вот готовая система:

---

## **🏗️ Система 5-ти координационных чатов (AI-агентов)**

### **📊 Общая схема работы:**
```
[ПЛАНИРОВЩИК] → [АРХИТЕКТОР] → [РАЗРАБОТЧИК] → [ТЕСТИРОВЩИК] → [АУДИТОР]
      ↓              ↓              ↓              ↓              ↓
  Этапы и       Структура       Код плагина    Проверка       Финальная
  контроль                        + виджеты   кода/ошибок    верификация
```

---

## **👑 1. ЧАТ-ПЛАНИРОВЩИК (Project Manager)**

**Роль:** Делит проект на этапы, контролирует прогресс

**Промпт для инициализации:**
```markdown
Ты - AI-проект-менеджер по разработке WordPress плагина. Твои задачи:

1. **Анализ документов:** Изучи все предоставленные документы
2. **Создание поэтапного плана:** Разбей разработку на 8-10 логических этапов
3. **Контроль этапов:** Следи за завершением каждого этапа
4. **Координация:** Давай точные инструкции следующему агенту

ИСПОЛЬЗУЙ ЭТИ ДОКУМЕНТЫ:
📄 Основное ТЗ (полная версия)
🗄️ База данных (npk-database.php) 
🏗️ Эталонная архитектура
⚠️ Архитектурные ограничения
🐛 Ошибки при создании
✅ Инструкция финальной проверки

ПОРЯДОК РАБОТЫ:
1. Сначала создай подробный поэтапный план (Stage Plan)
2. Для каждого этапа создай Task Card с четкими критериями
3. Передай Task Card ЧАТУ-АРХИТЕКТОРУ
4. Получив результат от АУДИТОРА, либо закрывай этап, либо отправляй на доработку

**ТЕХНИЧЕСКОЕ ЗАДАНИЕ ДЛЯ АРХИТЕКТОРА:**
```

## **🔄 Рабочий процесс на практике:**

### **День 1: Запуск системы**
1. **Создаете 5 отдельных чатов** (в разных окнах/вкладках)
2. **Инициализируете каждый** своим промптом
3. **Загружаете документы** во все чаты (кроме Планировщика)
4. **Даете команду Планировщику:** "Создай поэтапный план разработки плагина"

### **Цикл каждого этапа:**
```
1. ПЛАНИРОВЩИК → создает Task Card для этапа 1
2. АРХИТЕКТОР → создает Technical Design
3. РАЗРАБОТЧИК → пишет код
4. ТЕСТИРОВЩИК → проверяет и дает отчет
5. АУДИТОР → принимает решение
6. ПЛАНИРОВЩИК → запускает этап 2
```

### **Ключевые правила:**
1. **Каждый чат видит только свой промпт**
2. **Документы загружаются один раз и используются всеми**
3. **Результат передается цепочкой**
4. **При отклонении - возврат к нужному звену**
5. **Архивируйте результаты каждого этапа**

## **🎯 Преимущества системы:**

1. **Четкое разделение ответственности** - каждый AI специализируется
2. **Минимизация ошибок** - 4 уровня проверки
3. **Сохранение контекста** - документы у всех
4. **Масштабируемость** - можно добавлять новых агентов
5. **Отслеживаемость** - полная история решений

**Начните с инициализации ЧАТА-ПЛАНИРОВЩИКА** и загрузки в него всех документов. Он запустит весь процесс.
