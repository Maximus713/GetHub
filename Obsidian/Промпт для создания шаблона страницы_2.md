# 🎯 **ПРОМПТ: СОЗДАНИЕ ШАБЛОННОЙ СТРАНИЦЫ WORDPRESS ДЛЯ КАЛЬКУЛЯТОРА**

## 🎯 **ЦЕЛЬ:**
Создать шаблонную страницу WordPress для изолированного отображения калькулятора NPK с максимальной защитой от конфликтов с Elementor и BeTheme.

## 📋 **ТРЕБОВАНИЯ К ШАБЛОНУ:**

### **1. ИЗОЛЯЦИЯ ОТ ELEMENTOR/BETHEME:**
- **Блокировать ВСЕ стили Elementor** на странице калькулятора
- **Удалять инлайн-стили Elementor** (`style="..."` с `!important`)
- **Деактивировать JavaScript Elementor** который может вмешиваться
- **Сохранять НАШИ стили** из `calculator.css` нетронутыми

### **2. CSS СТРАТЕГИЯ:**
- **НЕ ДУБЛИРОВАТЬ** стили из `calculator.css`
- **НЕ ИСПОЛЬЗОВАТЬ** повсеместный `!important`
- **Использовать CSS Containment**: `isolation: isolate`, `contain: content`
- **Минимальные layout-стили** только для этой страницы

### **3. JAVASCRIPT ЗАЩИТА:**
- **MutationObserver** для удаления динамических инлайн-стилей
- **Selective cleaning**: удалять ТОЛЬКО стили Elementor/BeTheme
- **Debounced execution**: запускать очистку несколько раз с интервалами
- **Emergency fix**: fallback-решение если всё сломано

### **4. СТРУКТУРА СТРАНИЦЫ:**
- **Минимальный header** с логотипом и кнопкой "Назад на сайт"
- **Main content area** для калькулятора
- **Изолированная зона**: div с `id="npk-isolation-zone"`
- **Простой footer** с копирайтом

### **5. ПОДКЛЮЧЕНИЕ РЕСУРСОВ:**
- **Основной CSS калькулятора** из плагина
- **JavaScript калькулятора** из плагина
- **jQuery WordPress**
- **WordPress head/footer** хуки

### **6. ТЕХНИЧЕСКИЕ ДЕТАЛИ:**
- **Имя шаблона**: `NPK Calculator - Clean Isolation`
- **PHP require**: `wp-load.php`
- **Деактивация стилей**: в `wp_enqueue_scripts` с приоритетом 999999
- **Кодировка**: UTF-8
- **Адаптивность**: mobile-first

## 🚫 **ЗАПРЕЩЕНО:**
- ❌ Копировать CSS из `calculator.css` в шаблон
- ❌ Использовать `!important` для всех свойств
- ❌ Создавать сложные CSS-фреймворки
- ❌ Нарушать структуру плагина NPK Calculator
- ❌ Использовать `all: unset` для элементов калькулятора

## ✅ **ОБЯЗАТЕЛЬНЫЕ ФУНКЦИИ:**

### **1. PHP Функции:**
```php
// Деактивация Elementor
add_action('wp_enqueue_scripts', function() {
    wp_dequeue_style('elementor-frontend');
    wp_dequeue_style('elementor-global');
    // ... все стили Elementor/BeTheme
}, 999999);
```

### **2. JavaScript Очистка:**
```javascript
// Удаление инлайн-стилей Elementor
function cleanInlineStyles() {
    // Удаляем только style атрибуты с 'elementor', 'mfn-', '!important'
    // Сохраняем безопасные стили
}
```

### **3. CSS Изоляция:**
```css
.npk-calculator-isolation-wrapper {
    isolation: isolate;
    contain: content;
    position: relative;
    z-index: 10;
}
```

- Минимальный emergency CSS с `!important` (только если необходимо)
