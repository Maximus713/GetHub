## **🎯 ПОСЛЕДОВАТЕЛЬНОСТЬ РАБОТЫ С ПРОМПТОМ ДЛЯ ЧАТА**

Работайте **строго в 4 этапа**:

---

### **🎯 ЭТАП 1: ПОДГОТОВКА И АНАЛИЗ**

```
1. СКОПИРУЙТЕ В ЧАТ:
   - Весь промпт "Архитектор-Корректор ТЗ"
   - Полную версию ТЗ (как у вас в первом сообщении)
   - Дополнение к ТЗ (как у вас во втором сообщении)

2. ДАЙТЕ ЧАТУ КОМАНДУ:
"Проанализируй ТЗ и Дополнение. Создай таблицу соответствий:
- Каждый пункт Дополнения → Какой пункт ТЗ изменяет/отменяет
- Приоритет изменений (критические/важные/рекомендации)
- Потенциальные конфликты с неизменными требованиями ТЗ"

3. ДОЖДИТЕСЬ ОТВЕТА ЧАТА С ТАБЛИЦЕЙ
```

### **🎯 ЭТАП 2: ПОШАГОВЫЕ ИСПРАВЛЕНИЯ (ГЛАВНАЯ РАБОТА)**

```
4. ДАЙТЕ ЧАТУ КОМАНДУ:
"Начни внесение изменений в ТЗ согласно таблице соответствий.
Работай ПО ОДНОМУ пункту из Дополнения.
После каждого изменения выводи результат в формате промпта."

5. ПОСЛЕ КАЖДОГО ИСПРАВЛЕНИЯ:
- Проверьте, что изменение минимальное и точное
- Убедитесь, что остальной ТЗ не затронут
- Дайте команду: "Переходи к следующему пункту из таблицы"
```

**Пример диалога на этом этапе:**
```
Вы: "Начни с изменения #1 из таблицы: AJAX формат"
Чат: [Выводит исправление для п.6.6.1 ТЗ]
Вы: "✅ Принято. Переходи к изменению #2: Nonce проверка"
Чат: [Выводит исправление для AJAX Handler]
...
```

### **🎯 ЭТАП 3: ПРОВЕРКА ЦЕЛОСТНОСТИ**

```
6. КОГДА ВСЕ ИЗМЕНЕНИЯ ВНЕСЕНЫ, ДАЙТЕ КОМАНДУ:
"Проведи финальную проверку целостности исправленного ТЗ:
7. Все ли требования Дополнения учтены?
8. Есть ли противоречия между исправленными и старыми пунктами?
9. Сохранена ли структура и нумерация ТЗ?
10. Актуальны ли все перекрёстные ссылки?"

11. ДОЖДИТЕСЬ ОТЧЁТА О ПРОВЕРКЕ
```

### **🎯 ЭТАП 4: ФИНАЛИЗАЦИЯ**

```
8. ПОСЛЕ УСПЕШНОЙ ПРОВЕРКИ:
"Представь окончательную версию исправленного ТЗ.
В начале документа укажи:
- Версию (например, ТЗ 3.1 с учётом Дополнения №1)
- Список внесённых изменений
- Дату корректировки"

9. ПОЛУЧИТЕ ИТОГОВЫЙ ДОКУМЕНТ
```

---

## **⏱️ ПРИМЕРНАЯ ВРЕМЕННАЯ СХЕМА:**

```
МИНУТЫ 0-5: Этап 1 (Анализ)
МИНУТЫ 5-25: Этап 2 (Пошаговые исправления - 10-15 изменений)
МИНУТЫ 25-30: Этап 3 (Проверка целостности)
МИНУТЫ 30-35: Этап 4 (Финальная версия)
```

## **🚨 ЧТО ДЕЛАТЬ, ЕСЛИ ЧАТ ОШИБАЕТСЯ:**

```
СИТУАЦИЯ: Чат пытается внести лишние изменения
ВЫ ГОВОРИТЕ: "Стоп. Это изменение не требуется Дополнением.
              Вернись к таблице соответствий. Следующий пункт: [номер]"

СИТУАЦИЯ: Чат пропустил требование из Дополнения
ВЫ ГОВОРИТЕ: "Вернись к пункту [номер] Дополнения.
              Он требует изменения в п.[номер] ТЗ. Внеси исправление"

СИТУАЦИЯ: Непонятное изменение
ВЫ ГОВОРИТЕ: "Объясни, почему это изменение необходимо.
              Покажи цитату из Дополнения"
```

## **📋 КОРОТКИЙ ЧЕК-ЛИСТ ДЛЯ ВАС КАК КУРАТОРА:**

- [ ] **Перед началом:** Есть полные ТЗ и Дополнение
- [ ] **Шаг 1:** Получена таблица соответствий от чата
- [ ] **Шаг 2:** Каждое изменение проверено на минимальность
- [ ] **Шаг 3:** После всех изменений — проверка целостности
- [ ] **Шаг 4:** Получена финальная версия с отметкой об изменениях
- [ ] **Контроль:** Никаких "улучшений" ТЗ, только то, что в Дополнении

---

**Начните с первого этапа — скопируйте промпт, ТЗ и Дополнение в чат и дайте команду на анализ.** Я готов помочь, если возникнут вопросы на любом этапе.
