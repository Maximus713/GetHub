## 🗺️ **КАРТА ЭТАПОВ (ЗАРАНЕЕ ЗНАЕШЬ):**

### **ЭТАП 1: АРХИТЕКТУРНЫЙ СКЕЛЕТ**
- 9 файлов с пустыми классами и методами
- WordPress хуки (регистрация без реализации)
- НИКАКОЙ бизнес-логики
- **Готовность:** Плагин активируется, классы загружаются

### **ЭТАП 2: CALCULATION_ENGINE (ЯДРО ЛОГИКИ)**

- Алгоритм определения state (п.4.3)
- Валидация solubility_total (п.4.2)
- **Готовность:** calculate() возвращает корректные данные

### **ЭТАП 3: DATA_ADAPTER (ПОДГОТОВКА ДАННЫХ)**
- Структура NPK_Concentration_Data (п.7.3.1)
- Сортировка удобрений по id
- Пометка профиля по умолчанию
- **Готовность:** JavaScript получает полные данные

### **ЭТАП 4: AJAX_HANDLER (ТРАНСПОРТ)**
- Обработка POST запросов в JSON формате
- Валидация 4 обязательных полей
- Вызов Calculation_Engine
- **Готовность:** AJAX endpoint возвращает правильный JSON

### **ЭТАП 5: JAVASCRIPT (UI ЛОГИКА)**
- Обработчики событий (слайдер, кнопки, поля)
- Дебаунс 500мс для AJAX запросов
- Предварительный расчёт для мгновенной обратной связи
- **Готовность:** Интерфейс реагирует на действия пользователя

### **ЭТАП 6: HTML/CSS (ВИЗУАЛЬНАЯ ЧАСТЬ)**
- Вёрстка по макету из ТЗ п.5
- Стили с префиксом .npk-
- Цветовая логика (интерполяция)
- **Готовность:** Калькулятор выглядит как в макете

### **ЭТАП 7: ИНТЕГРАЦИЯ И ТЕСТИРОВАНИЕ**
- Полный цикл расчёта от UI до сервера
- Проверка архитектурных ограничений
- Тестирование ошибок и fallback
- **Готовность:** Весь плагин работает как единое целое
