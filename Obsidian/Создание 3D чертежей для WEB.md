[[Конвертация PDF]]

## **✅ Правильная последовательность:**

### **1. В AutoCAD подготовить ракурсы** — **ДА ✅**

### **2. Создать листы 1600×1400px** — **НЕТ ❌**
**Вместо этого:**
- **В AutoCAD работайте в реальных единицах** (мм, см)
- **При экспорте в PDF** используйте стандартные форматы:
  ```
  A3 (297×420 мм) или A4 (210×297 мм)
  ```
- **Пиксельный размер** настраивайте на этапе конвертации PDF → PNG

### **3. Экспортировать в PDF** — **ДА ✅**
```
Правильные настройки:
- Printer: DWG To PDF.pc3
- Paper size: ISO A3 (или A4 если чертёж простой)
- Plot area: Window (выделите область)
- Plot scale: Fit to paper
- Quality: Maximum
```

### **4. Конвертировать PDF в WebP** — **ДА, но через промежуточный PNG ✅**
```
PDF → PNG (высокое качество, 300 DPI) → WebP (оптимизированный)
```

### **5. Создать уменьшенные копии 400×300px** — **ДА ✅**
Но делайте это **из того же PNG**, не из уменьшенного WebP:
```
PNG (300 DPI, большой) 
├─→ WebP full (1600px, 90% качество)
└─→ WebP preview (400px, 75% качество)
```

### **6. Разместить на сайте** — **ДА ✅**

## **🎯 Пошагово для одного чертежа:**

### **Шаг 1: AutoCAD → PDF**
```
1. Открыли чертёж
2. Ctrl+P (Печать)
3. Принтер: DWG To PDF.pc3
4. Бумага: ISO A3
5. Область: Window → выделили чертёж
6. Сохранили: основание-системы.pdf
```

### **Шаг 2: PDF → High-quality PNG**
```
1. Открыли smallpdf.com/ru/pdf-to-png
2. Загрузили PDF
3. Настройки: 300 DPI, все страницы
4. Скачали: основание-системы.png (~2500×3500px)
```

### **Шаг 3: PNG → Два WebP**
```
1. Открыли Squoosh.app
2. Загрузили PNG
3. Вариант А (full):
   - Resize: 1600px width
   - Format: WebP
   - Quality: 90%
   - Скачали: основание-full.webp
   
4. Вариант Б (preview):
   - Resize: 400px width  
   - Format: WebP
   - Quality: 75%
   - Скачали: основание-preview.webp
```

### **Шаг 4: На сайт**
```
В Elementor:
1. Добавили виджет "Изображение"
2. Выбрали основание-preview.webp
3. Включили Lightbox
4. Указали основание-full.webp как файл для lightbox
```

## **⚠️ Что может пойти не так:**

### **Проблема: PDF слишком большой/тяжёлый**
**Решение:** В AutoCAD при печати выберите **A4 вместо A3**.

### **Проблема: При уменьшении до 400px текст нечитаем**
**Решение:** Создайте превью **600×450px** вместо 400×300.

### **Проблема: WebP не открывается в старом браузере**
**Решение:** Используйте `<picture>` тег с fallback на JPG:
```html
<picture>
  <source srcset="image.webp" type="image/webp">
  <source srcset="image.jpg" type="image/jpeg">
  <img src="image.jpg" alt="Чертёж">
</picture>
```

## **🎯 Способ 1: Онлайн-конвертеры (самый простой)**

### **1. Squoosh.app** (рекомендую — от Google)
- **Бесплатно, без регистрации**
- **Реальный предпросмотр** до/после
- **Контроль качества** ползунком
- **Сравнение** разных настроек
- **Ссылка:** https://squoosh.app

**Как использовать:**
```
1. Откройте Squoosh.app
2. Перетащите JPG/PNG
3. Справа выберите "WebP"
4. Настройте качество (80-85% для чертежей)
5. Скачайте
```

### **2. Convertio.co**
- **Пакетная конвертация** (много файлов сразу)
- **Сохраняет структуру папок**
- **Ограничение:** 100MB бесплатно
- **Ссылка:** https://convertio.co/ru/webp-converter/

### **3. Online-Convert.com**
- **Много форматов** на вход
- **Настройки** сжатия
- **Ссылка:** https://image.online-convert.com/convert-to-webp

```
5. Включить "Convert images automatically"
```

## **⚡ Профессиональные настройки для чертежей:**

### **В Squoosh.app используйте:**
```
1. Resize:
   - Превью: 400×300 (или 600×450 для Retina)
   - Full: 1600×1200
   
2. Quality: 
   - Превью: 70-75% (маленький размер)
   - Full: 85-90% (качество важно)
   
3. Метод сжатия:
   - Обычные фото: стандартный
   - Чертежи/схемы: можно попробовать "lossless" (без потерь)
```

### **Проверьте результат:**
1. **Откройте WebP** в браузере
2. **Увеличьте до 100%** — линии должны быть чёткими
3. **Сравните с оригиналом** — не должно быть артефактов

## **⚠️ Важные моменты:**

### **1. Совместимость:**
```
✅ Поддерживают: Chrome, Firefox, Safari, Edge (последние 2-3 года)
❌ Не поддерживают: IE11, очень старые браузеры
```

**Решение:** Используйте `<picture>` тег:
```html
<picture>
  <source srcset="image.webp" type="image/webp">
  <source srcset="image.jpg" type="image/jpeg">
  <img src="image.jpg" alt="Чертёж">
</picture>
```

### **2. Сохраняйте оригиналы!**
Всегда храните **исходные DWG/PNG** — WebP это финальный формат для веба.

При конвертации **сохраняйте EXIF данные** (автор, описание) если нужно.

И второе замечание:
Цитата от тебя:
"Не хватает фраз типа:
- «Здесь возникает интересный момент»"/
Нет, вот как раз бессмысленных и пустых по смыслу речевых оборотов и устойчивых выражений не нужно. Стиль текста должен быть литературным, но в "хорошем" смысле этого слова. Не нужны слова просто ради красивых оборотов. Каждое слово должно нести полезную информацию. Но в целом, текст не должен быть через чур академическим, сухим, просто перечислением фактов и тезисов.


Напиши еще раз статью на тему: "Почему рассада вытягивается даже при подсветке". Но уже с учетом всего выше сказанного. 
Задача, не потерять в информативности, но дополнить текст "человеческим" фактором. Читатель должен чувствовать, что с ним общается живой человек, который хочет ему помочь.
