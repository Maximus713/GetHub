## 🎯 КРИТИЧЕСКИЕ ИНСАЙТЫ ДЛЯ ЧАТОВ:

### **1. 🚨 HTML СТРУКТУРА ВАЖНЕЕ CSS**
- **Проблема:** `.npk-fertilizer-info` был внутри `.npk-fertilizer-row`
- **Урок:** Сначала проверяйте HTML структуру в DevTools! CSS не может вытащить элемент из родительского контейнера
- **Правило:** "Синий внутри красного" = меняем HTML, не CSS

### **2. ⚡ ELEMENTOR ДОБАВЛЯЕТ INLINE-СТИЛИ**
- **Проблема:** `!important` не работал, потому что Elementor добавляет `style="font-size: 20px !important"`
- **Урок:** Если CSS не применяется - проверяйте `style=""` атрибуты в HTML
- **Решение:** Только JavaScript может удалить inline-стили Elementor

### **3. 🎯 CSS УЖЕ РАБОТАЕТ - НЕ ЛОМАТЬ!**
- **Ошибка:** Я пытался "исправить" уже работающий файл
- **Урок:** Этот CSS файл УЖЕ оптимизирован и работает с Elementor
- **Правило:** Делать МИНИМАЛЬНЫЕ изменения, проверенные в 3 этапа

### **4. 📦 ВЫВОДИТЬ ПОЛНЫЕ БЛОКИ**
- **Ошибка:** Я выводил фрагменты, пользователь искал что менять
- **Урок:** Всегда выводить ВЕСЬ блок CSS целиком для замены
- **Правило:** "85 строк - полный блок, готов к замене"

### **5. 🔍 ТЗ В HTML КОММЕНТАРИЯХ**
- **Особенность:** Требования в `<!-- ТЗ п.5.1 -->` комментариях
- **Урок:** Внимательно читать HTML перед изменениями CSS
- **Пример:** ТЗ п.5.1-5.6 уже реализованы в CSS

### **6. 🛡️ JS-ФИКСЫ УКАЗЫВАЮТ НА ПРОБЛЕМЫ**
- **Инсайт:** JS-фиксы в HTML показывают, где Elementor ломает стили
- **Урок:** Переносить JS-фиксы в CSS где возможно
- **Пример:** Фиксы 4-6 уже в CSS, но 1-3 требуют JavaScript

### **7. 🎨 ШРИФТЫ И ЦВЕТА УКАЗАНЫ ТОЧНО**
- **Важно:** Пользователь даёт точные HEX-значения (#FFA000, #2E7D32)
- **Урок:** Соблюдать ТОЧНО указанные значения, не предполагать
- **Пример:** "Тёмно-зелёный" = #2E7D32, не #228B22

### **8. ⏱️ ELEMENTOR ПЕРЕРИСОВЫВАЕТ СТИЛИ**
- **JS-код:** `setTimeout(fixElementorStyles, 100/500/1000)`
- **Инсайт:** Elementor постоянно перебивает стили, нужны таймауты
- **Вывод:** Борьба с Elementor требует терпения и JS
