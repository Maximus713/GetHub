## **🎯 КРИТИЧЕСКИЕ ШАБЛОНЫ (обязательны к использованию):**

### **🔴 ВСЕГДА ИСПОЛЬЗУЙ ЭТИ ШАБЛОНЫ:**
1. **AJAX_JS** + **AJAX_PHP** → для всех AJAX операций
2. **STATE_PHP** → для определения состояния
3. **VALIDATE** → для валидации входящих данных
4. **VALIDATE_SOLUBILITY** → для работы с растворимостью

**Нарушение = неработающий плагин**

### **🟡 РЕКОМЕНДУЕМЫЕ ШАБЛОНЫ:**
1. **STATE_JS** → для мгновенного UX
2. **DEBOUNCE** → для плавного ввода
3. **FALLBACK** → для работы без интернета

**Неиспользование = плохой UX, но плагин работает**

### **🟢 ОПЦИОНАЛЬНЫЕ ШАБЛОНЫ:**
1. **COLOR_INTERPOLATE** → для красивого интерфейса
2. **UI_UPDATE** → для отсутствия морганий

## **🚨 ЧАСТЫЕ ОШИБКИ И КАК ИХ ИЗБЕЖАТЬ:**

| ОШИБКА | ЧТО ПРОИСХОДИТ | КАКОЙ ШАБЛОН ИСПОЛЬЗОВАТЬ |
|--------|---------------|--------------------------|
| Страница перезагружается при AJAX | Используется `FormData` или `URLSearchParams` | **AJAX_JS** + **AJAX_PHP** |
| State определяется в JavaScript | Нарушение архитектуры | **STATE_PHP** (сервер) + **STATE_JS** (UX) |
| Нет мгновенной реакции на ввод | Только серверные запросы | **CALC_LOCAL** + **STATE_JS** |
| Моргание интерфейса | Прямое изменение DOM | **UI_UPDATE** + **UI_SYNC** |
| Множественные запросы | Нет debounce | **DEBOUNCE** |
