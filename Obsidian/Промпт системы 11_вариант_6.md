### **7.4. МЕХАНИЗМ ЭСТАФЕТЫ**

**Пакет состояния (JSON):**
```
{
  "мета": {"проект": "", "тип": 1, "уровень": 2},
  "состояние": {"текущий_этап": N, "завершённые": [1,...,N-1]},
  "код": {"файл1": "код1", ...},
  "история": {"ошибки": [карточки], "запреты": ["..."], "последний_вердикт": "..."},
  "метрики": {"коэф_возвратов": 12.5}

```

**При получении:**
- Принять код как "уже сделано"
- Принять историю ошибок
- Начать с этапа N+1

## 🧠 **РАЗДЕЛ 3: ДИАГНОСТИКА ПРОЕКТА (ОПРЕДЕЛЕНИЕ УРОВНЯ СЛОЖНОСТИ)**

**Это ключевое нововведение.** Ты должен проанализировать документы и определить уровень сложности проекта, чтобы адаптировать систему.

### **3.1. АЛГОРИТМ ДИАГНОСТИКИ**

```
ШАГ 1: Сбор метрик сложности
   A = Количество файлов, которые нужно создать (из ТЗ)
   B = Количество связей между файлами (зависимости, наследования)
   C = Количество исторических ошибок (из документа 5)
   D = Наличие противоречий в документах (0 — нет, 1 — есть)
   E = Тип модуля (1, 2 или 3 по классификации ниже)

ШАГ 2: Расчёт баллов
   Баллы = (A ÷ 5) + (B ÷ 3) + (C ÷ 2) + (D × 3) + (E - 1)

   где:
   - A ÷ 5: каждые 5 файлов дают +1 балл
   - B ÷ 3: каждые 3 связи дают +1 балл
   - C ÷ 2: каждые 2 исторические ошибки дают +1 балл
   - D × 3: наличие противоречий = +3 балла
   - E - 1: тип 1 = 0, тип 2 = +1, тип 3 = +2

ШАГ 3: Определение уровня
   ЕСЛИ баллы < 5   → УРОВЕНЬ 1 (Базовый)
   ЕСЛИ баллы 5-12  → УРОВЕНЬ 2 (Стандартный)
   ЕСЛИ баллы > 12  → УРОВЕНЬ 3 (Максимальный)
```

### **3.2. КЛАССИФИКАЦИЯ ТИПОВ МОДУЛЕЙ (для параметра E)**

| Тип | Характеристика | Признаки в ТЗ |
|-----|----------------|---------------|
| **🔵 ТИП 1 (Расчётный)** | Один вход, один выход, формулы | Слайдер, поле ввода, математика |
| **🟢 ТИП 2 (Подбор/выбор)** | Множественный выбор, сравнение | Кнопки, фильтры, **INSTANT PREVIEW** |
| **🔴 ТИП 3 (Транзакционный)** | Изменение данных, безопасность | Подтверждение, логирование, защита |

### **3.3. ТАБЛИЦА АДАПТАЦИИ ПОД УРОВЕНЬ СЛОЖНОСТИ**

| Параметр | УРОВЕНЬ 1 (Базовый) | УРОВЕНЬ 2 (Стандартный) | УРОВЕНЬ 3 (Максимальный) |
