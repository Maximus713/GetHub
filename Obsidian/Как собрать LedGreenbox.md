### **4. ПОШАГОВАЯ ИНСТРУКЦИЯ С ФОТО**

#### **ШАГ 1: Установите вертикальную стойку**
```
1. Положите основание на ровную поверхность
2. Вставьте вертикальную стойку в трубку основания
3. Зафиксируйте двумя болтами (идут снизу)
[ФОТО: крупно болты фиксации]
```

#### **ШАГ 2: Наденьте центральную крестовину**
```
1. Наденьте крестовину на вертикальную стойку
2. Пока не фиксируйте! Оставьте на нужной высоте
3. Запомните: фиксация через отверстия, а не прижимом
[ФОТО: как крестовина одевается на стойку]
```

#### **ШАГ 3: Установите длинные горизонтальные штанги**
```
1. Проденьте длинные штанги через крестовину
2. Разведите в противоположные стороны
3. При необходимости зафиксируйте болтами (если не будете регулировать)
[ФОТО: вид сверху на крестовину со штангами]
```

#### **ШАГ 4: Закрепите короткие поперечные штанги**
```
1. Возьмите короткую штангу
2. Наденьте на ДВЕ длинные штанги (они будут параллельны)
3. Повторите для всех 3 коротких штанг
4. Распределите равномерно
[ФОТО: как короткая штанга надевается на две длинные]
```

#### **ШАГ 5: Установите светильники**
```
1. Возьмите светильник с подвижным креплением
2. Наденьте крепление на короткую штангу
3. Повторите для всех 6 светильников
4. Разместите по краям штанг
[ФОТО: крепление светильника крупно]
```

#### **ШАГ 6: Настройте положение (регулировка)**
```
• ВЫСОТА: ослабьте болт на крестовине, передвиньте, зафиксируйте в отверстии
• ГЛУБИНА: передвиньте короткие штанги вдоль длинных
• ШИРИНА: передвиньте светильники по коротким штангам
[ГИФКА: показывающая все три вида регулировки]
```

#### **ШАГ 7: Установите светоотражающую пленку**
```
1. Наденьте вторую крестовину (для пленки) на стойку
2. Раздвиньте 4 упорные штанги в стороны
3. Натяните пленку на упоры
4. Закрепите липучками/зажимами (идут в комплекте)
[ФОТО: натянутая пленка со всех сторон]
```
