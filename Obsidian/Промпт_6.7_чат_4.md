ЗАДАЧА 1: ПРОВЕРКА PHP-ФАЙЛОВ  
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  
1.1. Selection_Engine.php:  
• Алгоритм Отиаи: нормализация (normalize_npk()) → минимумы → сумма → ×100  
• Fallback-режим при match < 75%  
• Генерация подсказок: пересечение additives ∩ priority  
• Только вызовы NPK_Database::, 0 прямых SQL  
• Type hints, return types

1.2. AJAX_Handler.php:  
• ТОЛЬКО FormData() (не JSON!)  
• Получение данных: $_POST['crop_id'], $_POST['phase_id']  
• Вызов Selection_Engine::find_matching_fertilizers()  
• wp_send_json_success() / wp_send_json_error()

1.3. Data_Adapter.php:  
• ТОЛЬКО подготовка данных для wp_localize_script()  
• НИКАКОЙ логики расчёта  
• НЕ участвует в AJAX  
• Возвращает get_crops_list(), get_phases_list(), get_fertilizers()

1.4. Shortcode.php:  
• Регистрация в init (не позже!)  
• Всегда wp_enqueue_script() без условий  
• HTML-разметка без формул

ЗАДАЧА 2: ПРОВЕРКА JAVASCRIPT-ФАЙЛОВ  
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  
2.1. AJAX:  
• 0 результатов поиска "URLSearchParams"  
• 0 результатов "application/x-www-form-urlencoded"  
• ТОЛЬКО FormData()  
• ❌ НЕ добавлять Content-Type

2.2. UI обновления:  
• ВСЕ DOM-изменения внутри requestAnimationFrame()  
• 0 статических стилей (element.style.color = "#fff")  
• Только динамические значения (width: ${percentage}%)

2.3. Instant Preview:  
• Предзагрузка данных из window.NPK_Selector_Data  
• Алгоритм Отиаи для preview (упрощённый)  
• Замена preview финальными данными с сервера

ЗАДАЧА 3: ПРОВЕРКА CSS-ФАЙЛОВ  
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  
3.1. Централизация стилей:  
• ВСЕ статические стили ТОЛЬКО в selector.css  
• 0 инлайн-стилей style="" в HTML/шаблонах  
• 0 статических стилей в JS

3.2. Селекторы:  
• ВСЕ с префиксом .npk- (нет глобальных!)  
• Нет дублирования стилей

3.3. Специфика Модуля 2:  
• Цвета прогресс-баров: зелёный (#28a745) ≥85%, оранжевый (#FFD700) 75-84%, серый (#6c757d) <75%  
• Адаптивная таблица (4 колонки)  
• Кнопки культур/фаз в ряд, равной ширины
