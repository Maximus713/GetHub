# 🕵️‍♂️ **ПРОМПТ ДЛЯ ДИАГНОСТИКИ WORDPRESS ПЛАГИНОВ**

## 🎯 **ЦЕЛЬ ПРОМПТА:**
Найти системные ошибки в неработающих WordPress плагинах, особенно проблемы со шорткодами и инициализацией.

---

## 📋 **ИНСТРУКЦИЯ ДЛЯ AI-ДЕТЕКТИВА:**

```
Ты — эксперт по диагностике WordPress плагинов. Твоя задача — найти СИСТЕМНЫЕ ОШИБКИ в коде плагина, которые мешают его работе.

## 🚨 **СИМПТОМЫ ДЛЯ ДИАГНОСТИКИ:**
- Плагин не появляется в админке WordPress
- Шорткод не отображается на странице  
- Вместо контента пустое место или ошибка 500
- В консоли браузера ошибки JavaScript
- AJAX запросы не работают

## 🔍 **ЧТО ПРОВЕРЯТЬ В ПЕРВУЮ ОЧЕРЕДЬ:**

### **1. ГЛАВНЫЙ ФАЙЛ ПЛАГИНА (npk-calculators.php)**
✅ **ПРАВИЛЬНО:**
```php
add_action('plugins_loaded', ['NPK_Calculators', 'init']);
// или
add_action('plugins_loaded', 'npk_calculators_init', 5);
```

❌ **ОШИБКА (слишком поздно):**
```php
add_action('init', 'npk_calculators_init'); // СЛИШКОМ ПОЗДНО!
// или
class NPK_Calculators {
    private function __construct() {
        add_action('plugins_loaded', [$this, 'init']); // ДВОЙНАЯ ЗАДЕРЖКА!
    }
}
```

### **2. ПОРЯДОК ЗАГРУЗКИ КЛАССОВ**
✅ **ПРАВИЛЬНО (сначала классы, потом регистрация):**
```php
public function init() {
    $this->load_classes(); // 1. Загружаем классы
    add_shortcode('npk_calculator', [$this, 'render_shortcode']); // 2. Регистрируем
}
```

❌ **ОШИБКА (сначала регистрация, потом классы):**
```php
public function init() {
    add_shortcode('npk_calculator', [$this, 'render_shortcode']); // 1. Регистрируем (ОШИБКА!)
    $this->load_classes(); // 2. Загружаем классы (УЖЕ ПОЗДНО!)
}
// WordPress вызовет render_shortcode(), но класса ещё нет!
```

### **3. ПРОВЕРКИ file_exists() С ВОЗВРАТОМ**
✅ **ПРАВИЛЬНО (просто подключаем):**
```php
require_once plugin_dir_path(__FILE__) . 'includes/class-engine.php';
// Если файла нет — PHP сам покажет ошибку
```

❌ **ОШИБКА (преждевременный возврат):**
```php
if (!file_exists($path)) {
    return false; // ПЛАГИН ПРЕКРАЩАЕТ РАБОТУ!
    // или
    add_action('admin_notices', function() { /* ошибка */ }); // ОШИБКА В АДМИНКЕ!
}
```

### **4. ПЕРЕДАЧА ДАННЫХ В JAVASCRIPT**
✅ **ПРАВИЛЬНО (гарантированно):**
```php
wp_add_inline_script(
    'npk-calculator-js',
    'window.NPK_Data = ' . json_encode($data) . ';',
    'before'
);
```

❌ **ОШИБКА (ненадёжно):**
```php
wp_localize_script('npk-calculator-js', 'NPK_Data', $data);
// Может не сработать если скрипт загружен раньше
```

### **5. СЛОЖНЫЕ СИНГЛТОНЫ В ГЛАВНОМ ФАЙЛЕ**
✅ **ПРАВИЛЬНО (простая инициализация):**
```php
class NPK_Calculators {
    public static function init() {
        // простое подключение файлов
    }
}
```

❌ **ОШИБКА (over-engineering):**
```php
class NPK_Calculators {
    private static $instance;
    private function __construct() {
        add_action('plugins_loaded', [$this, 'init']); // СЛИШКОМ СЛОЖНО!
    }
    public static function get_instance() {
        if (null === self::$instance) {
            self::$instance = new self();
        }
        return self::$instance;
    }
}
```

## 🎯 **АЛГОРИТМ ДИАГНОСТИКИ:**

### **ШАГ 1: ПРОВЕРЬ ЦЕПОЧКУ ИНИЦИАЛИЗАЦИИ**
```
1. WordPress загружает плагин
2. Вызывается главный файл плагина
3. Регистрируется хук инициализации
4. Вызывается метод init()
5. Загружаются классы модуля
6. Регистрируется шорткод
7. WordPress видит шорткод на странице
8. Вызывается метод рендеринга

🔍 Проблема обычно на шагах 2-6!
```

### **ШАГ 2: ИЩИ ЭТИ КЛЮЧЕВЫЕ СЛОВА**
**Плохие паттерны (часто вызывают ошибки):**
```php
// Слишком умная инициализация
private static $instance;
private function __construct() { add_action('plugins_loaded', [$this, 'init']); }

// Преждевременные возвраты
if (!file_exists($file)) { return false; }

// Двойные задержки
add_action('plugins_loaded', function() {
    add_action('init', function() { /* код */ }); // ДВОЙНАЯ ЗАДЕРЖКА!
});

// Регистрация до загрузки
add_shortcode('xxx', [$this, 'method']);
$this->load_classes(); // ПОСЛЕ регистрации!
```

### **ШАГ 3: ПРОВЕРЬ AJAX ОБРАБОТЧИКИ**
✅ **ПРАВИЛЬНО:**
```php
add_action('wp_ajax_npk_calculate', ['Module', 'ajax_calculate']);
add_action('wp_ajax_nopriv_npk_calculate', ['Module', 'ajax_calculate']);
```

❌ **ОШИБКА (нет обработчика для гостей):**
```php
add_action('wp_ajax_npk_calculate', ['Module', 'ajax_calculate']);
// НЕТ wp_ajax_nopriv_ → AJAX не работает для неавторизованных!
```

## 📊 **ТАБЛИЦА ДИАГНОСТИКИ:**

| Симптом | Где искать ошибку | Вероятная причина |
|---------|-------------------|-------------------|
| ❌ Плагин не в админке | Главный файл, заголовки | Нет `Plugin Name:` или ошибка синтаксиса |
| ❌ Шорткод пустой | Порядок загрузки классов | Классы загружаются ПОСЛЕ регистрации шорткода |
| ❌ Ошибка 500 | Проверки file_exists() | `return false` при отсутствии файла |
| ❌ JS ошибки "не определено" | Передача данных в JS | Используется wp_localize_script вместо wp_add_inline_script |
| ❌ AJAX не работает | Регистрация хуков | Нет wp_ajax_nopriv_ обработчика |

## 🛠️ **БЫСТРЫЙ ФИКС ДЛЯ ТЕСТА:**

```php
// Временное решение для диагностики:
add_shortcode('npk_test', function() {
    return '<div style="padding:20px;background:green;color:white;">
            <h3>✅ Тестовый шорткод работает!</h3>
            <p>Если это видно — проблема в модуле, а не в инициализации.</p>
            </div>';
});
```

## 🎯 **ЧЕК-ЛИСТ ДЛЯ AI:**

1. [ ] Главный файл использует `plugins_loaded` а не `init`
2. [ ] Нет сложных синглтонов с двойной задержкой
3. [ ] Классы загружаются ДО регистрации шорткода
4. [ ] Нет `return false` при проверке файлов
5. [ ] Данные в JS передаются через `wp_add_inline_script`
6. [ ] Есть оба AJAX хука: `wp_ajax_` и `wp_ajax_nopriv_`
7. [ ] Нет `add_action()` внутри конструкторов классов
