## **ВАША СТРАТЕГИЯ - ПРАВИЛЬНЫЙ ВЫБОР**

### **Почему это оптимально:**
1. **Функционал > Дизайн** - сначала работает логика, потом красивая обертка
2. **Меньше файлов = меньше контекста** - ChatGPT не переполнится
3. **Быстрее итерации** - меняете мало, видите результат сразу
4. **Проще дебаггинг** - ошибки только в логике, не в стилях

## **КОНКРЕТНЫЙ ПЛАН ДЛЯ ВАС**

### **ШАГ 1: Определите КРИТИЧЕСКИЕ 2-3 файла**

Скорее всего это:
1. **`main.js`** - вся логика расчетов (самый важный!)
2. **`calculator.php`** или **главный файл плагина** - структура и данные
3. **`style.css`** - только базовые стили для работы

### **ШАГ 2: Приоритеты доделки**

#### **1. Сначала ДОРАБОТАТЬ ЛОГИКУ (main.js):**

#### **2. Потом ДОРАБОТАТЬ ДАННЫЕ (calculator.php или главный файл):**

## **КОНКРЕТНЫЙ ПЛАН ИЗ 4 ИТЕРАЦИЙ**

### **Итерация 1: Исправить расчет соответствия удобрений**
**Файлы:** только `main.js`
**Задача:** Заменить косинусную схожесть на РЕАЛЬНЫЙ расчет отклонения
**Критерий успеха:** Диаммофоска для NPK 1:2:2 показывает ~94%, Нитроаммофоска ~60%

### **Итерация 2: Исправить цвета концентрации**
**Файлы:** `main.js` + `style.css` (минимум)
**Задача:** Цвета фона поля/ползунка по зонам безопасности
**Критерий успеха:** При сухой почве и 0.4% - красный, при 0.2% - зеленый

### **Итерация 3: Проверить все формулы**
**Файлы:** `main.js` + PHP файл с данными
**Задача:** Убедиться, что:
- Границы концентраций правильные
- Расчет граммов: `граммы = (концентрация% / 100) × объем_литры × 1000`
- Коэффициенты почвы: сухая×0.3, влажная×1.0

### **Итерация 4: Тест всех сценариев**
**Файлы:** все 2-3 файла
**Задача:** Проверить 3 тестовых сценария из ТЗ
**Критерий успеха:** Все сценарии работают как описано в ТЗ
