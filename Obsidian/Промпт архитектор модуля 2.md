## **🚨 СПЕЦИАЛЬНЫЕ ПРАВИЛА ДЛЯ МОДУЛЯ 2**

### **Архитектурные правила:**
1. ❌ **НЕЛЬЗЯ** использовать имена классов/хуков из Модуля 1
2. ✅ **ОБЯЗАТЕЛЬНО** использовать префиксы: `FS_` (классы), `.npk-fs-` (CSS), `npk_fs_` (хуки)
3. ❌ **НЕЛЬЗЯ** изменять файлы в папке `module-concentration/`
4. ✅ **ОБЯЗАТЕЛЬНО** использовать только публичные методы `NPK_Database`

### **Технические требования:**
1. **Алгоритм Отиаи** должен быть идентичен на клиенте и сервере
2. **Instant Preview** должен работать на предзагруженных данных
3. **Fallback режим** должен показывать 3 лучших варианта при отсутствии ≥75%
4. **Кеширование** результатов должно использовать WordPress Transients

### **Интеграционные требования:**
1. Модуль 2 должен регистрироваться через тот же механизм, что и Модуль 1
2. Оба модуля должны сосуществовать без конфликтов
3. Пользователь должен иметь возможность использовать оба калькулятора на одной странице
