# **ВАШИ ШАГИ ДЛЯ РАБОТЫ С ЧАТОМ ПО ПРОМПТУ**

## **📋 ВАШ АЛГОРИТМ РАБОТЫ:**

### **ШАГ 1: ПОДГОТОВКА ДОКУМЕНТОВ**
```
1. Скопировать ВСЕ необходимые документы в один файл:
   [СЕКЦИЯ 1] Оригинальное ТЗ (полностью)
   [СЕКЦИЯ 2] БД версия 3.2 (полностью)
   [СЕКЦИЯ 3] Дополнение №1 (полностью)
   [СЕКЦИЯ 4] Требование: "Изменить шкалу с 1,5 на 1%"

2. Добавить заголовки:
   "=== ОРИГИНАЛЬНОЕ ТЗ ==="
   "=== БД ВЕРСИЯ 3.2 ==="
   "=== ДОПОЛНЕНИЕ №1 ==="
   "=== НОВЫЕ ТРЕБОВАНИЯ ==="
```

### **ШАГ 2: НАСТРОЙКА ЧАТА**
```
1. Открыть новый чат
2. Вставить промпт "АНТИОШИБОЧНЫЙ АРХИТЕКТОР-КОРРЕКТОР"
3. Отправить
4. Дождаться ответа чата (он запросит документы)
```

### **ШАГ 3: ПЕРЕДАЧА ДОКУМЕНТОВ ЧАТУ**
```
1. Ответить чату: "Вот все документы:"
2. Вставить подготовленный файл с 4 секциями
3. Добавить инструкцию:
   "Работай строго по твоему алгоритму. Начинай с ФАЗЫ 0."
```

### **ШАГ 4: КОНТРОЛЬ ПРОЦЕССА**
```
Чат будет работать так:
1. Он выведет: "Начинаю ФАЗУ 0: Подготовка"
2. Он создаст таблицу изменений
3. Он будет выводить КАЖДОЕ изменение по одному:

   "Изменение #001: Максимальная концентрация 1.5% → 1.0%"
   "ИСТОЧНИК: БД 3.2, комментарий: 'Максимальная концентрация изменена...'"
   "МЕСТО В ТЗ: п.5 'Технический диапазон: 0.05% — 1.5%'"
   "Подтвердите: Заменить '1.5%' на '1.0%'?"

ВАША РОЛЬ:
✅ Ответить: "✅ Да, подтверждаю" или "❌ Нет, ошибка"
```

### **ШАГ 5: РЕАКЦИЯ НА ПРОБЛЕМЫ**
```
Если чат говорит:
1. "Не могу найти источник" → 
   Вы: "Источник в [СЕКЦИЯ X], строка Y: [цитата]"

2. "Непонятно, куда вносить" →
   Вы: "Вноси в [раздел ТЗ], фраза: [цитата]"

3. Чата предлагает сомнительное изменение →
   Вы: "❌ Нет, остановись. Объясни почему ты так думаешь."
```

### **ШАГ 6: ФИНАЛЬНАЯ ПРОВЕРКА**
```
Когда чат закончит:
1. Он выведет "ФИНАЛЬНЫЙ ОТЧЁТ"
2. Проверить:
   - Все ли изменения из БД 3.2 учтены?
   - Все ли из Дополнения №1 учтены?
   - Изменение шкалы 1.5→1.0% учтено?
   - Нет ли противоречий?

3. Если всё верно → 
   Вы: "✅ Принимаю. Создай итоговое Дополнение-2"
```

## **🎯 КЛЮЧЕВЫЕ ФРАЗЫ ДЛЯ ВАС:**

### **ДЛЯ ПОДТВЕРЖДЕНИЯ:**
```
"✅ Да, верно"
"✅ Подтверждаю"
"✅ Применяй это изменение"
```

### **ДЛЯ ОСТАНОВКИ:**
```
"❌ Стоп, ошибка"
"❌ Нет, неправильно"
"❌ Остановись и объясни"
```

### **ДЛЯ УТОЧНЕНИЯ:**
```
"Покажи источник этого изменения"
"Где именно в ТЗ ты это нашёл?"
"Проверь математику этого изменения"
```

## **⏱️ ВРЕМЕННЫЕ ОЖИДАНИЯ:**

```
0-2 мин: Чат запросит документы
2-5 мин: Чат создаст таблицу
5-25 мин: Пошаговые изменения (15-20 шт)
25-30 мин: Верификация
30-35 мин: Финальный отчёт
```

---

## **⚠️ ЧЕГО НЕ ДЕЛАТЬ:**

```
❌ НЕ давать чату работать без вашего подтверждения
❌ НЕ пропускать проверку источников
❌ НЕ разрешать делать несколько изменений за раз
❌ НЕ принимать изменения без математической проверки
```

---

## **✅ ПРИЗНАКИ ПРАВИЛЬНОЙ РАБОТЫ:**

```
ХОРОШО:
- Чат показывает ЦИТАТЫ из документов
- Чат спрашивает подтверждение КАЖДОГО изменения
- Чат делает паузы для проверки
- Чат документирует каждый шаг

ПЛОХО:
- Чат предполагает без цитат
- Чат делает изменения без спроса
- Чат объединяет несколько изменений
- Чат не показывает источники
```
