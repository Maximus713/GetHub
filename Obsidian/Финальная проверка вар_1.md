**Перед любым кодированием проверить:**
1. Беру начальные значения из ТЗ п.6.1

### **ШАГ 2: АРХИТЕКТУРНЫЙ КОНТРОЛЬ (на каждый файл)**
**Перед созданием ЛЮБОГО файла спросить:**

1. Какую РОЛЬ играет в архитектуре? (ТЗ п.3.2)

3. Кого НЕ МОЖЕТ вызывать? (Жёсткие ограничения)
4. Какие ДАННЫЕ получает/возвращает?
5. При переходе к кодированию очередного файла обязательно возвращаться к ТЗ и заново прочитывать (но не выводить на печать) все данные, относящиеся именно к этому файлу.
6. Проверять, есть ли для этого файла ТОЧНЫЕ ТРЕБОВАНИЯ в ТЗ?"


### **ШАГ 3: АНТИ-ОШИБОЧНЫЕ ВОПРОСЫ (перед каждой функцией)**
**Перед написанием КАЖДОЙ функции!**

1. Не дублирует ли логику из другого файла? (Запрет дублирования)
2. Определяет ли state? (Только Calculation_Engine!)
3. Содержит ли бизнес-логику в UI? (Запрещено)
4. Может ли вызвать моргание UI? (Дебаунс, requestAnimationFrame)
5. Использует ли правильный источник данных? (Только npk-database.php)
6. Использует ли классы/CSS из других файлов? Проверены ли они?
7. Передаёт ли данные между слоями? Правильный ли формат?
8. Можно ли протестировать эту функцию изолированно?"


### **ШАГ 4: СЦЕНАРНЫЕ ПРОВЕРКИ (во время кодирования)**

"А ТАК ЛИ ЭТО РАБОТАЕТ В РЕАЛЬНОСТИ?

3. Пользователь вводит 0,04% → корректируется до 0,05%
4. Нет интернета → калькулятор РАБОТАЕТ на локальных расчётах
5. Быстрый ввод → предыдущие AJAX-запросы ОТМЕНЯЮТСЯ"

## **🎯 КЛЮЧЕВЫЕ ПРИНЦИПЫ НА ВСЁ ВРЕМЯ РАБОТЫ:**

### **ПРИНЦИП 1: "ОДИН ФАЙЛ — ОДНА ЗАВЕРШЁННАЯ РАБОТА"**

1. Берём ОДИН файл (по приоритету из ТЗ)
2. Возвращаемся к ТЗ → читаем ВСЕ требования к этому файлу
3. Создаём файл ПОЛНОСТЬЮ готовым (от первой до последней строки)
4. **Проверяем ВСЕ связи с уже созданными файлами**
5. **Если файл зависит от другого → убедиться, что зависимость работоспособна**
6. **Если файл предоставляет данные другому → убедиться, что формат правильный**
7. Выводим файл НЕМЕДЛЕННО после создания и проверки
8. Только потом переходим к следующему файлу
9. При переходе к новому файлу — снова возвращаемся к ТЗ

### **ПРИНЦИП 2: "ОДНА РОЛЬ — ОДИН ФАЙЛ"**

Calculation_Engine = ТОЛЬКО формулы

```
npk-database.php → Calculation_Engine → AJAX_Handler → JavaScript
          ↓
      Data_Adapter → JavaScript
```

```

```

### **ПРИНЦИП 5: "UI НЕ ЗНАЕТ ФОРМУЛ"**
