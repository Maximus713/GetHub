**Ключевой момент!** Шаблоны должны быть **неотъемлемой частью рабочего процесса чата**, а не просто "ещё одним документом".

Вот как это интегрировать:

---

## **🔗 ИНТЕГРАЦИЯ ШАБЛОНОВ В РАБОЧИЙ ПРОЦЕСС**


[[Навигатор по шаблонам]]
### **ШАГ 1: СОЗДАЙТЕ "НАВИГАТОР ПО ШАБЛОНАМ"**

```markdown
# 🗂️ НАВИГАТОР ПО ШАБЛОНАМ КОДА

## КОГДА ИСПОЛЬЗОВАТЬ ШАБЛОНЫ:
**ЕСЛИ ты пишешь...** → **ИСПОЛЬЗУЙ ШАБЛОН...**

### AJAX запросы:
- JavaScript: отправка запроса → **ШАБЛОН 1.1**
- PHP: обработка запроса → **ШАБЛОН 1.2**

### Определение состояния (state):
- PHP: финальный state → **ШАБЛОН 2.1** 
- JavaScript: предварительный state → **ШАБЛОН 2.2**

### Цвета и интерфейс:
- Интерполяция цвета → **ШАБЛОН 3**
- Синхронное обновление → **ШАБЛОН 3 (updateAllColorsSynchronously)**

### Локальные расчёты:
- Масса для UX → **ШАБЛОН 4**
- Концентрация NPK → **ШАБЛОН 4 (calculateNPKConcentration)**

### Управление запросами:
- Debounce и отмена → **ШАБЛОН 5**
- Fallback при ошибках → **ШАБЛОН 5 (handleFallback)**

### Обновление UI:
- Без морганий → **ШАБЛОН 6**
- Синхронные изменения → **ШАБЛОН 6 (updateMultiple)**

## ПРАВИЛА:
1. ⚠️ **КОПИРУЙ ЦЕЛИКОМ** — не меняй логику шаблонов
2. ⚠️ **СОБЛЮДАЙ КОММЕНТАРИИ** — они объясняют требования ТЗ
3. ⚠️ **ПРОВЕРЬ СВЯЗИ** — убедись, что все зависимости существуют
```

**Для PHP файлов (ajax-handler.php):**

**Для PHP файлов (calculation-engine.php):**
[ ] Определение state использует **ШАБЛОН 2.1**

## **ШАГ 5: СОЗДАЙТЕ "КАРТУ ОШИБОК → ШАБЛОНОВ"**

```markdown
# 🚨 КАРТА: ОШИБКА → КАКОЙ ШАБЛОН ИСПРАВЛЯЕТ

## ОШИБКА: "AJAX вызывает перезагрузку страницы"
**ПРИЧИНА:** Используется FormData или URLSearchParams
**РЕШЕНИЕ:** **ШАБЛОН 1.1** (JSON.stringify)

## ОШИБКА: "State определяется в JavaScript"
**ПРИЧИНА:** Бизнес-логика в UI
**РЕШЕНИЕ:** **ШАБЛОН 2.1** (PHP) + **ШАБЛОН 2.2** (JS для UX)

## ОШИБКА: "Моргание интерфейса"
**ПРИЧИНА:** Прямое изменение DOM
**РЕШЕНИЕ:** **ШАБЛОН 6** (requestAnimationFrame)

## ОШИБКА: "Нет мгновенной реакции на ввод"
**ПРИЧИНА:** Нет локальных расчётов
**РЕШЕНИЕ:** **ШАБЛОН 4** (локальные расчёты)

## ОШИБКА: "Цвета обновляются несинхронно"
**ПРИЧИНА:** Разные вызовы анимации
**РЕШЕНИЕ:** **ШАБЛОН 3** (updateAllColorsSynchronously)

## ОШИБКА: "Множественные запросы при быстром вводе"
**ПРИЧИНА:** Нет debounce
**РЕШЕНИЕ:** **ШАБЛОН 5** (RequestManager)
```

## **ПОЧЕМУ ТАКАЯ СТРУКТУРА РАБОТАЕТ:**

1. **Сначала — защита от ошибок** (шаблоны и инструкции)
2. **Потом — требования** (ТЗ)
3. **Во время работы — шпаргалки** (что когда использовать)
4. **При ошибках — карта решений** (ошибка → шаблон)

**Чат работает по алгоритму:**
```
1. Читаю "Что может пойти не так" → знаю риски
2. Читаю "Какие шаблоны есть" → знаю решения  
3. Читаю ТЗ → понимаю требования
4. Создаю файл → использую шаблоны
5. Проверяю → сверяюсь с контрольным списком
```

**Это превращает хаотичное "угадывание" в системный процесс.**
