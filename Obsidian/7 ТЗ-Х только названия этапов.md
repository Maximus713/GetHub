# 🎯 **ПОЛНЫЙ ПЛАН ТЗ-Х ДЛЯ МОДУЛЯ 2**

## **📊 ОБЩАЯ СТРАТЕГИЯ: 7 ЭТАПОВ**

### **ПРИНЦИПЫ:**
1. **Каждый этап — самостоятельная единица**
2. **Зависимости только на предыдущие этапы**
3. **Тестирование после каждого этапа**
4. **Интеграция с Модулем 1 проверяется на каждом этапе**

---

## **🗺️ КАРТА ЭТАПОВ:**

### **ТЗ-0: АРХИТЕКТУРНЫЙ СКЕЛЕТ** ✅ *(в работе)*
**Цель:** Базовая структура файлов, регистрация модуля
**Файлы:** 10 файлов с пустыми классами
**Проверка:** Модуль активируется с Модулем 1 без ошибок

### **ТЗ-1: SELECTION_ENGINE (Алгоритм Отиаи)**
**Цель:** Реализация ядра логики подбора
**Фокус:** Алгоритм нормализации, расчёт соответствия, fallback режим
**Тесты:** Корректность расчётов для тестовых данных

### **ТЗ-2: FS_DATA_ADAPTER (Подготовка данных UI)**
**Цель:** Подготовка данных для интерфейса
**Фокус:** Формирование `window.NPK_FS_Data`, адаптация культур/фаз
**Тесты:** Данные доступны в JavaScript

### **ТЗ-3: FS_AJAX_HANDLER + КЕШИРОВАНИЕ**
**Цель:** Обработка AJAX запросов, кеширование
**Фокус:** Формат `FormData()`, WordPress Transients, инвалидация
**Тесты:** AJAX работает без перезагрузки страницы

### **ТЗ-4: ШОРТКОД И ШАБЛОНЫ**
**Цель:** Интерфейс пользователя
**Фокус:** Шорткод `[npk_fertilizer_selector]`, HTML шаблон
**Тесты:** Калькулятор отображается на странице

### **ТЗ-5: JAVASCRIPT + CSS (Instant Preview)**
**Цель:** Клиентская часть, мгновенный предпросмотр
**Фокус:** Instant Preview <100мс, цветовая индикация, адаптивность
**Тесты:** Мгновенная реакция на выбор культуры/фазы

### **ТЗ-6: ИНТЕГРАЦИЯ И ФИНАЛЬНОЕ ТЕСТИРОВАНИЕ**
**Цель:** Совместная работа модулей, финальные проверки
**Фокус:** Тестирование с Модулем 1, производительность, чек-листы
**Тесты:** Все критерии из ТЗ Модуля 2 выполнены
