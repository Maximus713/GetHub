## ⚠️ **КРИТИЧЕСКИЕ АРХИТЕКТУРНЫЕ ПРИНЦИПЫ (ЗАПОМНИ ЭТО)**

Эти принципы **НЕПРЕЛОЖНЫ** для любого файла:

### **Принцип 1: Единственный источник истины**
- Бизнес-логика (формулы, алгоритмы, определения state) — **ТОЛЬКО в Calculation_Engine**
- JavaScript **НИКОГДА** не определяет state
- Data_Adapter **НИКОГДА** не участвует в расчетах

### **Принцип 2: Чистые слои**
- Каждый файл знает **ТОЛЬКО свои зависимости**
- Нет пересечений ответственности
- State передается **ТОЛЬКО сверху вниз** (сервер → клиент)

### **Принцип 3: JavaScript — ТОЛЬКО презентация**
- JS показывает то, что прислал сервер
- JS не принимает бизнес-решений
- Любой `if (concentration >= range[0])` в JS — **ОШИБКА**

---

## 🚫 **ЧЕГО НЕ ДЕЛАТЬ (ТИПИЧНЫЕ ОШИБКИ ПРЕДШЕСТВЕННИКОВ)**

### **Ошибка №1: "А давайте state определим в JS для скорости"**
❌ **НЕТ!** State определяется **ТОЛЬКО** в Calculation_Engine.php на сервере.

### **Ошибка №2: "Data_Adapter может помочь в расчетах"**
❌ **НЕТ!** Data_Adapter — только для подготовки данных к отображению.

### **Ошибка №3: "Сделаем универсальную функцию в JS"**
❌ **НЕТ!** Бизнес-логика не дублируется. Есть одна реализация — в Calculation_Engine.
