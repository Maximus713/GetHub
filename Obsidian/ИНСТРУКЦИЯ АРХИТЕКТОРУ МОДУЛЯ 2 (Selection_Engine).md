📌 ИНСТРУКЦИЯ АРХИТЕКТОРУ МОДУЛЯ 2 (Selection_Engine):  
────────────────────────────────────

1. Метод доступен с версии БД 4.1:
    
    php
    
    $normalized = NPK_Database::normalize_npk($npk);
    
2. **Не копировать** код метода в Selection_Engine.
    
3. Обновить composer.json / зависимости:
    
    - Требовать `"npk/database": ">=4.1"`
        
4. В коде Selection_Engine использовать **только** публичный API БД.
