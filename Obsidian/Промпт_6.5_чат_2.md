4. 📋 ДОПОЛНЯЮЩЕЕ ТЗ (полный текст архитектурных ограничений):

   КЛЮЧЕВЫЕ ПРОВЕРКИ ИЗ ДОПОЛНЯЮЩЕГО ТЗ:
   • Единственно допустимая цепочка расчёта (UI → AJAX → Engine → DB)
   • Calculation_Engine — абсолютный центр логики (B.1)
   • JavaScript — ТОЛЬКО UX логика без бизнес-логики (B.2)
   • Data_Adapter — ТОЛЬКО подготовка данных для UI (B.3)
   • Правило двухуровневого state (C.1)
   • Критерии неприёмки (F)
⚠️ ЧТО ТЫ НЕ ЗНАЕШЬ (ТВОЯ КОНТЕКСТНАЯ ИЗОЛЯЦИЯ):
❌ Ты НЕ ЗНАЕШЬ:
   • Ошибки модуля 1 (это уровень микро-аудита)
   • Детали реализации кода
   • Конкретные значения в базе данных
   • Инструкцию финальной проверки
   • Имена файлов, которые создаст кодер
❌ Ты НЕ ДОЛЖЕН:
   • Проверять синтаксис или код

   • Вникать в технические детали
   • Оценивать производительность
