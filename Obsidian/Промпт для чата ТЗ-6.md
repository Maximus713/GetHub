**ПРЕДСТАВЬ СЕБЕ ЭТИ СЦЕНАРИИ И СООТНЕСИ С ТЗ-6:**

### **ТЕСТ 1: ФОРМАТЫ AJAX (КРИТИЧЕСКИ)**
```
1. Открываю JavaScript, ищу AJAX запросы
2. Проверяю каждый fetch():
   - Content-Type: application/json? ✅
   - body: JSON.stringify()? ✅
   - НЕТ FormData? ✅
   - НЕТ URLSearchParams? ✅
3. Если найду запрещённое → ОШИБКА
```

### **ТЕСТ 2: ДЕБАУНС 500МС**
```
1. Представляю пользователя быстро печатающего в поле
2. JavaScript должен:
   - Сбрасывать таймер при каждом вводе
   - Отправлять запрос только после 500мс паузы
   - Отменять предыдущие запросы (AbortController)
```

### **ТЕСТ 3: ЦВЕТОВАЯ СИНХРОННОСТЬ**
```
1. Пользователь меняет концентрацию
2. Одновременно должны обновиться:
   - Заливка слайдера (цвет состояния)
   - Метка над слайдером (фон цвета состояния)
   - Поле концентрации (интерполированный фон)
   - Блок состояния в результатах (цвет состояния)
3. Все 4 элемента → обновляются в requestAnimationFrame
```

### **ТЕСТ 4: НАЧАЛЬНОЕ СОСТОЯНИЕ ТЗ п.6.1**
```
1. Страница загружается
2. Калькулятор показывает:

   - Концентрация: 0.30%
   - Объём воды: 10.0 л
   - Первое удобрение выбрано
   - Выполняется расчёт
```
