### **9. КРИТИЧЕСКИЕ ВОПРОСЫ И ОТВЕТЫ:**

#### **ВОПРОС: Почему нельзя одним чатом?**
```
ОТВЕТ: Когнитивная перегрузка. Один чат с 6 документами:
- Теряет фокус
- Путает уровни абстракции
- Делает ошибки из-за информационного шума
```

#### **ВОПРОС: Почему именно 3 чата?**
```
ОТВЕТ: Минимальное разделение для контроля качества:
1 уровень: ЧТО делать (стратегия)
2 уровень: КАК делать и проверить (тактика)  
3 уровень: СДЕЛАТЬ (исполнение)
Меньше: теряем контроль, больше: усложняем коммуникацию
```

#### **ВОПРОС: Что если кодер уходит в середине?**
```
ОТВЕТ: Новый кодер получает текущее задание + контекст задания
НЕ получает: историю, архитектуру, стратегию
МОЖЕТ: выполнить задание (оно самодостаточно)
```

#### **ВОПРОС: Как масштабировать на команду?**
```
ОТВЕТ: Каждый "чат" → реальная роль в команде
Архитектор → lead developer
Координатор → project manager + QA
Кодер → developer(s)
Система остаётся той же
```
