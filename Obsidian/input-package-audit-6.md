7. КЛЮЧЕВЫЕ АРХИТЕКТУРНЫЕ РЕШЕНИЯ
   **Почему алгоритм Отиаи ТОЛЬКО в Selection_Engine:**  
   Это единственный источник истины для соответствия NPK. Любой другой слой, вычисляющий совпадение, создаст рассинхронизацию и сделает систему непредсказуемой.  
   
   **Почему Instant Preview — исключение из правила:**  
   Preview — это UX-эвристика, а не бизнес-логика. Её результат всегда перезаписывается серверным расчётом, не сохраняется и не влияет на смежные системы. ADR-2024-001 явно разрешает такие клиентские оптимизации при маркировке «Preview».  
   
   **Почему Fallback — архитектура, а не баг:**  
   Отсутствие удобрений ≥75% — штатная ситуация. Система не должна показывать пустой экран. 3 лучших варианта с явным флагом «fallback» — это контролируемое поведение, дающее пользователю прозрачность и выбор.

## ПРАВИЛО ДВУХУРОВНЕВОГО STATE
#### C.1. Источники состояния

- **ФИНАЛЬНЫЙ `state`** ВСЕГДА определяется:
    - только в `Calculation_Engine`
    - только на сервере
    - является источником истины для всех итоговых данных

- **ПРЕДВАРИТЕЛЬНЫЙ `state`** может определяться:
    - в JavaScript для мгновенного UX
    - по ТЕМ ЖЕ правилам, что и финальный (п.4.3)
    - заменяется финальным при получении ответа сервера

- UI **ОТОБРАЖАЕТ:**
    - предварительный `state` для мгновенной обратной связи
    - финальный `state` как подтверждённый результат

✅ Определение предварительного `state` в UI — разрешено для UX
❌ Игнорирование финального `state` — ошибка реализации

     * ВСПОМОГАТЕЛЬНЫЕ МЕТОДЫ ДЛЯ МОДУЛЯ ПОДБОРА УДОБРЕНИЙ
     * (Добавлены в версии 4.0)

    /**
     * Нормализует вектор NPK (сумма компонентов = 1)
     * Вспомогательный метод для расчёта коэффициента Отиаи
     * 
     * @param array $npk Вектор NPK [N, P, K]
     * @return array Нормализованный вектор
     */
    private static function normalize_npk($npk) {
        if (!is_array($npk) || count($npk) !== 3) {
            return [0, 0, 0];
        }
        
        $sum = array_sum($npk);
        
        // Избегаем деления на ноль
        if ($sum == 0) {
            return [0, 0, 0];
        }
        
        return [
            $npk[0] / $sum,
            $npk[1] / $sum,
            $npk[2] / $sum
        ];
    }

        if (!isset($crops[$crop_id]['phases'][$phase_id])) {
            return false;
        }
        
        $phase_data = $crops[$crop_id]['phases'][$phase_id];
        $crop_data = $crops[$crop_id];
        
        return [
            // Основные данные
            'npk' => $phase_data['npk'],                         // [1.0, 2.0, 1.0]
            'npk_normalized' => self::normalize_npk($phase_data['npk']), // Нормализованный вектор
            'priority' => $phase_data['priority'] ?? [],         // ['P', 'Ca', 'микроэлементы']
            'notes' => $phase_data['notes'] ?? '',
            
            // Метаданные для интерфейса
            'crop_name' => $crop_data['name'],                   // "Томаты"
            'crop_emoji' => $crop_data['emoji'],                 // "🍅"
            'phase_name' => $phase_data['name'],                 // "Цветение и завязь"
            'phase_emoji' => $phase_data['emoji'],               // "🌸"
            
            // Идентификаторы
            'crop_id' => $crop_id,
            'phase_id' => $phase_id
        ];
    }
