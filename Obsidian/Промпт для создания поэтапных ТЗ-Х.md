### **1.3. КРИТИЧЕСКАЯ ПРОВЕРКА НА ПРОТИВОРЕЧИЯ**

1. **Начальная концентрация 0.30% для влажного грунта:**
   - Берёшь профиль 'wet' из БД
   - Состояние 'optimal' → range = [0.25, 0.35)
   - Проверяешь: `0.30 ≥ 0.25 = true`, `0.30 < 0.35 = true`
   - Результат: `0.30% ∈ optimal` ✅
   - Если нет → ПРОТИВОРЕЧИЕ, спроси пользователя

2. **water_volume_max = 200:**
   - Проверь: `get_constants()['thresholds']['water_volume_max']` = 200
   - Соответствует ТЗ п.1.3
   - Если нет → ПРОТИВОРЕЧИЕ

3. **Имена классов:** Соответствуют ли существующим файлам?

**При противоречии → остановись и спроси пользователя.**
