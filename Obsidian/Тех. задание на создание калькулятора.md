# ОБЩЕЕ ТЕХНИЧЕСКОЕ ЗАДАНИЕ
## WordPress плагин: «Калькулятор рассады LedGreen»

---

## 1. НАЗНАЧЕНИЕ И ЦЕЛЬ

### 1.1 Основная задача
Калькулятор предназначен для **садоводов и огородников**, выращивающих рассаду под световыми системами **LedGreen Box**. 

**Цель**: помочь пользователю понять:
- Какая система освещения подходит (малая или большая)
- Когда количество рассады превышает допустимую площадь
- Объяснить логику временного перегруза (избыточная посадка с последующей выбраковкой)

### 1.2 Ключевой принцип
Калькулятор **не продает напрямую**, а **обучает и подсказывает правильное агротехническое решение**.

---

## 2. ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ

### 2.1 Платформа
- WordPress плагин
- Работает через **шорткод** `[ledgreen_calculator]`
- Поддержка **Elementor** (виджет)
- **Не требует** подключения к `functions.php` темы

### 2.2 Архитектура
- Вся логика внутри плагина
- Без AJAX, без базы данных, без сохранения состояний
- Клиентские расчеты на JavaScript
- PHP для шаблонов и конфигурации

## 4. ЛОГИКА РАБОТЫ (КЛЮЧЕВАЯ ЧАСТЬ)

### 4.1 Четыре состояния калькулятора

#### 🟢 СОСТОЯНИЕ 1 — Малая система
**Условие**: `общая площадь ≤ 1.8 м²`

**Визуальные индикаторы**:
- Цвет шкалы: светло-зеленый (`#81c784`)
- Фон текста состояния: светло-зеленый (`#d4edda`)
- Граница блока состояния: зеленый (`#28a745`) слева

**Текст состояния**:
```
Растения помещаются в малую систему.
```

**Логика расчета**:
- 100% шкалы = 1.8 м²
- Процент отображения = `(площадь / 1.8) × 100`

---

#### 🟢🟢 СОСТОЯНИЕ 2 — Требуется большая система
**Условие**: `1.8 < площадь ≤ 2.8 м²`

**Визуальные индикаторы**:
- Цвет шкалы: темно-зеленый (`#2e7d32`)
- Фон текста состояния: зеленый темнее (`#b8d8be`)
- Граница блока состояния: темно-зеленый (`#1e7e34`) слева

**Текст состояния**:
```
Количество растений превышает площадь малой системы. 
Необходима большая система.
```

**Логика расчета**:
- 100% шкалы = 2.8 м²
- Процент отображения = `(площадь / 2.8) × 100`

---

#### 🟡 СОСТОЯНИЕ 3 — Временный перегруз (агротехническая норма)
**Условие**: `2.8 < площадь ≤ 3.08 м²`

**Визуальные индикаторы**:
- Цвет шкалы: желтый (`#fbc02d`)
- Фон текста состояния: светло-желтый (`#fff3cd`)
- Граница блока состояния: желтый (`#ffc107`) слева

**Текст состояния**:
```
Количество растений превышает площадь большой системы.
Для комфортного состояния на поздних этапах роста рассады 
её количество нужно сократить.
```

**Важное пояснение**:
Это НЕ ошибка, а объяснение агротехнической логики:
- Для садоводов нормально сажать рассаду с запасом
- Расчет ведется по растениям, дошедшим до финальной стадии
- Избыточное количество допустимо временно
- По мере роста слабые растения нужно убрать

**Логика расчета**:
- 100% шкалы = 3.08 м²
- Процент отображения = `(площадь / 3.08) × 100`

---

#### 🟠 СОСТОЯНИЕ 4 — Критическое превышение
**Условие**: `площадь > 3.08 м²`

**Визуальные индикаторы**:
- Цвет шкалы: оранжевый (`#f57c00`)
- Фон текста состояния: светло-оранжевый (`#ffe5d0`)
- Граница блока состояния: оранжевый (`#fd7e14`) слева

**Текст состояния**:
```
Превышение площади более чем на 10%. 
Рекомендуется значительно сократить количество растений.
```

**Логика расчета**:
- Шкала показывает 100% (максимум)
- Процент отображения = 100%

---

### 4.2 Критически важная логика изменения состояний

**Требуемое поведение**:
- Все визуальные изменения должны происходить **МГНОВЕННО** при фактическом пересечении числовых границ
- Анимация ширины шкалы должна быть отделена от логики смены состояний

**Алгоритм мгновенного переключения**:
1. **Определение состояния** (на каждом расчете, чистая математика)
2. **Мгновенное визуальное обновление** (при смене состояния):
   - Немедленно меняется цвет шкалы
   - Немедленно меняется фон текста состояния
   - Немедленно меняется текст сообщения
   - Сбрасывается/пересчитывается процент шкалы
3. **Плавная анимация шкалы** к новому значению (анимация НЕ блокирует визуальные изменения)

**Примеры сценариев**:
- Переход с 1.5 м² до 1.9 м² → мгновенное изменение цвета шкалы с светло-зеленого на темно-зеленый
- Переход с 2.5 м² до 2.9 м² → мгновенное изменение цвета шкалы с темно-зеленого на желтый
- Превышение 3.08 м² → мгновенное изменение цвета шкалы с желтого на оранжевый

- **Расположение**: grid с адаптивностью
- **Поведение**: автоматический расчет при изменении значения

#### 3. Блок шкал
Две шкалы одна под другой:

**Верхняя шкала (тонкая, статичная)**:

- Цвет: `#e0e0e0` (фон), `#2e7d32` (заполнение)

**Нижняя шкала (основная, анимируемая)**:
- Высота: 25px (уменьшена на 30% от исходной)

- Закругление: 12px

- **Метки границ**:
  - Метка "Малая система · 1,8 м²" на 58.4% (1.8/3.08×100)
  - Метка "Большая система · 2,8 м²" на 90.9% (2.8/3.08×100)
  - Текст меток: увеличен на 50%
  - Вертикальные отметки размещены непосредственно на шкале

#### 4. Кнопка управления
- Только одна кнопка: **«Сбросить всё»**
- **Нет кнопки** «Рассчитать» - все расчеты автоматические

## 6. ТЕХНИЧЕСКАЯ РЕАЛИЗАЦИЯ

### 6.1 JavaScript логика (main.js)

#### Алгоритм расчета:
```javascript
1. Собрать значения из всех полей ввода
2. Рассчитать общую площадь (сумма count × area_m2)
3. Определить текущее состояние по границам:
   - if area ≤ 1.8 → состояние 1
   - if 1.8 < area ≤ 2.8 → состояние 2
   - if 2.8 < area ≤ 3.08 → состояние 3
   - if area > 3.08 → состояние 4
4. Проверить изменение состояния:
   - if (текущее_состояние !== предыдущее_состояние):
     - МГНОВЕННО обновить цвет шкалы
     - МГНОВЕННО обновить фон и текст состояния
     - Обновить предыдущее_состояние
5. Рассчитать процент для шкалы:
   - Состояние 1: (area / 1.8) × 100
   - Состояние 2: (area / 2.8) × 100
   - Состояния 3-4: (area / 3.08) × 100
6. Плавно анимировать ширину шкалы к новому проценту
7. Обновить числовые значения (площадь, процент)
```

#### Передача данных в JavaScript:
```php
// В ledgreen-plant-calculator.php
wp_localize_script('ledgreen-plant-calculator', 'LedGreenConfig', [
    'plants' => [...],      // Массив растений из config.php
    'systems' => [          // Границы систем
        'small' => 1.8,
        'big'   => 2.8,
        'max'   => 3.08
    ],
    'colors' => [           // Цвета для состояний
        'state1' => '#81c784',
        'state2' => '#2e7d32',
        'state3' => '#fbc02d',
        'state4' => '#f57c00'
    ]
]);
```

### 6.2 CSS требования
- **Адаптивность**: корректная работа на мобильных устройствах
- **Плавные переходы**: для анимации ширины шкалы
- **Четкие состояния**: явное визуальное различие между 4 состояниями
- **Читаемость**: черный текст на светлых фонах должен быть четко виден
- **Совместимость**: работа в основных браузерах (Chrome, Firefox, Safari, Edge)

## 7. ОСОБЫЕ СЦЕНАРИИ И ОГРАНИЧЕНИЯ

- В редакторе/Elementor калькулятор может отображаться упрощенно
- Карточки растений могут быть скрыты в админке
- Функционал расчета в админке не критичен

### 7.2 Ограничения ввода
- Поля ввода: только целые числа ≥ 0
- Максимальное значение: технически не ограничено, но визуализация ограничена 3.08 м²
- Отрицательные значения не допускаются

### 7.3 Граничные случаи
- **Ровно на границе** (1.8 или 2.8 м²) → считается как нижнее состояние
- **Превышение более 3.08 м²** → состояние 4, шкала 100%, оранжевый цвет
- **Сброс значений** → возврат к состоянию 1

Это ТЗ содержит полное описание плагина "Калькулятор рассады LedGreen" и является единственным источником требований для разработки. Все противоречия из предыдущих версий устранены, логика состояний и визуального поведения полностью согласована.

Алгоритм смены цветов
Этап 1. не выбрано ни одного растения. Шкала заполнения площади пустая. Фон за текстом белый. 
Этап 2. Добавлено первое растение. Площадь малой системы начала заполняться. Шкала индикатор заполненности сдвинулась в проаво и стала светло зеленая. Фон за текстом тоже стал светло зеленый.
Этап 3. Заполненная площадь стала больше 1,8 м. кв. Шкала заполнения стала темно-зеленой. Фон за тестом тоже стал чуть темнее.
Этап 4. Заполненная площадь больше 2,8 м. и меньше 2,8+10%. Шкала желтая. Фон за текстом тоже желтый.
Этап 5. Заполненная площадь больше чем 2,8 м.кв. +10%. Шкала оранжевая, фон за текстом тоже оранжевый.
