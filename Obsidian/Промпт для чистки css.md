# 🧹 **ПРОМПТ ДЛЯ ОЧИСТКИ CSS ФАЙЛА КАЛЬКУЛЯТОРА**

## 🎯 **ЦЕЛЬ**
Очистить CSS файл WordPress плагина от:
- Лишних `!important`
- Селекторов для конкретных тем (Elementor, BeTheme)
- Избыточных переопределений
- Костылей и хаков

**Сохранить:** Чистый, семантичный, поддерживаемый CSS.

---

## 📋 **КОНТЕКСТ ПРОЕКТА**

### **ЧТО ИМЕЕМ:**
- **Плагин:** NPK Calculators (калькулятор концентрации удобрений)
- **Файл:** `calculator.css` (стили модуля концентрации)
- **Контекст:** Изолированная шаблонная страница

### **ТЕКУЩИЕ ПРОБЛЕМЫ:**
1. Много `!important` (защита от Elementor)
2. Селекторы для конкретных тем (`.elementor-`, `.mfn-`)
3. Агрессивные сбросы (`all: initial`)
4. Костыли для исправления конфликтов

### **ЖЕЛАЕМЫЙ РЕЗУЛЬТАТ:**
- Чистые CSS правила
- Минимум `!important`
- Семантичные селекторы
- Поддерживаемость

## 🏗️ **ЭТАП 2: ПРИНЦИПЫ ОЧИСТКИ**

### **2.1 ЧТО УДАЛЯТЬ БЕЗУСЛОВНО:**
```
1. Все селекторы с .elementor-
2. Все селекторы с .mfn-, .betheme-
3. Все селекторы с [data-elementor-]
4. Все комментарии про фиксы тем
5. Агрессивные сбросы: `all: initial`
```

### **2.2 ЧТО ПЕРЕПИСЫВАТЬ:**
```
1. !important → оставить только для:
   - CSS-переменных
   - Критических утилит
   - Максимум 5% от всех правил

2. Костыли → переписать на нормальные CSS
   Пример: margin-left: 40px !important;
   Стало: .npk-concentration-group { margin-left: 40px; }

3. Вложенные селекторы → упростить
   Пример: .npk-calc .npk-input .npk-field
   Стало: .npk-input-field
```

### **2.3 ЧТО СОХРАНЯТЬ:**
```
1. Все селекторы с .npk- (основа)
2. Адаптивные медиа-запросы
3. Анимации и transitions
4. CSS-переменные
5. Семантичные комментарии
```

## 🛠️ **ЭТАП 3: ТЕХНИКА ОЧИСТКИ**

### **3.1 ШАБЛОНЫ ПРЕОБРАЗОВАНИЯ:**

**ШАБЛОН 1: Удаление темовых селекторов**
```css
/* БЫЛО (удалить) */
.elementor-section .npk-calculator-container,
[data-elementor-type] .npk-ground-button,
.mfn-wrapper .npk-input-field {
    /* стили */
}

/* СТАЛО (сохранить только .npk- селектор) */
.npk-calculator-container,
.npk-ground-button,
.npk-input-field {
    /* стили */
}
```

**ШАБЛОН 2: Уменьшение !important**
```css
/* БЫЛО (переписать) */
.npk-input-field {
    background: white !important;
    border: 1px solid #ddd !important;
    font-size: 16px !important;
}

/* СТАЛО (оставить только для background) */
.npk-input-field {
    background: white !important; /* Критично для изоляции */
    border: 1px solid #ddd;
    font-size: 16px;
}
```

**ШАБЛОН 3: Упрощение селекторов**
```css
/* БЫЛО (упростить) */
.npk-concentration-calculator .npk-calculator-container .npk-input-fields .npk-input-row .npk-input-group input.npk-input-field

/* СТАЛО */
.npk-input-field
```

### **3.2 ПРИОРИТЕТ ОЧИСТКИ:**
```
ВЫСОКИЙ (сделать в первую очередь):
1. Удалить Elementor/BeTheme селекторы
2. Удалить агрессивные сбросы
3. Удалить комментарии-фиксы

СРЕДНИЙ (оптимизировать):
4. Уменьшить !important до 5%
5. Упростить вложенные селекторы
6. Удалить дубли

НИЗКИЙ (полировка):
7. Реорганизовать структуру
8. Добавить семантичные комментарии
9. Проверить специфичность
```
