## **4. КРИТИЧЕСКИЕ ЭЛЕМЕНТЫ И DATA-АТРИБУТЫ**

### **✅ ОБЯЗАТЕЛЬНЫЕ DATA-АТРИБУТЫ ДЛЯ JS:**

```
data-npk-calculator-id          → Уникальный ID калькулятора
data-npk-ground-type            → Тип грунта на кнопках
data-npk-fertilizer-select      → Select элемент для выбора удобрения
data-npk-fertilizer-npk         → Контейнер для отображения NPK
data-npk-input="water-volume"   → Поле ввода объёма воды
data-npk-input="concentration"  → Поле ввода концентрации
data-npk-color-target           → Элемент для цветовой интерполяции
data-npk-slider                 → Слайдер концентрации
data-npk-slider-track           → Трек слайдера
data-npk-slider-fill            → Заливка слайдера (меняет цвет)
data-npk-state-label            → Метка состояния над слайдером
data-npk-state-name             → Название состояния
data-npk-state-emoji            → Эмодзи состояния
data-npk-result-mass            → Результат: масса удобрения
data-npk-result-concentration   → Результат: концентрация
data-npk-result-state           → Результат: состояние раствора
data-npk-warnings               → Контейнер для предупреждений
data-npk-npk-concentration      → Поле концентрации NPK (только чтение)
```
