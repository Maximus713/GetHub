# 🎯 **ЧЁТКАЯ ИНСТРУКЦИЯ: 7 ШАГОВ**

## **ШАГ 1: СОЗДАЙТЕ НОВЫЙ ЧАТ «АРХИТЕКТОР»**
**Что делать:** Откройте DeepSeek → Новый чат → Вставьте этот текст:

```
Ты — архитектор. Создашь 8 мини-ТЗ для файлов плагина.

ПОРЯДОК:
1. Я дам тебе 3 документа: Основное ТЗ, Архитектуру, Дополнение
2. Ты создашь мини-ТЗ для Calculation_Engine.php
3. Я проверю
4. Ты создашь остальные 7 мини-ТЗ

ТВОЙ ФОРМАТ:
# ФАЙЛ: [имя]
# СЛОЙ: [ядро/транспорт/адаптация/представление]
# НАЗНАЧЕНИЕ: [1 строка]

РАЗРЕШЕНО: [список]
ЗАПРЕЩЕНО: [список]
МЕТОДЫ: [сигнатуры]
ВОЗВРАТ: [структура массива]

Готов? Жду документы.
```

## **ШАГ 2: ОТПРАВЬТЕ ДОКУМЕНТЫ**
**Что делать:** В том же чате отправьте одним сообщением:
- Основное ТЗ (полная версия)
- Архитектурный манифест
- Дополняющее ТЗ

## **ШАГ 3: ПОЛУЧИТЕ 8 МИНИ-ТЗ**
**Что делать:** Говорите архитектору:
```
Создай мини-ТЗ для Calculation_Engine.php
```
→ Проверьте, что есть разделы «ЗАПРЕЩЕНО» и «State определяется только здесь»
→ Скажите: «Хорошо, теперь следующий файл: AJAX_Handler.php»
→ Повторите для всех 8 файлов

**Сохраните каждое мини-ТЗ в отдельный файл TXT.**

## **ШАГ 4: СОЗДАЙТЕ НОВЫЙ ЧАТ «РАЗРАБОТЧИК»**
**Что делать:** Новый чат DeepSeek → Вставьте этот текст:

```
Ты — разработчик. Пишешь код строго по мини-ТЗ.

ПРАВИЛА:
1. Я дам тебе мини-ТЗ для ОДНОГО файла
2. Ты перечислишь ВСЕ требования из него
3. Я скажу "Продолжай"
4. Только тогда напишешь код
5. Нарушишь — начнём заново

Первый файл: Calculation_Engine.php
Готов? Жду твое подтверждение.
```

## **ШАГ 5: РАЗРАБОТКА КАЖДОГО ФАЙЛА**
**Что делать для КАЖДОГО файла:**

1. **Отправьте мини-ТЗ** (скопируйте из TXT-файла)
2. **Дождитесь,** пока чат перечислит требования
3. **Ответьте:** «Продолжай»
4. **Получите код** → сохраните в файл с правильным именем
5. **Скажите:** «Следующий файл: [имя]. Вот его мини-ТЗ»

**ПОРЯДОК файлов:**
1. `Calculation_Engine.php`
2. `AJAX_Handler.php`
3. `Data_Adapter.php`
4. `Shortcode.php`
5. `concentration-module.php`
6. `calculator.js`
7. `calculator-template.php`
8. `calculator.css`





## **ШАГ 5: КОНТРОЛЬ БЕЗ ЧТЕНИЯ КОДА**

**После каждого файла задавайте один вопрос:**

1. Для **Calculation_Engine.php**: «State определяется только в этом классе?»
    
2. Для **Data_Adapter.php**: «Ты не вызываешь Calculation_Engine?»
    
3. Для **calculator.js**: «В коде нет if (concentration >= range[0])?»
    

**Чату ответит «да» — продолжаем. Ответит «нет» — начинаем файл заново.**



## **ШАГ 6: СОБЕРИТЕ ПЛАГИН**
**Что делать вручную:**
1. Создайте папки:
   ```
   npk-calculators/
   ├── npk-calculators.php
   ├── shared/config/
   │   └── npk-database.php (ваш реальный файл)
   └── module-concentration/
       ├── concentration-module.php
       ├── includes/          ← 4 PHP файла
       ├── assets/            ← JS и CSS
       └── templates/         ← HTML шаблон
   ```
2. Разложите созданные файлы по папкам

## **ШАГ 7: ПРОВЕРКА**
**Что делать:**
1. Установите плагин на тестовый WordPress
2. Добавьте шорткод `[npk_concentration]` на страницу
3. Проверьте:
   - Отображается ли интерфейс?
   - Меняется ли state при движении слайдера?
   - AJAX запросы работают?
