[[Структура страницы FAQ]]

**Отлично! С Elementor Pro + Rank Math SEO вы сможете создать максимально эффективный FAQ раздел.** Вот пошаговая инструкция:

## 🎯 **Создание FAQ страницы с Elementor Pro и Rank Math:**

### **Шаг 1: Создайте новую страницу в WordPress**
1. **WordPress → Страницы → Добавить новую**
2. **Название:** "Часто задаваемые вопросы"
3. **Постоянная ссылка:** `/faq/`
4. **Нажмите:** "Редактировать с Elementor"

---

### **Шаг 2: Создайте структуру в Elementor Pro**

#### **Секция 1: Заголовок**
```
[Виджет "Заголовок"]
- Текст: "Часто задаваемые вопросы"
- HTML тег: H1
- Выравнивание: По центру
```

#### **Секция 2: Описание**
```
[Виджет "Текст"]
- "Здесь собраны ответы на самые популярные вопросы. Не нашли ответ? Свяжитесь с нами!"
```

#### **Секция 3: Навигация (якорные ссылки)**
**Используйте виджет "Tabs" или "Inline Menu":**
```
[Виджет "Меню вкладок"]
- Доставка и оплата → якорь #delivery
- Гарантия и возврат → якорь #warranty  
- Установка → якорь #installation
- Техподдержка → якорь #support
```

#### **Секция 4: FAQ с аккордеонами**
**Вариант A: Один большой аккордеон**
```
[Виджет "Аккордеон"]
  Элемент 1:
    - Заголовок: "Какой срок доставки?"
    - Контент: "Доставка занимает 3-5 рабочих дней..."
    - HTML тег: H3
  
  Элемент 2:
    - Заголовок: "Есть ли самовывоз?"
    - Контент: "Да, доступен самовывоз..."
```

**Вариант B: Несколько аккордеонов по разделам (рекомендую)**
```
[Заголовок H2] 📦 Доставка и оплата
[Аккордеон с 3-4 вопросами по доставке]

[Заголовок H2] 🛡️ Гарантия и возврат  
[Аккордеон с 3-4 вопросами по гарантии]
```

#### **Секция 5: CTA форма**
```
[Виджет "Форма"]
- "Не нашли ответ? Задайте свой вопрос"
- Поля: Имя, Email, Вопрос
- Кнопка: "Отправить вопрос"
```

---

### **Шаг 3: Настройка Rank Math SEO для FAQ**

#### **А) В панели редактирования страницы:**

1. **Прокрутите вниз до панели Rank Math**
2. **Нажмите "Schema"** → **"Добавить новый тип Schema"**
3. **Выберите "FAQ Page"**

#### **Б) Заполните Schema разметку:**
```
Rank Math Schema Editor:
  Тип: FAQPage
  Название: Часто задаваемые вопросы
  Описание: Ответы на популярные вопросы о [ваша тема]

  Вопросы (нажмите "Добавить вопрос"):
    1. Вопрос: Какой срок доставки?
       Ответ: Доставка занимает 3-5 рабочих дней...
    
    2. Вопрос: Есть ли гарантия?
       Ответ: Да, гарантия 2 года на все товары...
    
    [Добавьте ВСЕ вопросы с вашей страницы]
```

#### **В) Альтернативный способ: Автоопределение**
1. **Rank Math → Общие настройки → Schema**
2. **Включите:** "Auto-detect FAQ content"
3. Rank Math **сам найдёт** вопросы в аккордеонах Elementor

---

### **Шаг 4: Оптимизация SEO параметров**

#### **В панели Rank Math заполните:**

**Общие:**
- **SEO Title:** `Часто задаваемые вопросы | [Название сайта]`
- **Meta Description:** `✅ Ответы на популярные вопросы о [тема]. Узнайте о доставке, гарантии, установке. Задайте свой вопрос!`

**Дополнительно:**
- **Focus Keyphrase:** `часто задаваемые вопросы`, `FAQ`
- **Добавьте синонимы:** `вопросы и ответы`, `популярные вопросы`

**Социальные сети:**
- **Facebook/OG Image:** Загрузите специальную картинку для FAQ
- **Описание:** Кратко, с эмоджи

## 🔧 **Продвинутые техники Elementor Pro:**

### **1. Динамический FAQ для разных товаров:**
```yaml
1. Создайте Custom Field "faq_questions"
2. В Elementor: Динамический контент → Custom Field
3. Разные товары → разные FAQ
```

### **2. Popup с быстрыми FAQ:**
```yaml
1. Elementor → Шаблоны → Popup
2. Триггер: Наведение на иконку "?"
3. Содержимое: 3-4 самых частых вопроса
4. Использовать: На страницах товаров
```

### **3. Search FAQ Widget:**
```yaml
1. Виджет "Search" → "Ajax Search"
2. Ограничить поиск: Только страница FAQ
3. Результаты в реальном времени
```

## 📊 **SEO-проверки после создания:**

### **1. Проверка Schema разметки:**
- **Google Rich Results Test:** https://search.google.com/test/rich-results
- **Schema Markup Validator:** https://validator.schema.org/

### **2. Проверка в Google Search Console:**
1. **URL Inspection:** Введите `/faq/`
2. **Проверьте:** "Улучшения" → "FAQ"
3. **Запросите индексацию**

### **3. Внутренние ссылки:**
- Добавьте ссылку на FAQ в **главное меню**
- В **футер** сайта
- В **виджете "Полезные ссылки"**
- В **карточках товаров** ("Частые вопросы")

## 💡 **Советы для максимального SEO-эффекта:**

### **С Rank Math:**
1. **Включите** модуль "Local SEO" если есть офлайн-точки
2. **Добавьте** Breadcrumbs на страницу FAQ
3. **Создайте** sitemap.xml с приоритетом для FAQ

### **С Elementor:**
1. **Включите** lazy loading для изображений
2. **Оптимизируйте** скорость загрузки (не более 3 сек)
3. **Протестируйте** на мобильных устройствах
