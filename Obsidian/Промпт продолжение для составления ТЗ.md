# ПРОМПТ ДЛЯ СОЗДАНИЯ ТЕХНИЧЕСКОГО ЗАДАНИЯ КАЛЬКУЛЯТОРА

## КОНТЕКСТ ПРОЕКТА
Ты — технический писатель/аналитик, которому поручено создать полное техническое задание для «Калькулятора №1: Подбор готового удобрения по составу NPK». Это первый из трех взаимосвязанных калькуляторов для садоводов-любителей.

**Важная концепция:** У каждого калькулятора СТРОГО своя функция без дублирования:
1. **Калькулятор №1** (этот) — подбор готового удобрения по соответствию NPK
2. **Калькулятор №2** — расчет дозировок и приготовления растворов
3. **Калькулятор №3** — составление комбинированных смесей из простых удобрений

## ОСНОВНЫЕ ТРЕБОВАНИЯ

### 1. ЦЕЛЬ СИСТЕМЫ
Инструмент получает на вход **культуру** и **фазу роста**, а на выходе показывает:
- Оптимальное соотношение NPK для этих условий
- Список коммерческих удобрений, чей состав максимально соответствует этому соотношению

**Критическое ограничение:** ТОЛЬКО подбор по составу, без расчетов доз, растворов, альтернатив.

### 2. ФУНКЦИОНАЛЬНЫЕ ХАРАКТЕРИСТИКИ

#### Входные данные:
- **Культура:** выбор одной из 5: `["Томаты", "Огурцы", "Перец", "Баклажаны", "Кабачки"]`
- **Фаза роста:** выбор одной из 4: `["Рассада", "Вегетация", "Цветение", "Плодоношение"]`

#### Логика работы:
- Автоматический мгновенный пересчет при изменении выбора (БЕЗ кнопки "Подобрать")
- Результаты обновляются в реальном времени

#### Алгоритм подбора:
1. Для каждой пары [культура, фаза] есть эталонное значение NPK (например, `[10, 15, 30]`)
2. Для каждого удобрения в базе вычисляется процент соответствия его состава эталону
3. Используется **коэффициент Отиаи (Ochiai coefficient)** для сравнения пропорций
4. **Порог отображения:** ≥75% соответствия
5. **Сортировка:** по убыванию процента соответствия

#### Визуализация результатов:
- **Компактный табличный вид** (одна строка = одно удобрение)
- **Три колонки:**
  - Левая: Название + тип удобрения (40% ширины)
  - Центр: Состав NPK крупно (20% ширины)
  - Правая: Слайдер соответствия + процент + подсказка (40% ширины)
- **Слайдеры:** одинаковой длины, выровнены по правому краю, цвет от красного (75%) к зеленому (100%)
- **Подсказки:** короткие (1-2 строки), генерируются автоматически на основе данных

### 3. АРХИТЕКТУРА ДАННЫХ

#### База эталонных потребностей (plant_needs.json):
```json
{
  "Томаты": {
    "Рассада":      {"npk": [15, 15, 10], "priority": ["N", "P", "Ca"]},
    "Вегетация":    {"npk": [20, 10, 20], "priority": ["N", "Mg"]},
    "Цветение":     {"npk": [10, 15, 30], "priority": ["P", "K", "B", "Ca"]},
    "Плодоношение": {"npk": [12, 10, 25], "priority": ["K", "Ca", "Mg"]}
  }
}
```

#### База удобрений (fertilizers.json):
```json
{
  "id": 1,
  "name": "Мастер Агро Цветение",
  "npk": [10, 18, 32],
  "type": "водорастворимое",
  "additives": ["Ca", "B", "Mg", "микроэлементы"],
  "tags": ["для_цветения"]
}
```

### 4. ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ
- **Производительность:** ответ < 0.5 сек
- **Расширяемость:** добавление культур/удобрений через JSON без изменения кода
- **Адаптивность:** desktop-first, но с учетом мобильных устройств
- **Совместимость:** современные браузеры (Chrome 80+, Firefox 75+, Safari 14+)

### 6. НЕФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ
- **Удобство использования:** новичок должен разобраться за 30 секунд
- **Наглядность:** сразу видно, какое удобрение лучше
- **Образовательная ценность:** краткие пояснения "почему это хорошо"
- **Производительность:** работа с базой до 1000 удобрений

### 7. ОГРАНИЧЕНИЯ И ИСКЛЮЧЕНИЯ
- ❌ НЕТ расчета дозировок
- ❌ НЕТ советов "если нет в магазине"
- ❌ НЕТ комбинирования удобрений
- ❌ НЕТ истории выборов
- ❌ НЕТ сравнения нескольких удобрений
- ✅ ТОЛЬКО подбор готового продукта по составу

## **ОБНОВЛЁННЫЕ КРИТЕРИИ ДЛЯ ТЗ ЭТОГО КАЛЬКУЛЯТОРА:**

### **1. ЧЁТКИЕ ГРАНИЦЫ ФУНКЦИОНАЛА**

- Что делают ДРУГИЕ калькуляторы (расчёт растворов, составление смесей)
- Чёткое разделение ответственности

### **2. ИНТЕГРАЦИЯ С СУЩЕСТВУЮЩЕЙ БАЗОЙ**
- Использование уже существующей базы данных (NPK_Database.php)
- Описание, какие поля используются, какие игнорируются
- Формат данных (пропорции, нормированные на азот)

### **3. АЛГОРИТМ ПОДБОРА С ДЕТАЛЯМИ**
- Коэффициент Отиаи для сравнения пропорций
- Порог 75% для отображения
- Учёт приоритетных элементов (priority) для подсказок
- Учёт дополнительных элементов (additives) в удобрениях

### **4. ИНТЕРФЕЙС В РЕАЛЬНОМ ВРЕМЕНИ**
- Автоматический пересчёт при выборе (без кнопок "Подобрать")
- Компактный табличный вид (одна строка = одно удобрение)
- Визуальные слайдеры соответствия

### **5. УМНЫЕ ПОДСКАЗКИ (НО БЕЗ ПЕРЕГРУЗА)**
- Автоматическая генерация на основе priority/additives
- Краткие, понятные формулировки
- Значки для типов подсказок (✓, ⚠️, ℹ️)
