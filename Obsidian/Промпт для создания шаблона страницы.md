**ТЫ — Senior WordPress Architect** с экспертизой в CSS-изоляции и конфликтах с page builders. Твоя задача — создать умную шаблонную страницу, которая решает конкретные проблемы.

---

## 🎯 **ТОЧНАЯ ПОСТАНОВКА ЗАДАЧИ**

### **ПРОБЛЕМА:**
Существующие шаблонные страницы WordPress:
1. **Дублируют CSS-настройки** (нарушают DRY)
2. **Или полностью изолируются** (теряют связь с основными стилями)
3. **Не решают конфликты с Elementor** адекватно

### **ЦЕЛЬ:**
Создать шаблонную страницу, которая:
```
✅ МАКСИМАЛЬНО ИЗОЛИРУЕТ от Elementor (главное требование)
✅ НЕ ДУБЛИРУЕТ CSS (использует основной файл стилей)
✅ СОХРАНЯЕТ НАВИГАЦИЮ (мини-меню или доступ к основному)
✅ ПРОДУКТИВНА В НАСТРОЙКЕ (легко менять через основной CSS)
```

### **НЕДОПУСТИМО:**
- ❌ Копировать CSS из основного файла в шаблон
- ❌ Создавать параллельную систему стилей
- ❌ Забывать про мобильную адаптивность
- ❌ Игнорировать SEO и accessibility

## 🏗️ **ЭТАП 2: АРХИТЕКТУРНЫЕ РЕШЕНИЯ**

### **ПРЕДЛОЖИ НА ВЫБОР:**

#### **ВАРИАНТ A: CSS LAYERS ИЗОЛЯЦИЯ** (современный подход)
```css
/* Используем @layer для контроля специфичности */
@layer reset, theme, components, utilities, elementor-fixes;

@layer elementor-fixes {
    /* Здесь перебиваем только Elementor, не трогая свои стили */
    .npk-page .elementor-widget {
        all: unset !important;
    }
}
```

#### **ВАРИАНТ B: ATTRIBUTE SELECTOR ИЗОЛЯЦИЯ**
```html
<!-- Добавляем data-атрибут для изоляции -->
<div data-page="npk-calculator" data-isolated="true">
    <!-- Контент -->
</div>
```

```css
/* В основном CSS файле: */
[data-isolated="true"] .npk-component {
    /* Стили работают ТОЛЬКО в изолированном контексте */
}
```

#### **ВАРИАНТ C: SHADOW DOM APPROACH** (экспериментальный)
```javascript
// Если нужно максимальная изоляция
const shadow = element.attachShadow({mode: 'open'});
shadow.innerHTML = `<style>/* Изолированные стили */</style>`;
```

## 📝 **ЭТАП 3: РЕАЛИЗАЦИЯ ШАБЛОНА**

### **ТРЕБОВАНИЯ К PHP ШАБЛОНУ:**

#### **1. ИНТЕЛЛЕКТУАЛЬНАЯ ЗАГРУЗКА CSS:**
```php
// НЕ КОПИРУЕМ CSS, а умно подключаем
function npk_enqueue_styles() {
    // Основной CSS темы
    wp_enqueue_style('theme-main', get_stylesheet_uri());
    
    // CSS плагина NPK Calculator
    $npk_css = NPK_PLUGIN_URL . 'assets/css/npk-calculator.css';
    if (file_exists($npk_css)) {
        wp_enqueue_style('npk-calculator', $npk_css);
    }
    
    // ИЗОЛИРУЮЩИЙ CSS (только для Elementor)
    wp_add_inline_style('npk-calculator', '
        /* ТОЛЬКО правила против Elementor */
        .npk-isolated-page .elementor-widget {
            all: unset !important;
        }
    ');
}
```

#### **2. МОДУЛЬНАЯ СТРУКТУРА:**
```php
<?php
/**
 * Template Name: NPK Calculator (Isolated)
 * Description: Изолированная страница, использующая основной CSS
 * CSS Strategy: Main CSS + Elementor Isolation Layer
 */

// 1. Подключаем основной header для навигации
get_header('minimal'); // или кастомный minimal-header.php

// 2. Контейнер с data-атрибутом для изоляции
?>
<div class="npk-page-container" data-page="npk-calculator" data-isolated="true">
    
    <!-- 3. МИНИМАЛЬНОЕ МЕНЮ (берем из основного, но фильтруем) -->
    <?php npk_render_filtered_menu(); ?>
    
    <!-- 4. ОСНОВНОЙ КОНТЕНТ (шорткод плагина) -->
    <main class="npk-main-content">
        <?php echo do_shortcode('[npk_calculator]'); ?>
    </main>
    
    <!-- 5. ФУТЕР (минимальный) -->
    <?php get_footer('minimal'); ?>
</div>

<?php
// 6. INLINE JS для изоляции (если нужно)
npk_add_isolation_script();
```

#### **3. УМНЫЕ ВСПОМОГАТЕЛЬНЫЕ ФУНКЦИИ:**
```php
// functions-npk-template.php
function npk_render_filtered_menu() {
    // Берем основное меню WordPress
    $menu = wp_get_nav_menu_items('primary');
    
    // Фильтруем: оставляем только критические пункты
    $critical_items = ['Главная', 'Блог', 'Контакты'];
    
    foreach ($menu as $item) {
        if (in_array($item->title, $critical_items)) {
            echo '<a href="' . $item->url . '">' . $item->title . '</a>';
        }
    }
}

function npk_add_isolation_script() {
    ?>
    <script>
    // Изоляция через MutationObserver
    if (typeof MutationObserver !== 'undefined') {
        const observer = new MutationObserver((mutations) => {
            mutations.forEach((mutation) => {
                // Удаляем inline-стили Elementor
                if (mutation.type === 'attributes' && 
                    mutation.attributeName === 'style' &&
                    mutation.target.classList.contains('elementor-widget')) {
                    mutation.target.removeAttribute('style');
                }
            });
        });
        
        observer.observe(document.body, {
            attributes: true,
            subtree: true,
            attributeFilter: ['style']
        });
    }
    </script>
    <?php
}
```

/* ===== ИЗОЛЯЦИОННЫЙ СЛОЙ ===== */

[data-page="npk-calculator"] .npk-concentration-calculator {
    /* Переопределения, если нужны */

/* БОРЬБА С ELEMENTOR (избирательно) */
[data-isolated="true"] .elementor-widget .npk-ground-button {

## 🧪 **ЭТАП 5: ТЕСТИРОВОЧНЫЙ ПРОТОКОЛ**

### **ЧАТ ДОЛЖЕН ПРЕДЛОЖИТЬ:**

#### **1. ТЕСТ КОНФЛИКТОВ:**
```javascript
// Скрипт для проверки
const testElementorConflicts = () => {
    const elements = document.querySelectorAll('.npk-concentration-calculator *');
    let conflicts = 0;
    
    elements.forEach(el => {
        if (el.style.cssText && el.style.cssText.includes('elementor')) {
            conflicts++;
            console.warn('Elementor conflict:', el, el.style.cssText);
        }
    });
    
    return conflicts === 0 ? '✅ No conflicts' : `⚠️ ${conflicts} conflicts found`;
};
```

#### **2. ТЕСТ ПРОИЗВОДИТЕЛЬНОСТИ:**
- Замерить FCP (First Contentful Paint)
- Проверить unused CSS (через Coverage в DevTools)
- Убедиться, что нет дублирования правил
