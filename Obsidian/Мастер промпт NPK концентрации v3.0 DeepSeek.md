## 📊 СЛОИ АРХИТЕКТУРЫ (НЕВОЗМОЖНО ИЗМЕНИТЬ)

### Слой 1: Данные (ТОЛЬКО чтение)
- **Файл:** `shared/config/npk-database.php`
- **Содержит:** `get_fertilizers()`, `get_concentration_profiles()`, `get_constants()`
- **Запрещено:** Любая логика, любые изменения

### Слой 2: Чистая логика (ЕДИНСТВЕННЫЙ источник истины)
- **Файл:** `includes/class-calculation-engine.php`
- **Содержит:** ВСЕ формулы, ВСЕ алгоритмы
- **Определяет:** массу, концентрацию, состояние (`state`), предупреждения
- **Может вызывать:** Только методы `NPK_Database::`
- **Не может вызывать:** Data_Adapter, AJAX_Handler, Shortcode, JS

### Слой 3: Транспорт данных
- **Файл:** `includes/class-ajax-handler.php`
- **Задача:** Принять запрос → вызвать `Calculation_Engine::calculate()` → вернуть JSON
- **Не может:** Считать, определять state, генерировать HTML

### Слой 4: Адаптация для UI (НЕ для расчетов)
- **Файл:** `includes/class-data-adapter.php`
- **Задача:** Подготовить данные для `wp_localize_script()`
- **Может:** Применять валидацию ТОЛЬКО для отображения
- **Не может:** Участвовать в расчетах, передавать данные в `Calculation_Engine`

### Слой 5: Представление
- **Файл:** `assets/js/calculator.js` (UI логика)
- **Может:** Отправлять AJAX, менять цвета, обновлять интерфейс
- **НЕ МОЖЕТ (КРИТИЧЕСКОЕ):** 
  - Определять `state`
  - Сравнивать концентрацию с диапазонами `state.range`
  - Содержать логику вида: `if (concentration >= state.range[0])`
- **Правило:** JavaScript ТОЛЬКО отображает `state`, полученный от сервера

## 🧮 ФОРМУЛЫ И РАСЧЕТЫ (ТОЛЬКО В Calculation_Engine)

### Основная формула массы:
```php
масса_удобрения_г = (концентрация_из_ui / 100) × объем_воды_л × 1000 × (100 / solubility_total_из_бд)
```

### Валидация растворимости (ОБЯЗАТЕЛЬНО):
```php
protected function validate_solubility_total($value) {
    if ($value === null || $value === 0) return 100;
    if ($value < 1) return 1;
    if ($value > 100) return 100;
    return (float)$value;
}
```

### Определение состояния (state) — АЛГОРИТМ:
1. Получить `states` из профиля грунта
2. Для всех состояний, кроме последнего: `нижняя_граница ≤ концентрация < верхняя_граница`
3. Для последнего состояния: `нижняя_граница ≤ концентрация ≤ верхняя_граница`
4. Вернуть первое подходящее состояние
5. Если ниже первого — вернуть первое, если выше последнего — вернуть последнее

## 🎨 ИНТЕРФЕЙС (СТРОГАЯ СТРУКТУРА)

### Порядок элементов сверху вниз:
1. **Панель грунта:** [ Сухой ] [ Слабо влажный ] [ Влажный ] ← активен по умолчанию
2. **Пояснительный текст** (блок-заглушка)
3. **Блок удобрения:**
   - Слева: `<select>` (формат: `Название [N-P-K]`, сортировка по `id` ↑)
   - Справа: NPK крупно (формат: `N - P - K`)
4. **Панель ввода:**
   - Слева: "Объём воды" (только поле с кнопками ▲/▼, без слайдера)
   - Справа: "Концентрация" (поле + слайдер)
5. **Слайдер концентрации:**
   - Диапазон: 0.05% — 1.5%, шаг 0.01
   - Заливка слева: цвет `state.color` (сплошной)
   - Метка сверху: `state.name` (цвет = `state.color`)
6. **Блок результатов** (горизонтально):
   - Слева: "Масса удобрения" (окр. до целого, `157 г`)
   - Центр: "Концентрация" (2 знака, `0.30 %`)
   - Справа: "Состояние раствора" (название + эмодзи на фоне `state.color`)

## 🔄 ПОВЕДЕНИЕ UI (ГИБРИДНАЯ ЛОГИКА)

### Начальное состояние при загрузке:
1. Грунт: "Влажный" (профиль `'wet'`)
2. Удобрение: первое в списке (минимальный `id`)
3. Концентрация: 0.30%
4. Объём воды: 10.0 л
5. **Немедленный полный цикл расчёта** (локальный + AJAX)

### При изменении параметра:
1. **Мгновенная реакция:** JS использует последний подтвержденный сервером `state` для обновления UI
2. **Точный расчет:** После окончания ввода → AJAX → `Calculation_Engine` → точные данные

### Интерполяция цвета фона поля концентрации (ТОЛЬКО в JS):
```javascript
// weight от 0 (начало state.range) до 1 (конец state.range)
let weight = (currentConcentration - state.range[0]) / (state.range[1] - state.range[0]);
let r = Math.round(255 + (state_color_r - 255) * weight);
let g = Math.round(255 + (state_color_g - 255) * weight);
let b = Math.round(255 + (state_color_b - 255) * weight);
let backgroundColor = `rgb(${r}, ${g}, ${b})`;
```

## 🚫 КРИТИЧЕСКИЕ ЗАПРЕТЫ (НЕПРИЁМКА)

### Архитектурные запреты:
- ❌ `state` определяется вне `Calculation_Engine`
- ❌ JavaScript содержит логику выбора `state` 
- ❌ `Data_Adapter` участвует в расчетах
- ❌ В системе более одного "источника истины"
- ❌ Логика вида в JS: `if (concentration >= state.range[0]) { ... }`

### Технические запреты:
- ❌ Изменение файла `npk-database.php`
- ❌ Дублирование данных в коде
- ❌ Градиенты или сегментация на слайдере
- ❌ Использование `optimal_min`/`optimal_max` для ограничения ввода
- ❌ Расчет массы без учета `solubility_total`
- ❌ Сохранение состояния (localStorage, cookies)
