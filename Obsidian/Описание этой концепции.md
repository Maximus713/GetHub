## **РЕШЕНИЕ ПАРАДОКСА:**

### **УРОВЕНЬ 1: 100% ГАРАНТИРОВАННЫЕ ИСПРАВЛЕНИЯ (что МОЖНО делать)**

Только то, что **точно** не сломает код:

1. **ДОБАВЛЕНИЕ проверок** (не удаление!):
    
    - Добавить `if (!defined('ABSPATH')) exit;` в начало WordPress файлов
        
    - Добавить `htmlspecialchars()` вокруг вывода
        
    - Добавить `intval()` вокруг чисел в SQL
        
2. **ЗАМЕНА устаревшего на современное** (только если синтаксис идентичен):
    
    - `mysql_query()` → `mysqli_query()` (если параметры те же)
        
    - устаревшие функции WordPress на новые (если сигнатура та же)
        
3. **УДАЛЕНИЕ явного мусора:**
    
    - Закомментированный код, который никогда не используется
        
    - Пустые файлы
        
    - Дублированные файлы
        

### **УРОВЕНЬ 2: ЧЕГО НЕЛЬЗЯ делать НИКОГДА:**

1. **Не удалять рабочий код** (даже если он "плохой")
    
2. **Не менять логику** (только оборачивать в проверки)
    
3. **Не рефакторить** (только точечные минимальные исправления)

## **ПРАВИЛЬНАЯ СИСТЕМА ДЛЯ НЕПРОГРАММИСТОВ:**

### **ПРОМПТ 1: "СКАНЕР БЕЗОПАСНОСТИ"**

Находит только то, что можно **гарантированно исправить**:

- Отсутствие ABSPATH
    
- Прямые echo без экранирования
    
- Прямые SQL конкатенации
    
- Устаревшие функции (только если есть точный аналог)
    

### **ПРОМПТ 2: "МИНИМАЛЬНЫЙ ИСПРАВИТЕЛЬ"**

Применяет **только шаблонные исправления**:

text

Шаблон 1: Добавить ABSPATH
БЫЛО: (начало файла)
СТАЛО: <?php if (!defined('ABSPATH')) exit; ?>

Шаблон 2: Обезвредить echo
БЫЛО: echo $variable;
СТАЛО: echo htmlspecialchars($variable, ENT_QUOTES, 'UTF-8');

Шаблон 3: Обезвредить SQL
БЫЛО: "SELECT ... WHERE id = $id"
СТАЛО: "SELECT ... WHERE id = " . intval($id)

**Ключевое правило:** Если не подходит под шаблон — не трогать.

## **ПРАВИЛЬНЫЙ ВОПРОС, КОТОРЫЙ Я ДОЛЖЕН БЫЛ ЗАДАТЬ:**

**"Какие ошибки можно исправить ШАБЛОННО, не понимая логики кода?"**

Ответ:

1. Отсутствие базовых проверок безопасности (добавить)
    
2. Прямые выводы данных (обернуть в экранирование)
    
3. Прямые SQL (обернуть в intval/floatval)
    
4. Устаревшие функции (заменить, если точный аналог)
    

Всё остальное — требует понимания кода, поэтому **не для автоматической системы для непрограммистов**.
