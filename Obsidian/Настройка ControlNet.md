Отлично, рабочая цепочка собрана! Теперь переходим к **тонкой настройке и оптимизации**. Вот пошаговый план действий:

## 🎯 **Этап 1: Базовое тестирование**

### **Тест 1: Проверка ControlNet**
```
Промпт: "photo"
Strength ControlNet: 0.8
Steps: 20
```
**Цель:** Убедиться, что ControlNet повторяет композицию референса.

### **Тест 2: Проверка промпта**
```
Отключите ControlNet (strength: 0)
Промпт: "tomato seedlings on windowsill"
Steps: 25
```
**Цель:** Проверить, понимает ли модель, что такое рассада.

### **Тест 3: Комбинированный тест**
```
Включите ControlNet (strength: 0.6)
Добавьте полный промпт
Steps: 25, CFG: 7.5
```
**Цель:** Найти баланс между ControlNet и промптом.

## 🛠️ **Этап 2: Калибровка параметров**

### **Настройте KSampler:**
| Параметр | Старт | Оптимум | Тестируйте |
|----------|-------|---------|------------|
| **Steps** | 20 | 25-30 | 15, 20, 25, 30 |
| **CFG Scale** | 7.0 | 7.5-8.5 | 6.0, 7.0, 8.0, 9.0 |
| **Sampler** | Euler a | DPM++ 2M Karras | Euler a, DPM++ 2M, DDIM |
| **Scheduler** | Normal | Karras | Normal, Karras, Exponential |

### **Настройте ControlNet:**
```
strength: [0.3, 0.5, 0.7, 0.9]
start_percent: 0.0 (обычно)
end_percent: 1.0 (обычно)
```

## 🌿 **Этап 3: Оптимизация для растений**

### **Создайте пресет промптов:**
```
positive_preset = """
professional macro photography of {plant} seedlings on {surface},
{lighting} light, {details}, shallow depth of field,
gardening blog photo, realistic, sharp focus
"""

negative_preset = """
blurry, deformed, cartoon, drawing, painting,
artificial, plastic, dark, overexposed, underexposed
"""
```

### **Переменные для промпта:**
```python
plant = ["tomato", "pepper", "cucumber", "flower"]
surface = ["wooden windowsill", "plastic tray", "clay pots"]
lighting = ["morning", "afternoon", "golden hour", "overcast"]
details = ["condensation on glass", "soil texture visible", "water droplets"]
```

## 📊 **Этап 4: Систематическое тестирование**

### **Метод A/B тестирования:**
1. **Генерация сериями по 4 изображения** с разными сидами
2. **Изменяйте один параметр за раз** (только steps, только CFG и т.д.)
3. **Сохраняйте логи:** seed, параметры, результат

### **Пример тестовой таблицы:**
| Seed | ControlNet | Steps | CFG | Промпт | Результат |
|------|------------|-------|-----|--------|-----------|
| 123 | 0.6 | 25 | 7.5 | базовый | ✅ |
| 456 | 0.7 | 25 | 7.5 | базовый | ❌ (переконтроль) |
| 789 | 0.6 | 30 | 8.0 | базовый | ✅ |

## 🔧 **Этап 5: Добавление улучшений**

### **По одному добавляйте:**
1. **LoRA для реализма** (strength: 0.3)
2. **Второй ControlNet** (canny + depth)
3. **HiRes Fix** или **Upscale**

### **Проверка после каждого добавления:**

- Не появились ли артефакты?
- Не упала ли скорость?

## ⚙️ **Этап 7: Оптимизация производительности**

### **Для скорости:**
1. **Используйте --medvram** флаг при запуске
2. **Уменьшите tile size** в Ultimate SD Upscale
3. **Кэшируйте модели** (если ComfyUI поддерживает)

### **Для качества:**
1. **Увеличьте steps** до 30 для финальных работ
2. **Добавьте Refiner** если используете SDXL Base
3. **Используйте HiRes Fix** с denoise 0.3-0.4

## 📋 **Этап 8: Создание пайплайна для блога**

### **Единый процесс:**
```
1. Подготовка референсов (фото подоконников)
2. Генерация depth maps (пакетная обработка)
3. Основная генерация (сериями по 4-8 изображений)
4. Отбор лучших (визуальная оценка)
5. Апскейл и постобработка
6. Сохранение в папки по статьям
```
