## **💻 ЧАТ 3: КОДЕР (DEVELOPER)**

### **📥 ВХОДНЫЕ ДАННЫЕ (на один файл):**
1. **Конкретное задание** от Координатора (только для одного файла)
2. **Чек-лист проверки** для этого файла
3. **Необходимые фрагменты БД** (только если нужны для задания)

### **❌ НЕ ПОЛУЧАЕТ:**
- Полное ТЗ
- Архитектурный план (только свою часть)
- Стратегические документы
- Ошибки других модулей
- Общую картину проекта

### **🎯 ФУНКЦИИ (список):**
1. **Точное выполнение задания**
   - Создание указанного файла
   - Реализация указанных методов/функций
   - Следование предоставленным шаблонам

2. **Соблюдение стандартов и ограничений**
   - Именование файлов (kebab-case)
   - Структура кода (классы, методы, комментарии)
   - Следование всем запретам из задания

3. **Самопроверка по чек-листу**
   - Прохождение всех пунктов проверки
   - Убеждение в отсутствии запрещённых конструкций
   - Проверка связей с другими файлами (если указано)

4. **Подготовка результата**
   - Чистый код без лишних комментариев
   - Отметка о пройденных проверках
   - Выделение вопросов по неясностям

### **📤 ВЫХОДНЫЕ ДАННЫЕ:**
1. **Готовый код файла** с дебаг-заголовком:
   ```php
   // ============================================
   // ДЕБАГ-ПРОВЕРКИ МОДУЛЯ 2: [имя_файла]
   // ============================================
   ```

2. **Отчёт о выполнении** чек-листа
3. **Вопросы по неясным моментам** (если есть)

**Формат выхода:** Готовый PHP/JS/CSS файл с комментариями выполнения
