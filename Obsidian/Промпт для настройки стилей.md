# 🎯 ОПТИМИЗАЦИЯ АРХИТЕКТУРЫ СТИЛЕЙ NPK CALCULATOR**

## 🏗️ **КОНТЕКСТ И ЦЕЛЬ**

**ПРОБЛЕМА:** NPK калькулятор имеет стили, распределённые по нескольким местам, что создает сложности в поддержке и потенциальные конфликты с Elementor.

**ЦЕЛЬ:** Оптимизировать архитектуру стилей для максимальной защиты от Elementor при минимальном риске сломать существующую рабочую систему.

**ПРИНЦИП:** "Усиление без перестройки" - добавляем защиту поверх существующего рабочего кода.

## 📁 **СТРУКТУРА ФАЙЛОВ (СУЩЕСТВУЮЩАЯ)**

### **1. ШАБЛОН СТРАНИЦЫ v9.1** (`page-npk-calculator-ultimate.php`)
- **Назначение:** Изолированная страница с защитой от Elementor
- **Особенность:** Содержит inline CSS с критическими стилями
- **Расположение:** Тема WordPress

### **2. ОСНОВНОЙ CSS КАЛЬКУЛЯТОРА** (`calculator.css`)
- **Путь:** `/wp-content/plugins/npk-calculators/module-concentration/assets/css/calculator.css`
- **Назначение:** Основные стили дизайна калькулятора
- **Объём:** ~610 строк
- **Статус:** Полностью рабочий

### **3. HTML ШАБЛОН КАЛЬКУЛЯТОРА** (`calculator-template.php`)
- **Назначение:** Чистая HTML структура калькулятора
- **Особенность:** Использует data-атрибуты `data-npk-element`
- **Пример:** `<button data-npk-element="ground-button" data-npk-ground-type="dry">`

### **4. SHORTCODE КЛАСС** (`class-shortcode.php`)
- **Назначение:** Вывод калькулятора через `[npk_concentration_calculator]`
- **Особенность:** Регистрирует стили и скрипты

## 🎯 **ЗАДАЧА ОПТИМИЗАЦИИ**

### **ПРОБЛЕМЫ ДЛЯ РЕШЕНИЯ:**

1. **Конфликты с Elementor** - сбрасывает границы кнопок
2. **Дублирование стилей** - защита в шаблоне + основные стили в CSS
3. **iOS zoom на мобильных** - инпуты увеличиваются при фокусе
4. **Сложность поддержки** - стили в разных местах

### **ОГРАНИЧЕНИЯ И РИСКИ:**

- ❌ **Нельзя** переписывать HTML шаблон
- ❌ **Нельзя** удалять существующие рабочие стили  
- ❌ **Нельзя** нарушать работу шаблона v9.1
- ✅ **Можно** добавлять новые стили поверх существующих
- ✅ **Можно** усиливать специфичность селекторов
- ✅ **Можно** добавлять CSS переменные для гибкости

## 🛡️ **СТРАТЕГИЯ "УСИЛЕНИЕ БЕЗ ПЕРЕСТРОЙКИ"**

### **ЭТАП 1: УСИЛЕНИЕ calculator.css (БЕЗОПАСНО)**

**Добавить в конец `calculator.css`:**

```css
/* ==================== CSS УСИЛЕНИЕ v2.0 ==================== */
/* Дополнительная защита от Elementor для любых страниц */

/* CSS ПЕРЕМЕННЫЕ ДЛЯ КРИТИЧЕСКИХ ЗНАЧЕНИЙ */
:root {
    --npk-critical-border-width: 4px;
    --npk-critical-border-style: solid;
    --npk-dry-color: #e6b400;
    --npk-medium-color: #63b3ed;
    --npk-wet-color: #3182ce;
    --npk-input-border: 1px solid #e0d8c9;
}

/* 1. МАКСИМАЛЬНАЯ СПЕЦИФИЧНОСТЬ ПРОТИВ ELEMENTOR */
body #wpwrap .npk-concentration-calculator {
    position: relative !important;
    z-index: 100 !important;
    isolation: isolate !important;
}

body #wpwrap .npk-concentration-calculator * {
    box-sizing: border-box !important;
}

/* 2. ДВОЙНАЯ ЗАЩИТА КНОПОК ГРУНТА (классы + data-атрибуты) */
body .npk-concentration-calculator .npk-ground-buttons 
.npk-ground-button.npk-ground-button-dry,
[data-npk-element="ground-button"].npk-ground-button-dry {
    border-width: var(--npk-critical-border-width) !important;
    border-style: var(--npk-critical-border-style) !important;
    border-color: var(--npk-dry-color) !important;
}

body .npk-concentration-calculator .npk-ground-buttons 
.npk-ground-button.npk-ground-button-medium,
[data-npk-element="ground-button"].npk-ground-button-medium {
    border-width: var(--npk-critical-border-width) !important;
    border-style: var(--npk-critical-border-style) !important;
    border-color: var(--npk-medium-color) !important;
}

body .npk-concentration-calculator .npk-ground-buttons 
.npk-ground-button.npk-ground-button-wet,
[data-npk-element="ground-button"].npk-ground-button-wet {
    border-width: var(--npk-critical-border-width) !important;
    border-style: var(--npk-critical-border-style) !important;
    border-color: var(--npk-wet-color) !important;
}

/* 3. ЗАЩИТА КНОПОК +/- */
body .npk-concentration-calculator .npk-input-with-buttons 
.npk-input-button,
[data-npk-element="input-button"] {
    border: var(--npk-input-border) !important;
    box-sizing: border-box !important;
}

/* 4. ЗАЩИТА ПОЛЕЙ ВВОДА (iOS zoom) */
body .npk-concentration-calculator input[type="number"],
body .npk-concentration-calculator .npk-input-field,
[data-npk-element="input-field"],
[data-npk-element="concentration-input"] {
    font-size: 16px !important;
    -webkit-appearance: none !important;
    -moz-appearance: none !important;
    appearance: none !important;
}

/* 5. ЗАЩИТА SELECT */
body .npk-concentration-calculator .npk-fertilizer-select,
[data-npk-element="fertilizer-select"] {
    border-radius: 8px !important;
    padding: 12px 15px !important;
    appearance: auto !important;
}

/* 6. TOUCH-АДАПТИВНОСТЬ С УСИЛЕНИЕМ */
@media (hover: none) and (pointer: coarse) {
    body .npk-concentration-calculator .npk-ground-button,
    body .npk-concentration-calculator .npk-input-button,
    [data-npk-element="ground-button"],
    [data-npk-element="input-button"] {
        min-height: 44px !important;
        min-width: 44px !important;
    }
}
```
