### **1.3. КРИТИЧЕСКАЯ ПРОВЕРКА ДЛЯ МОДУЛЯ 2**

1. **Преобразование данных для алгоритма Отиаи:**
   - Удобрения в БД: `[16, 16, 16]` (проценты)
   - Культуры в БД: `[1.0, 2.0, 1.0]` (относительные пропорции)
   - Преобразование: `[16, 16, 16] → [1, 1, 1]` (только для удобрений!)
   - Проверь соответствие с функциональным описанием

2. **Порог 75%:**
   - Проверь: `get_constants()['thresholds']['min_match_percentage']` = 75
   - Соответствует функциональному описанию п.3
   - Если нет → ПРОТИВОРЕЧИЕ

3. **Отсутствие конфликтов с Модулем 1:**
   - Проверь префиксы Модуля 1: `.npk-concentration-`, `NPK_Concentration_`, `npk_concentration_`
   - Префиксы Модуля 2 должны быть уникальными: `.npk-fs-`, `FS_`, `npk_fs_`
   - Если совпадают → ПРОТИВОРЕЧИЕ

4. **Наличие методов БД v4.0:**
   - Проверь существование методов: `get_crops_list()`, `get_phases_list()`, `get_crop_phase_requirements()`

## **🗺️ КАРТА ЭТАПОВ МОДУЛЯ 2**

### **ЭТАП 0: АРХИТЕКТУРНЫЙ СКЕЛЕТ МОДУЛЯ 2**
- Все файлы с пустыми интерфейсами в `module-fertilizer-selector/`
- WordPress хуки с префиксами `npk_fs_`
- Регистрация шорткода `[npk_fertilizer_selector]`

### **ЭТАП 1: SELECTION_ENGINE (АЛГОРИТМ ОТИАИ)**
- Класс: `FS_Selection_Engine`
- Методы: `find_matching_fertilizers()`, `calculate_otiai_match()`, `convert_to_proportions()`
- Реализация алгоритма Отиаи с преобразованием форматов
- Фильтрация по порогу 75%, fallback режим

### **ЭТАП 2: FS_DATA_ADAPTER (ПОДГОТОВКА ДАННЫХ)**
- Класс: `FS_Data_Adapter`
- Метод: `get_ui_data()` - подготовка культур, фаз, удобрений
- Использование `NPK_Database::get_crops_list()`, `get_phases_list()`
- Формирование `window.NPK_FS_Data` для JavaScript

### **ЭТАП 3: FS_AJAX_HANDLER + КЕШИРОВАНИЕ**
- Класс: `FS_AJAX_Handler`
- Метод: `handle_calculation()` - обработка выбора культуры/фазы
- Кеширование через WordPress Transients
- **Связь:** Вызывает `FS_Selection_Engine::find_matching_fertilizers()`

### **ЭТАП 4: SHORTCODE + ШАБЛОНЫ МОДУЛЯ 2**
- Класс: `FS_Shortcode`
- HTML: `selector-template.php`
- **Связь:** Использует данные из `FS_Data_Adapter`

### **ЭТАП 5: JAVASCRIPT + CSS МОДУЛЯ 2**
- `selector.js` - Instant Preview, обработка выбора
- `selector.css` - стили с префиксом `.npk-fs-`
- **Связь:** Использует `window.NPK_FS_Data`

### **ЭТАП 6: ИНТЕГРАЦИЯ И ТЕСТИРОВАНИЕ**
- Совместная работа с Модулем 1
- Тестирование отсутствия конфликтов
- Проверка производительности
- Финальная проверка всех функций Модуля 2
