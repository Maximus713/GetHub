### **ПРИМЕР ДЛЯ ТЗ-2 (Calculation_Engine):**

```markdown
# ТЗ-2: Calculation_Engine (ядро логики)

## 1. ЦЕЛЬ
Реализовать ВСЕ формулы и алгоритмы расчёта

## 2. ФАЙЛ
`module-concentration/includes/class-calculation-engine.php`

## 3. ТРЕБОВАНИЯ ИЗ ОСНОВНОГО ТЗ:

### 3.1. Формула расчёта массы (п.4.1)
```
масса_удобрения_г = (концентрация_из_ui / 100) × объем_воды_л × 1000 × (100 / solubility_total_из_бд)
```

### 3.2. Валидация растворимости (п.4.2)
```php
protected function validate_solubility_total($value) {
    if ($value === null || $value === 0) return 100;
    if ($value < 1) return 1;
    if ($value > 100) return 100;
    return (float)$value;
}
```

### 3.3. Алгоритм определения state (п.4.3)
- Возвращает первое состояние, в диапазон которого попадает концентрация
- Для последнего состояния: нижняя_граница ≤ концентрация ≤ верхняя_граница
- Для остальных: нижняя_граница ≤ концентрация < верхняя_граница

### 3.4. Структура возвращаемых данных (п.4.4)
```php
return [
    'fertilizer_mass' => int,
    'concentration'   => float,
    'water_volume'    => float,
    'state' => [
        'id'          => string,
        'name'        => string,
        'color'       => string,
        'emoji'       => string,
        'description' => string,
        'range'       => [float, float]
    ],
    'warnings' => []
];
```

## 4. АРХИТЕКТУРНЫЕ ОГРАНИЧЕНИЯ:

✅ МОЖЕТ:
- Вызывать NPK_Database::get_*() методы
- Использовать validate_solubility_total()
- Определять state

❌ НЕ МОЖЕТ:
- Вызывать другие классы модуля (Data_Adapter, AJAX_Handler)
- Генерировать HTML/JS
- Изменять данные из БД

## 5. ПРОВЕРКИ:
1. Метод calculate() возвращает правильную структуру
2. Формула массы использует растворимость
3. State определяется по алгоритму п.4.3
4. 0.30% для влажного грунта = состояние 'optimal'
```
