# **ТЕХНИЧЕСКОЕ ЗАДАНИЕ**

На разработку плагина для Wordpress с установленным Element pro
## **Калькулятор концентрации раствора удобрений**

> Версия: **финальная, накопительная**  
> Источник справочных данных: `config/npk-database.php` (единый для всех калькуляторов)

---

## **1. Назначение калькулятора**

Калькулятор предназначен для **расчёта массы удобрения (в граммах)** и **оценки допустимости выбранной концентрации раствора** с учётом:

- объёма воды,
- выбранного удобрения,
- **состояния грунта перед подкормкой**,
- агрономически допустимых концентраций из базы данных.

Калькулятор **не просто считает**, а **сигнализирует о рисках** (стресс, ожог корней).

---

## **2. Архитектура и принципы**

### **2.1. Разделение ответственности**

- `npk-database.php`  
    Хранит **ВСЕ справочные данные**:
    
    - профили концентраций,
    - допустимые диапазоны,
    - состояния (`states`),
    - цвета,
    - текстовые описания и предупреждения.
- Логика калькулятора
    
    - читает данные **только из базы**,
    - **ничего не хардкодит**,
    - не придумывает диапазоны и цвета.
        

### **2.2. Ключевой принцип**

> **JS не интерпретирует агрономию. Он только отображает то, что пришло из базы.**

---

## **3. Состояние грунта (обязательный параметр)**

### **3.1. UI**

Три кнопки:

```
[ 🔴 СУХОЙ ]   [ 🟡 СЛАБО ВЛАЖНЫЙ ]   [ 🟢 ВЛАЖНЫЙ ]
```

- Выбор **обязателен**
- По умолчанию: **ВЛАЖНЫЙ**
- При переключении:
    - меняются допустимые диапазоны концентрации,
    - меняются цвета,
    - меняются предупреждения,
    - пересчитывается состояние выбранной концентрации.

---

## **4. Источник данных (обязательное требование)**

Используется профиль концентрации из `npk-database.php`.

### **4.1. Структура профиля**

```php
'ranges' => [
    'min' => float,
    'max' => float,
    'default' => float,
    'states' => [
        [
            'range' => [from, to],
            'label' => string,
            'color' => string,
            'desc'  => string
        ],
        ...
    ],
    'warning' => string|null
]
```

### **4.2. Критически важно**

- **`states` — единственный источник:**
    - логики оценки,
    - цветовых сигналов,
    - текстов.
- **Никаких «Мин / Средняя / Высокая» вне контекста типа грунта.**
    

---

## **5. Блок «Параметры раствора»**

### **5.1. Объём воды**

- Числовое поле с кнопками ↑ ↓
- **Нелинейный шаг изменения:**
    - от 0 до 10 л → шаг **0,5 л**
    - свыше 10 л → шаг **1 л**
- Ввод вручную разрешён
- Минимум: 0,5 л
- Верхний предел — из ТЗ проекта (например, 200 л)
    

---

### **5.2. Концентрация раствора**

#### **5.2.1. Поле ввода**

- Расположено **справа от поля объёма воды**
- Числовое поле + ползунок
- Шаг: **0,01 %**
- Диапазон:
    
    - `min / max` **строго из профиля выбранного грунта**
        

#### **5.2.2. Цветовая индикация**

Цвет **фона поля концентрации**:
- определяется **по текущему состоянию (`state`)**
- берётся из `state.color`
- меняется **от нейтрального к красному**, в зависимости от риска

#### **5.2.3. Ползунок концентрации**

- **Один, основной**
    
- Вторая шкала (без ползунка) — **УДАЛЯЕТСЯ**
- Цвет шкалы:
    - формируется **из `states` текущего профиля**

    - полностью совпадает по логике с фоном поля концентрации
        

#### **5.2.4. Градиент (принцип, не пример!)**

- PHP передаёт:
    
    - нормализованные позиции `startPercent / endPercent` для каждого `state`
        
- JS:
    
    - **не вычисляет проценты самостоятельно**
        
    - только строит `linear-gradient` по данным из базы
        

❗ **Любые статические подписи под шкалой (Мин / Средняя / Высокая) — запрещены**

---

## **6. Блок «Результат»**

### **6.1. Обязательные элементы**

- **Масса удобрения (г)**  
    Формула:
    
    ```
    масса (г) = (концентрация / 100) × объем воды × 1000
    ```
    
- **Выбранная концентрация (%)**
    
    - подсвечена **тем же цветом**, что:
        
        - поле концентрации,
            
        - шкала,
            
        - состояние
            
- **Состояние концентрации**
    
    - текст `label` из `state`
        
    - цвет `state.color`
        
    - tooltip / описание `state.desc`
        

### **6.2. Поле комментариев**

- Отдельный блок
    
- Пока пустой
    
- Должен принимать текст **в будущем**
    
- Логика комментариев **не реализуется сейчас**, но место под неё зарезервировано
    

---

## **7. Поведение при рисках**

### **7.1. Сухой грунт**

- Слайдер **физически ограничен** верхним пределом из базы
    
- Всегда показывается `warning`, если он есть
    
- Текст предупреждения — **строго из базы**
    
- Калькулятор **не запрещает расчёт**, но **визуально подчёркивает риск**
    

---

## **8. Общие требования**

- Все значения, цвета, пороги — **только из `npk-database.php`**
    
- Никаких:
    
    - хардкода,
    - усреднений,
    - «примерных» значений
- Любая новая логика → **сначала изменение базы, потом код**
    

---

## **9. Контрольный чек-лист**

-  Один источник данных (`npk-database.php`)
-  Один ползунок концентрации
-  Нет универсальных подписей под шкалой
-  Цвет поля = цвет шкалы = цвет состояния
-  Шаг воды меняется после 10 л
-  Состояние зависит от типа грунта
-  Все риски читаются из базы
-  Комментарии предусмотрены, но не реализованы
