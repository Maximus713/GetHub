Самые частые проблемы связанные с выращиванием рассады:

Отлично! Классические карточки с проблемами — это действительно самый **понятный и наглядный** формат для вашей аудитории. Давайте создадим этот блок.

---

## 🎯 **БЛОК «ПРОБЛЕМЫ, КОТОРЫЕ МЫ РЕШАЕМ»**

### **Заголовок блока:**
```
ПОЧЕМУ РАССАДА ВЫРАСТАЕТ СЛАБОЙ?
(И КАК LEDGREEN BOX ЭТО ИСПРАВЛЯЕТ)
```

**Или более мягко:**
```
С КАКИМИ ПРОБЛЕМАМИ ВЫ СТАЛКИВАЕТЕСЬ ПРИ ВЫРАЩИВАНИИ РАССАДЫ?
```

---

## 🃏 **4 КАРТОЧКИ С ПРОБЛЕМАМИ:**

### **Карточка 1: НЕРАВНОМЕРНЫЙ СВЕТ**
```
[Иконка: ☀️→🌱↑]

❌ **ПРОБЛЕМА:**
Рассада «тянется» к свету
Растения всегда растут в сторону единственного источника света (окна или лампы). Это делает стебли тонкими и длинными.

✅ **РЕШЕНИЕ LEDGREEN BOX:**
Свет со ВСЕХ сторон одновременно
Наша система создаёт «световой кокон» — растения получают равномерное освещение со всех направлений, поэтому растут КОРЕНАСТЫМИ.
```

### **Карточка 2: НЕХВАТКА МЕСТА**
```
[Иконка: 🪟✖️]

❌ **ПРОБЛЕМА:**
Подоконники заняты, света не хватает
Даже на южном окне весной не хватает света для всех растений. А если окон мало — катастрофа.

✅ **РЕШЕНИЕ LEDGREEN BOX:**
Рассада растёт в ЛЮБОМ месте
Поставьте систему в кладовой, гараже, углу комнаты — хоть в шкафу. Ей не нужен солнечный свет, только розетка.
```

### **Карточка 3: НЕПОСТОЯННЫЙ УХОД**
```
[Иконка: ⏰🤔]

❌ **ПРОБЛЕМА:**
Забываете вовремя включить/выключить свет
Идеальный световой день — 14-16 часов. Кто будет включать лампу в 6 утра и выключать в 22 вечера?

✅ **РЕШЕНИЕ LEDGREEN BOX:**
Автоматический световой день
Подключите к реле-таймеру (за 890 ₽) — система сама включит «рассвет» и выключит «закат» по вашему расписанию.
```

### **Карточка 4: НЕТ КОНТРОЛЯ НАД УСЛОВИЯМИ**
```
[Иконка: 🌡️❓]

❌ **ПРОБЛЕМА:**
Невозможно создать идеальные условия
На подоконнике: сквозняки, перепады температур, сухой воздух от батареи. Растения в стрессе.

✅ **РЕШЕНИЕ LEDGREEN BOX:**
Замкнутая контролируемая среда
Светоотражающий короб создаёт стабильный микроклимат: постоянная температура, влажность, NO сквозняков.
```

```
«Разочаровались, увидев свою вытянутую рассаду?»
```

```
«Этиоляция (вытягивание) как реакция на односторонний свет»
«Недостаток ФАР (фотосинтетически активной радиации)»
«Невозможность создания равномерного PPFD»
```

## 💡 **РЕКОМЕНДАЦИИ:**

1. **Используйте иконки** — визуализируйте каждую проблему
2. **Добавьте фото** — реальные фото вытянутой рассады, заставленных подоконников
3. **Сделайте интерактивным** — при наведении на проблему показывается решение
4. **Тестируйте порядок** — какая проблема самая болезненная для вашей аудитории?

**Какой вариант проблем больше резонирует с вашими будущими клиентами?** 

1. **Базовые (для начинающих):** Места нет, забываю поливать, рассада тонкая
2. **Продвинутые (для опытных):** Неравномерный свет, нет контроля PPFD, фотопериодический стресс
3. **Эмоциональные (для всех):** Разочарование, усталость, зависть к чужой рассаде
