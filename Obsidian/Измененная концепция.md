# **СИСТЕМА "ШАБЛОННЫЙ САНИТАР КОДА"**

## **ФИЛОСОФИЯ:**
**Только шаблонные, 100% гарантированные исправления. Никаких "улучшений", никакого "рефакторинга".**

## **ЧТО МЫ МОЖЕМ ДЕЛАТЬ БЕЗОПАСНО:**

### **✅ КАТЕГОРИЯ 1: ДОБАВЛЕНИЕ ОБЯЗАТЕЛЬНЫХ ПРОВЕРОК**
(Ничего не ломает, только добавляет защиту)

**Шаблон 1: WordPress ABSPATH**
```
БЫЛО: <?php
СТАЛО: <?php
if (!defined('ABSPATH')) exit;
```

**Шаблон 2: Базовая XSS защита**
```
БЫЛО: echo $var;
СТАЛО: echo htmlspecialchars($var, ENT_QUOTES, 'UTF-8');

БЫЛО: <?php echo $var; ?>
СТАЛО: <?php echo htmlspecialchars($var, ENT_QUQUOTES, 'UTF-8'); ?>
```

**Шаблон 3: Базовая SQL защита для чисел**
```
БЫЛО: "WHERE id = $id"
СТАЛО: "WHERE id = " . (int)$id

БЫЛО: "WHERE price = $price"  
СТАЛО: "WHERE price = " . (float)$price
```

### **✅ КАТЕГОРИЯ 2: ЗАМЕНА ТОЧЬ-В-ТОЧЬ УСТАРЕВШЕГО**
(Только если 100% совместимая замена)

**Шаблон 4: Устаревшие PHP функции**
```
mysql_connect() → mysqli_connect() // ТОЛЬКО если параметры те же
ereg() → preg_match() // ТОЛЬКО если синтаксис можно преобразовать по шаблону
```

### **✅ КАТЕГОРИЯ 3: УДАЛЕНИЕ ОПАСНОГО МУСОРА**
(Точно не используется)

**Шаблон 5: Удаление отладочного кода**
```
// УДАЛЯЕМ ВСЕГДА:
var_dump($_POST);
print_r($data);
die();
exit();
error_log(..., ..., ...);
```

**Шаблон 6: Удаление закомментированного кода**
```
// УДАЛЯЕМ если:
// 1. Начинается с // или /* и заканчивается */
// 2. Не содержит TODO, FIXME, HACK
// 3. Длиннее 5 строк
```

## **ЧЕГО НИКОГДА НЕ ДЕЛАЕМ:**

### **❌ НЕ ТРОГАЕМ:**
1. **Логику** (if/else, циклы, алгоритмы)
2. **Архитектуру** (классы, функции, структуру)
3. **Стиль** (отступы, названия переменных)
4. **Дублирование** (даже если явное)
5. **"Можно улучшить"** (всё субъективное)

### **❌ НЕ ДОГАДЫВАЕМСЯ:**
Если не уверены на 100% → пропускаем.
"Лучше пропустить 100 проблем, чем сломать 1 работающую строку."

## **АРХИТЕКТУРА СИСТЕМЫ (2 этапа):**

### **ЭТАП 1: ШАБЛОННЫЙ СКАНЕР**
```
ВХОД: Весь код
ЗАДАЧА: Найти ВСЁ, что подходит под шаблоны выше
ВЫХОД: Список "найдено X по шаблону Y в файле Z"
```

### **ЭТАП 2: ШАБЛОННЫЙ ИСПРАВИТЕЛЬ**
```
ВХОД: Код + список из Этапа 1
ЗАДАЧА: Применить шаблонные исправления
ПРАВИЛО: Если после исправления код не парсится → откат
ВЫХОД: Исправленный код + список изменений
```

## **ПРОМПТ 1: ШАБЛОННЫЙ СКАНЕР**

```markdown
# ШАБЛОННЫЙ СКАНЕР БЕЗОПАСНОСТИ

ТЫ — АВТОМАТИЧЕСКИЙ СКАНЕР. Ищешь ТОЛЬКО то, что можно исправить по жёстким шаблонам.

## ШАБЛОНЫ ПОИСКА:

### 1. WORDPRESS БЕЗ ABSPATH
- Файл начинается с `<?php`
- Нет строки `if (!defined('ABSPATH'))`
- Файл в WordPress проекте (есть wp-includes, wp-content)

### 2. ПРЯМОЙ ECHO БЕЗ ЭКРАНИРОВАНИЯ
- `echo $переменная;` (без функций вокруг)
- `<?php echo $переменная; ?>`
- НЕ: `echo htmlspecialchars(...)`, `echo esc_html(...)`

### 3. SQL С ЧИСЛАМИ БЕЗ ПРИВЕДЕНИЯ ТИПА
- `"WHERE id = $id"` (переменная-число без (int))
- `"WHERE price = $price"` (переменная-число без (float))

### 4. УСТАРЕВШИЕ ФУНКЦИИ (100% замена)
- `mysql_` → `mysqli_` (ТОЛЬКО если сигнатура та же)
- `ereg(` → `preg_match(` (ТОЛЬКО простые шаблоны)

### 5. ОТЛАДОЧНЫЙ КОД
- `var_dump(`
- `print_r(`
- `die();` или `exit();` в середине кода
- `error_log(` (не в try-catch)

## ФОРМАТ ВЫВОДА:

НАЙДЕНО: [КОЛИЧЕСТВО] проблем по шаблонам

1. [ШАБЛОН 1] Отсутствие ABSPATH
   - Файлы: plugin.php, admin-page.php

2. [ШАБЛОН 2] Прямой echo
   - Файл: template.php:15, user-profile.php:42

3. [ШАБЛОН 3] SQL без (int)
   - Файл: database.php:88

СЛЕДУЮЩИЙ ШАГ: "Применить шаблонные исправления"
```

## **КАК ЭТО РАБОТАЕТ НА ПРАКТИКЕ:**

### **ПРИМЕР КОДА ДО:**
```php
<?php
// plugin.php
function show_user($id) {
    $user = get_user($id);
    echo $user['name']; // XSS
    return $user;
}

function get_user($id) {
    global $db;
    $result = $db->query("SELECT * FROM users WHERE id = $id"); // SQLi
    var_dump($result); // Отладочный код
    return $result->fetch_assoc();
}
```

### **СКАНЕР НАЙДЁТ:**
1. Нет ABSPATH (шаблон 1)
2. `echo $user['name'];` без экранирования (шаблон 2)  
3. `"WHERE id = $id"` без (int) (шаблон 3)
4. `var_dump($result);` отладочный код (шаблон 5)

### **ИСПРАВИТЕЛЬ СДЕЛАЕТ:**
```php
<?php
if (!defined('ABSPATH')) exit; // ДОБАВЛЕНО

function show_user($id) {
    $user = get_user($id);
    echo htmlspecialchars($user['name'], ENT_QUOTES, 'UTF-8'); // ЭКРАНИРОВАНО
    return $user;
}

function get_user($id) {
    global $db;
    $result = $db->query("SELECT * FROM users WHERE id = " . (int)$id); // (int) ДОБАВЛЕНО
    return $result->fetch_assoc(); // var_dump УДАЛЁН
}
```

1. **100% безопасно** — только шаблонные замены

3. **Не сломает логику** — не меняем алгоритмы
4. **Предсказуемо** — всегда одинаковый результат
5. **Быстро** — нет глубокого анализа
