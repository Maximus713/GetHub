## **4. ТРЕБОВАНИЯ БЕЗОПАСНОСТИ (НОВЫЕ)**

### **4.1. Обязательная Nonce проверка**

**ДОБАВИТЬ в ТЗ (новый подраздел 7.3.5):**

```php
/**
 * AJAX обработчик ДОЛЖЕН начинаться с проверки Nonce
 */
public static function handle_ajax_request() {
    // 1. NONCE ПРОВЕРКА (ОБЯЗАТЕЛЬНО ПЕРВОЙ СТРОКОЙ)
    if (!isset($_POST['nonce']) || !wp_verify_nonce($_POST['nonce'], 'npk_concentration_calculate')) {
        wp_send_json_error([
            'message' => 'Security check failed',
            'code' => 'invalid_nonce'
        ], 403);
        wp_die();
    }
    
    // 2. ВАЛИДАЦИЯ ПАРАМЕТРОВ
    $fertilizer_id = isset($_POST['fertilizer_id']) ? (int)$_POST['fertilizer_id'] : 0;
    $concentration = isset($_POST['concentration']) ? (float)$_POST['concentration'] : 0.0;
    $water_volume = isset($_POST['water_volume']) ? (float)$_POST['water_volume'] : 0.0;
    $ground_type = isset($_POST['ground_type']) ? sanitize_text_field($_POST['ground_type']) : '';
    
    // 3. ПРОВЕРКА ДАННЫХ
    if ($fertilizer_id <= 0) {
        wp_send_json_error('Invalid fertilizer ID', 400);
    }
    
    if (!in_array($ground_type, ['dry', 'medium', 'wet'])) {
        wp_send_json_error('Invalid ground type', 400);
    }
    
    // ... остальная логика
}
```

### **5.2. Формула расчёта концентрации NPK**

**УТОЧНИТЬ в п.5 и п.6.3:**

```
Формула расчёта концентрации NPK:
NPK_концентрация = общая_концентрация × (npk_sum / 100)

Где npk_sum - сумма NPK из БД (новое поле)
Пример: удобрение 16-16-16 (npk_sum=48) при общей концентрации 0.45%:
NPK_концентрация = 0.45 × (48 / 100) = 0.216%
```
