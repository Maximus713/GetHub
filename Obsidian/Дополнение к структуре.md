# 🔧 Настройка FAQ Schema для страницы FAQ LedGreen Box

_(Schema & Structured Data for WP by Magazine3)_

## 0️⃣ Подготовка (важно)

Перед настройкой убедись:

- Страница FAQ **одна основная** (не дублируется).
    
- Визуально вопросы и ответы **реально присутствуют на странице** (требование Google).
    
- Формулировки вопросов:
    
    - в виде **вопроса**,
        
    - без скрытого текста,
        
    - совпадают по смыслу с тем, что видит пользователь.
        

---

## 1️⃣ Установка и базовая настройка плагина

1. Установи **Schema & Structured Data for WP (Magazine3)**
    
2. Зайди:  
    **Настройки → Structured Data → Settings**
    

Рекомендуемые параметры:

- ✅ Enable Schema Types — **ON**
    
- ❌ Automatically add schema — **OFF**  
    _(мы управляем вручную!)_
    
- ❌ Data Mapping — **OFF** (пока не нужно)
    

Сохрани.

---

## 2️⃣ Создание FAQ Schema для страницы

### Шаг 1. Добавляем новый Schema-тип

Зайди:

> **Structured Data → Schema Types → Add Schema Type**

Выбери:

- **Schema Type:** FAQ
    
- **Display On:**
    
    - `Entire Site` — ❌
        
    - `Specific Pages` — ✅  
        → укажи **страницу FAQ LedGreen Box**
        

---

### Шаг 2. Заполняем FAQ вручную

В блоке **FAQ Items**:

- Вопрос = **заголовок FAQ** (H3 / H4 на странице)
    
- Ответ = **точный текст ответа**, без сокращений
    

⚠️ ВАЖНО:

- **Один вопрос — один ответ**
    
- **Без ссылок, кнопок, HTML**
    
- **Без маркетинговых вставок**
    

Пример:

```
Q: Что такое LedGreen Box и для чего он нужен?
A: LedGreen Box — это система освещения, создающая для рассады равномерную световую среду...
```

---

## 3️⃣ Сколько вопросов добавлять в Schema

### 🔹 Оптимально для Google:

- **8–15 вопросов** на одну страницу в Schema
    
- Остальные вопросы остаются **визуально**, но без Schema
    

📌 Почему:

- Google не любит «простыни» FAQ Schema
    
- 60 вопросов = риск игнора разметки
    

---

## 4️⃣ Как выбрать «главные» вопросы для Schema

Рекомендую разметить:

### ✔️ Обязательно:

- Что это такое
    
- Чем отличается от ламп
    
- Для кого система
    
- Можно ли в квартире
    
- Почему не вытягивается
    
- Экономия электроэнергии
    
- Безопасность
    
- С чего начать
    

📌 Остальные:

- остаются на странице;
    
- участвуют в SEO текстом;
    
- не требуют Schema.
    

---

## 5️⃣ Связка с Elementor (чтобы всё совпадало)

В Elementor:

- Вопрос = **H3**
    
- Ответ = обычный текст
    
- Желательно **аккордеон**, но не обязательно
    

Важно:

- Текст в Elementor **должен совпадать по смыслу** с тем, что в Schema.
    
- Можно:
    
    - сократить ответ в Schema,
        
    - но нельзя добавлять того, чего нет на странице.
        

---

## 6️⃣ Проверка правильности

После сохранения:

1. Открой страницу FAQ
    
2. Перейди в **Rich Results Test (Google)**
    
3. Проверь:
    
    - тип: FAQPage
        
    - ошибки: ❌
        
    - предупреждения: допустимы, но лучше без них
        

---

## 7️⃣ Частые ошибки (не допусти)

❌ Разметить вопросы, которых нет на странице  
❌ Добавить ссылки или кнопки в ответ  
❌ Разметить весь FAQ из 60 вопросов  
❌ Использовать разные формулировки вопроса в тексте и Schema  
❌ Делать несколько FAQ Schema на одной странице

---

## 8️⃣ Рекомендованная финальная схема для тебя

- **Одна страница FAQ**
    
- **60 вопросов визуально**
    
- **10–12 ключевых вопросов в FAQ Schema**
    
- **Ручной контроль через Magazine3**
    
- **Rank Math Free — без конфликтов**
    

---

Если хочешь, следующим шагом можем:

- выбрать **конкретные 10–12 вопросов** из твоего списка для Schema;
    
- или собрать **идеальную структуру страницы FAQ в Elementor** (блоки, порядок, якоря).
