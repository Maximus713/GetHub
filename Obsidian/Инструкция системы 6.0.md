# 📋 **ПОДРОБНАЯ ПОШАГОВАЯ ИНСТРУКЦИЯ: КАК СОЗДАТЬ И ИСПОЛЬЗОВАТЬ СИСТЕМУ ИЗ 6 ЧАТОВ**

## **Этап 0: Подготовка**

### ✅ Что тебе нужно перед стартом:
1. Доступ к 6 отдельным чатам с ИИ (можно в разных окнах браузера)
2. Текстовый файл для копирования промптов
3. Блокнот для записи сообщений между чатами
4. Доступ к сайту с WordPress для тестирования

---

## **Этап 1: Получение промптов (сейчас)**

**Ты находишься ЗДЕСЬ**

1. Я создаю **6 промптов** (Архитектор, Стратегический аудитор, Координатор, Тактический аудитор, Кодер, Операционный аудитор)
2. Каждый промпт будет иметь четкие границы:
```
================================================================================
🔷 ПРОМПТ 1: НАЗВАНИЕ
================================================================================
[текст]
================================================================================
```
3. **НЕ ПРЕРЫВАЙ МЕНЯ**, пока я не создам все 6
4. После 6 промптов будет **ИНСТРУКЦИЯ ПО ЗАПУСКУ** — это сигнал, что можно начинать

---

## **Этап 2: Создание 6 чатов (твои действия)**

### 🔴 **ВАЖНО: Каждый промпт → в отдельный чат!**

| Чат | Роль | Действие |
|-----|------|----------|
| **Чат 1** | Архитектор | Скопировать промпт 1 → создать новый чат → вставить |
| **Чат 2** | Стратегический аудитор | Скопировать промпт 2 → создать новый чат → вставить |
| **Чат 3** | Координатор | Скопировать промпт 3 → создать новый чат → вставить |
| **Чат 4** | Тактический аудитор | Скопировать промпт 4 → создать новый чат → вставить |
| **Чат 5** | Кодер | Скопировать промпт 5 → создать новый чат → вставить |
| **Чат 6** | Операционный аудитор | Скопировать промпт 6 → создать новый чат → вставить |

**Проверь:** У тебя открыто 6 разных окон/вкладок с чатами, в каждом вставлен свой промпт.

---

## **Этап 3: Запуск системы (последовательность сообщений)**

### **ШАГ 3.1: Старт в Чате 1 (Архитектор)**
```
Ты пишешь в Чат 1:
"Начинаем проект Модуль 2. Вот все 6 документов:
[вставь сюда ТЗ, БД, Архитектуру, Ограничения, Ошибки, Проверку]"
```

### **ШАГ 3.2: Чат 1 → Чат 2**
Чат 1 создаст план и скажет тебе:
```
"План готов. Отправь это сообщение в Чат 2 (Стратегический аудитор):
[сообщение для Чата 2]"
```

**Твоя задача:** Скопировать это сообщение и отправить его в Чат 2.

### **ШАГ 3.3: Чат 2 → Чат 3**
Чат 2 проверит план и скажет тебе:
```
"План утвержден. Отправь это сообщение в Чат 3 (Координатор):
[сообщение для Чата 3]"
```

**Твоя задача:** Отправить сообщение в Чат 3.

### **ШАГ 3.4: Цикл "Координатор → Тактический аудитор"**
Теперь начинается цикл по этапам:

```
Чат 3 создает задание → говорит тебе отправить в Чат 4
Чат 4 проверяет задание → говорит отправить обратно в Чат 3 (если ок) или исправить
Когда задание утверждено → Чат 3 говорит отправить в Чат 5
```

### **ШАГ 3.5: Цикл "Кодер → Операционный аудитор"**
```
Чат 5 пишет код → говорит отправить в Чат 6
Чат 6 проверяет код → говорит отправить обратно в Чат 5 (если ошибки) или в Чат 3 (если готово)
Чат 3 отмечает этап выполненным
```

### **ШАГ 3.6: Контроль перехода**
```
Чат 4 (Тактический аудитор) периодически говорит:
"Проверяю этап N... Все ок. Можете переходить к этапу N+1"
БЕЗ этой команды следующий этап НЕ НАЧИНАЕТСЯ!
```

---

## **Этап 4: Схема общения (копируй сообщения!)**

```
ТЫ → [сообщение] → ЧАТ 1
ЧАТ 1 → [ответ] → ТЫ (с указанием "Отправь это в Чат 2")
ТЫ копируешь → [сообщение] → ЧАТ 2
ЧАТ 2 → [ответ] → ТЫ (с указанием "Отправь это в Чат 3")
... и так далее
```

**Ты — единственный мост между чатами!** Чаты НЕ видят друг друга.

---

## **Этап 5: Что писать в каждый чат для старта**

### **Для Чата 1 (Архитектор):**
```
Начинаем проект "Модуль 2: Калькулятор подбора удобрений".

Вот все 6 документов:

1. ТЕХНИЧЕСКОЕ ЗАДАНИЕ:
[вставь текст ТЗ]

2. БАЗА ДАННЫХ:
[вставь код npk-database.php]

3. ЭТАЛОННАЯ АРХИТЕКТУРА:
[вставь текст архитектуры]

4. АРХИТЕКТУРНЫЕ ОГРАНИЧЕНИЯ:
[вставь дополняющее ТЗ]

5. ИСТОРИЧЕСКИЕ ОШИБКИ:
[вставь список ошибок]

6. ИНСТРУКЦИЯ ПРОВЕРКИ:
[вставь инструкцию]

Создай пошаговый план разработки.
```

### **Для других чатов:**
Просто отправляй те сообщения, которые тебе скажут копировать предыдущие чаты.

---

## **Этап 6: Кризис-план (что делать если...)**

### 🟢 **Если чат завис или отвечает не то:**
1. Напиши: "Ты понял свою роль? Повтори кратко, что ты должен делать."
2. Если не помогает → создай новый чат с тем же промптом

### 🟡 **Если нашел ошибку в коде:**
1. Отправь код в Чат 6 (Операционный аудитор) с вопросом "Проверь этот код"
2. Чат 6 укажет на ошибки
3. Отправь замечания в Чат 5 для исправления

### 🔴 **Если система зациклилась:**
1. Напиши в Чат 4 (Тактический аудитор):
```
"Система зациклилась на этапе X. Дай команду на принудительный переход к этапу Y с проверкой всех предыдущих требований"
```

## **Главное правило:**

**Ты НЕ разработчик. Ты — диспетчер.**
Твоя задача: просто копировать сообщения из одного чата и вставлять в другой, строго следуя их инструкциям.

Система сама создаст идеальный код без ошибок.
