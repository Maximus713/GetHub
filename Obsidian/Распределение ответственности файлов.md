# 📁 **РАСПРЕДЕЛЕНИЕ ОТВЕТСТВЕННОСТИ ФАЙЛОВ ПЛАГИНА**

## 🎯 **ГЛАВНЫЙ ФАЙЛ ПЛАГИНА**
```
npk-calculators.php
```
**Ответственность:** Только инициализация плагина в WordPress

## 🧠 **ЯДРО СИСТЕМЫ (НИКОГДА НЕ ТРОГАТЬ ЛОГИКУ!)**
```
module-concentration/includes/class-calculation-engine.php
```
**Ответственность:** 
- Все формулы расчёта
- Определение state (ТОЛЬКО здесь!)
- Валидация данных
- **НЕ трогать если работает!**

## 📡 **ТРАНСПОРТ ДАННЫХ**
```
module-concentration/includes/class-ajax-handler.php
```
**Ответственность:**
- Приём AJAX запросов
- Вызов Calculation_Engine
- Возврат JSON
- **НЕ содержит логику расчёта!**

## 🔄 **АДАПТАЦИЯ ДЛЯ UI**
```
module-concentration/includes/class-data-adapter.php
```
**Ответственность:**
- Подготовка данных из БД для JavaScript
- **НЕ вызывает Calculation_Engine!**
- **НЕ участвует в расчётах!**

## 🏗️ **ПРЕДСТАВЛЕНИЕ**
```
module-concentration/includes/class-shortcode.php
```
**Ответственность:** 
- Регистрация шорткода `[npk_concentration]`
- Подключение скриптов/стилей
- **НЕ содержит логику!**

## 🎨 **ФРОНТЕНД**
```
module-concentration/assets/js/calculator.js
```
**Ответственность:**
- Интерфейс, анимации
- Отправка AJAX
- **НЕ определяет state!** (не содержит `if (concentration >= range[0])`)

```
module-concentration/assets/css/calculator.css
```
**Ответственность:** Только стили

```
module-concentration/templates/calculator-template.php
```
**Ответственность:** Только HTML разметка

## 💾 **ДАННЫЕ (НЕ ТРОГАТЬ КОД!)**
```
shared/config/npk-database.php
```
**Ответственность:**
- Хранение данных (удобрения, профили, константы)
- **НЕ содержит логику!**
- **Менять только значения, не структуру!**

## 🏢 **ОРГАНИЗАЦИЯ**
```
module-concentration/concentration-module.php
```
**Ответственность:** Инициализация модуля концентрации

---

# ⚠️ **ГЛАВНОЕ ПРАВИЛО**
**Если проблема с:** → **Исправлять в:**
- Расчётами, формулами, state → `Calculation_Engine.php`
- AJAX запросами → `AJAX_Handler.php`
- Данными в БД → `npk-database.php`
- Интерфейсом, отображением → JS/CSS/HTML файлы
- Шорткод не работает → `Shortcode.php`

**Больше ничего не нужно знать.**
