## 🏛️ КОМПОНЕНТЫ СИСТЕМЫ И ОТВЕТСТВЕННОСТИ:

### 1. NPK_Selection_Engine (Ядро бизнес-логики)
**Файл:** `includes/class-selection-engine.php`
**Зависимости:** 
- ТОЛЬКО `NPK_Database::get_*()` методы
- НЕ зависит от: UI классов, WordPress Core (кроме стандартных хуков)
**Методы:**
- `calculate(int $culture_id, int $fertilizer_id): float` - основной метод расчета
- `normalize(array $npk_values): array` - нормализация по алгоритму Отиаи
- `find_minimums(array $culture_norm, array $fert_norm): array` - поиск минимумов
- `calculate_percentage(array $minimums): float` - расчет процента (сумма × 100)

### 2. NPK_UI_Handler (Презентационный слой)
**Файл:** `includes/class-ui-handler.php`
**Зависимости:**
- `Selection_Engine::calculate()` (только публичные методы)
- WordPress Core (для хуков и рендеринга)
**Методы:**
- `render_form(): string` - рендеринг формы выбора
- `handle_ajax(): void` - обработка AJAX запросов
- `validate_input(array $data): bool` - валидация входных данных
- `enqueue_assets(): void` - подключение JS/CSS

### 3. NPK_Templates (Шаблоны отображения)
**Папка:** `templates/`
**Файлы:**
- `selection-form.php` - форма выбора культуры/удобрения
- `results-display.php` - отображение результатов расчета
- `instant-preview.php` - шаблон для JS превью

## 📦 КОНТЕЙНЕРЫ ЗАДАНИЙ (ТЗ-Х) для Диспетчера:

### ТЗ-Х-1: Создание ядра расчета (Selection_Engine)
**Цель:** Реализовать класс с алгоритмом Отиаи
**Файлы:**
- `includes/class-selection-engine.php` (основной класс)
- `tests/test-selection-engine.php` (юнит-тесты)
**Методы для реализации:**
1. `__construct()` - инициализация, получение данных из БД
2. `calculate()` - основной публичный метод
3. `normalize()` - нормализация значений
4. `find_minimums()` - поиск минимальных значений
5. `calculate_percentage()` - финальный расчет
**Тестовые сценарии:**
- Культура [1.0, 2.0, 1.0] + Удобрение [16, 16, 16] = ожидаемый результат X%
- Граничные значения (нулевые, максимальные)
- Обработка ошибок (несуществующие ID)

### ТЗ-Х-2: Реализация Instant Preview на JavaScript
**Цель:** Клиентский предварительный расчет для UX
**Файлы:**
- `assets/js/instant-preview.js`
- `assets/css/instant-preview.css`
**Требования:**
- Алгоритм ДОЛЖЕН быть идентичен PHP реализации
- Использовать `FormData()` для AJAX, НЕ `URLSearchParams()`
- Динамическое обновление стилей (НЕТ статических значений в JS)
- CSS селекторы с префиксом `.npk-`
- Интеграция через `wp_localize_script()`

### ТЗ-Х-3: Интеграция с WordPress
**Цель:** Подключение модуля в WordPress экосистему
**Хуки (порядок важен!):**
1. `init` - регистрация shortcode: `[npk_calculator]`
2. `wp_enqueue_scripts` - подключение JS/CSS (условно, только на нужных страницах)
3. `admin_menu` - добавление страницы настроек в админку (если требуется)
4. `wp_ajax_npk_calculate` и `wp_ajax_nopriv_npk_calculate` - обработчики AJAX
**Shortcode:** `[npk_calculator type="selection"]`
