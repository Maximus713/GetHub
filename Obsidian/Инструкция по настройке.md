   ```

1. В админке: **Страницы → Добавить новую**

   - **Шаблон:** NPK Calculator - Final Version

### ШАГ 3: Настройка ссылки
1. Перейдите: **Настройки → Постоянные ссылки**
2. **Нажмите "Сохранить изменения"** (без изменений)

### ШАГ 4: Проверка
1. Откройте: `ваш-сайт/npk-calculator/`
2. Должно отображаться:
   - Меню навигации сверху

   - Нет конфликтов с Elementor

### Что делает шаблон:
✅ Полностью изолирует калькулятор от Elementor

## 🛠️ РЕШЕНИЕ ПРОБЛЕМ

### Проблема: Калькулятор мелкий/невидимый
**Решение:** Добавьте в `npk-isolation.css`:
```css
.npk-concentration-calculator { 
    font-size: 16px !important; 
    zoom: 1.1; /* Увеличивает весь калькулятор */
}
```

### Проблема: Elementor всё ещё влияет
**Решение:** Добавьте в functions.php темы:
```php
add_action('template_redirect', function() {
    if (is_page_template('page-npk-calculator.php')) {
        // Полное отключение Elementor
        remove_action('wp_enqueue_scripts', 'elementor_frontend_register_scripts');
        remove_action('wp_head', 'elementor_frontend_register_styles');
    }
});
```

### Проблема: Не работает AJAX
**Решение:** Проверьте nonce в консоли браузера:
```javascript
console.log('NPK nonce:', window.NPK_Concentration_Data?.ajax?.nonce);
