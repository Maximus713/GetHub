## **ДЕТАЛЬНАЯ ИНСТРУКЦИЯ ДЛЯ КАЖДОГО ЭТАПА:**

### **ЭТАП 1: ТЗ-1 (СКЕЛЕТ)**
**Что делаем:** Создаём все файлы с пустыми классами
**Проверка:** WordPress видит плагин, шорткод работает
**Критерий успеха:** Нет фатальных ошибок PHP

### **ЭТАП 2: ТЗ-2 (Calculation_Engine)**
**Что делаем:** Реализуем ВСЕ формулы
**Проверка:** Метод calculate() возвращает правильные данные
**Критерий успеха:** 0.30% для влажного грунта = состояние 'optimal'

### **ЭТАП 3: ТЗ-3 (Data_Adapter)**
**Что делаем:** Подготавливаем данные для JavaScript
**Проверка:** `window.NPK_Concentration_Data` существует и полон
**Критерий успеха:** Данные передаются в JS без ошибок

### **ЭТАП 4: ТЗ-4 (AJAX_Handler)**
**Что делаем:** Реализуем транспорт данных
**Проверка:** AJAX запросы возвращают JSON
**Критерий успеха:** Нет ошибок 400, данные приходят

### **ЭТАП 5: ТЗ-5 (JavaScript)**
**Что делаем:** Реализуем UI логику
**Проверка:** Интерфейс реагирует на действия
**Критерий успеха:** Цвета меняются синхронно, нет запрещённых конструкций

### **ЭТАП 6: ТЗ-6 (HTML/CSS)**
**Что делаем:** Завершаем вёрстку
**Проверка:** Внешний вид соответствует ТЗ
**Критерий успеха:** Адаптивность, все элементы на месте

### **ЭТАП 7: ТЗ-7 (ТЕСТИРОВАНИЕ)**
**Что делаем:** Полная проверка системы
**Проверка:** Все функции работают
**Критерий успеха:** Плагин готов к использованию

## **ЧТО ДЕЛАТЬ ПРИ ОШИБКАХ:**

### **Если AI делает ошибки:**
1. **Остановите разработку**
2. **Скажите:** "СТОП. Ты нарушил архитектурное ограничение [конкретное]"
3. **Попросите исправить файл полностью**
4. **Только после исправления продолжайте**

### **Если не работает AJAX:**
1. Проверьте `wp-content/debug.log`
2. Включите отладку в `wp-config.php`
3. Проверьте, зарегистрирован ли AJAX action
4. Упростите AJAX_Handler до минимальной рабочей версии

### **Если не работает JavaScript:**
1. Проверьте консоль браузера
2. Убедитесь, что `NPK_Concentration_Data` существует
3. Проверьте, нет ли запрещённых конструкций
4. Упростите код до рабочего состояния
