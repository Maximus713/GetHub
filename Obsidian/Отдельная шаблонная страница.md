## 📋 **ПОЛНАЯ ИНСТРУКЦИЯ: ШАБЛОННАЯ СТРАНИЦА ДЛЯ NPK КАЛЬКУЛЯТОРА**

---

## 🎯 **ЦЕЛЬ:** Создать страницу без Elementor, где CSS/JS работают на 100%

---

## 📁 **ШАГ 1: СОЗДАНИЕ ШАБЛОННОЙ СТРАНИЦЫ**

### **1.1 Создайте файл в теме WordPress:**
```
wp-content/themes/ваша-тема/page-npk-calculator.php
```

### **1.2 Содержимое файла:**
```php
<?php
/**
 * Template Name: NPK Calculator Page
 * Template Post Type: page
 */
?>
<!DOCTYPE html>
<html <?php language_attributes(); ?>>
<head>
    <meta charset="<?php bloginfo('charset'); ?>">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <?php wp_head(); ?>
    
    <!-- Подключаем стили плагина -->
    <link rel="stylesheet" href="<?php echo plugin_dir_url(__FILE__) . '../npk-calculator/assets/css/npk-calculator.css'; ?>">
    <style>
        /* Дополнительные стили для изоляции от темы */
        .npk-calculator-page {
            max-width: 1200px;
            margin: 40px auto;
            padding: 0 20px;
        }
        
        /* Скрываем лишние элементы */
        .npk-calculator-page .site-header,
        .npk-calculator-page .site-footer,
        .npk-calculator-page .sidebar {
            display: none;
        }
        
        /* Центрируем калькулятор */
        .npk-calculator-container {
            margin: 0 auto;
        }
    </style>
</head>
<body <?php body_class('npk-calculator-page'); ?>>
    
    <div class="npk-calculator-page-container">
        <!-- ==================== КАЛЬКУЛЯТОР ==================== -->
        <?php
        // Способ 1: Если плагин использует шорткод
        echo do_shortcode('[npk_calculator]');
        
        // ИЛИ Способ 2: Прямой HTML (если знаете структуру)
        // include_once WP_PLUGIN_DIR . '/npk-calculator/templates/calculator.php';
        ?>
    </div>
    
    <!-- Подключаем скрипты плагина -->
    <script src="<?php echo plugin_dir_url(__FILE__) . '../npk-calculator/assets/js/npk-calculator.js'; ?>"></script>
    
    <?php wp_footer(); ?>
</body>
</html>
```

## 🔧 **ШАГ 2: АДАПТАЦИЯ CSS ПЛАГИНА**

### **2.1 Создайте изолированную версию CSS:**
```css
/* npk-calculator-isolated.css */
.npk-calculator-page .npk-concentration-calculator {
    /* КОПИРУЕТЕ ВЕСЬ ВАШ CSS ФАЙЛ СЮДА */
    /* Но удаляете ВСЕ !important и body .elementor-widget */
    
    /* Вместо этого: */
    box-sizing: border-box;
    font-family: 'Roboto', sans-serif;
    max-width: 800px;
    margin: 30px auto;
    /* ... и весь остальной CSS ... */
}

/* Удалите ВСЕ эти строки: */
body .elementor-widget .npk-concentration-calculator ... { ... !important }
```

### **2.2 Или используйте ваш текущий CSS, но в изоляции:**
```html
<style>
/* Обёртка для изоляции */
.npk-calculator-page #npk-calculator-main {
    all: initial; /* Сброс всех наследуемых стилей */
    display: block;
}

.npk-calculator-page #npk-calculator-main * {
    all: unset; /* Сброс для всех дочерних */
}
</style>
```

## ⚡ **ШАГ 5: ОПТИМИЗАЦИЯ (ОПЦИОНАЛЬНО)**

### **5.1 Отключите ненужные скрипты на этой странице:**
```php
// В functions.php вашей темы
add_action('wp_enqueue_scripts', function() {
    if (is_page_template('page-npk-calculator.php')) {
        // Отключаем ненужные скрипты
        wp_dequeue_style('theme-styles');
        wp_dequeue_script('theme-scripts');
        
        // Отключаем Elementor
        wp_dequeue_style('elementor-frontend');
        wp_dequeue_script('elementor-frontend');
    }
});
```

### **5.2 Ускорение загрузки:**
```html
<!-- В шапке шаблонной страницы -->
<link rel="preload" href="<?php echo plugin_dir_url(__FILE__) . '../npk-calculator/assets/css/npk-calculator.css'; ?>" as="style">
<link rel="preload" href="<?php echo plugin_dir_url(__FILE__) . '../npk-calculator/assets/js/npk-calculator.js'; ?>" as="script">
```

## 🔄 **АЛЬТЕРНАТИВА: ПОДКЛЮЧЕНИЕ ЧЕРЕЗ PLUGIN TEMPLATE**

### **Если хотите сделать это внутри плагина:**
```php
// В вашем плагине создайте:
// npk-calculator/templates/page-template.php

// И добавьте в основной файл плагина:
add_filter('theme_page_templates', function($templates) {
    $templates['npk-calculator-template.php'] = 'NPK Calculator Page';
    return $templates;
});

add_filter('template_include', function($template) {
    if (get_page_template_slug() === 'npk-calculator-template.php') {
        return plugin_dir_path(__FILE__) . 'templates/page-template.php';
    }
    return $template;
});
```

## ⚠️ **ВАЖНЫЕ ЗАМЕЧАНИЯ:**

### **Проблемы и решения:**
1. **Стили темы мешают?** → Используйте `all: initial` или iframe
2. **JavaScript не работает?** → Проверьте консоль браузера (F12)
3. **Страница не найдена?** → Пересохраните постоянные ссылки
4. **Дизайн ломается?** → Добавьте больше изоляции в CSS

### **Преимущества этого подхода:**
- ✅ **100% контроль** над стилями
- ✅ **Нет конфликтов** с Elementor
- ✅ **Быстрая реализация** (1-2 часа)
- ✅ **Легко поддерживать**
- ✅ **Можно встроить** через iframe куда угодно
