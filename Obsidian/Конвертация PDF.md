

Вот полный пошаговый порядок действий для конвертации ваших чертежей из PDF в PNG с помощью **PDF24 Tools**. Весь процесс займет около 5-10 минут для пакета файлов.

## 📋 Полный порядок действий в PDF24 Tools

### **Шаг 1: Откройте сервис и выберите инструмент**
1. Перейдите по адресу: **[https://tools.pdf24.org/ru/](https://tools.pdf24.org/ru/)**
2. В списке всех инструментов найдите и выберите **«Конвертер PDF в JPG»** (он также конвертирует в PNG).
3. Или используйте прямую ссылку: [Конвертер PDF в JPG](https://tools.pdf24.org/ru/converter/pdf-to-jpg)

### **Шаг 2: Загрузите PDF-файлы с чертежами**
4. На открывшейся странице нажмите **«Выбрать файлы»**.
5. В проводнике выберите **все подготовленные PDF-файлы** с чертежами. Можно загружать несколько файлов одновременно (нет ограничения на количество в бесплатной версии).
6. Файлы появятся в списке. Убедитесь, что загружены все нужные чертежи.

### **Шаг 3: Настройте параметры конвертации (КРИТИЧНО ДЛЯ КАЧЕСТВА)**
7. Под списком файлов найдите раздел **«Настройки вывода»**.
8. Установите следующие параметры:
   - **«Формат вывода»**: выберите **`PNG`** (предпочтительнее для чертежей, чем JPG).
   - **«Качество изображения»**: установите ползунок на максимум (**`Высокое`** или значение 100%).
   - **«Разрешение (DPI)»**: выберите **`300 dpi`**. Это обеспечит четкость линий и текста на чертежах.
   - **«Способ преобразования»**: для технических чертежей выбирайте **`Каждая страница в отдельное изображение`** (если в одном PDF несколько листов, они станут отдельными PNG-файлами).

### **Шаг 4: Запустите конвертацию**
9. Нажмите синюю кнопку **«Конвертировать»**.
10. Дождитесь завершения процесса. Прогресс отобразится для каждого файла. Скорость зависит от количества и размера файлов.

### **Шаг 5: Скачайте результаты**
11. После завершения обработки на экране появится кнопка **«Скачать все файлы»** (или список отдельных файлов для скачивания).
12. Нажмите ее, чтобы загрузить **ZIP-архив** со всеми PNG-файлами. Система предложит сохранить его на ваш компьютер.
13. **Распакуйте архив** в удобную папку. Внутри вы найдете PNG-файлы с именами, соответствующими исходным PDF (например, `основание-системы_страница-1.png`).

## 🎨 Что делать дальше с полученными PNG-файлами?

После успешной конвертации у вас будут высококачественные PNG, готовые к финальному этапу — созданию оптимизированных версий для сайта:

1.  **Создайте две папки**: `webp_full` и `webp_preview`.
2.  Откройте **[Squoosh.app](https://squoosh.app)**.
3.  Для **каждого** PNG-файла выполните:
    - **Полноразмерная версия (для lightbox)**:
        - Перетащите PNG в Squoosh
        - Справа выберите формат **`WebP`**
        - Установите **Качество (Quality) ≈ 90%**
        - В настройках **Resize** укажите **Ширину (Width) = 1600px**
        - Скачайте файл и сохраните в папку `webp_full` с суффиксом `_full` (например, `основание_full.webp`)
    - **Уменьшенная версия (превью для страницы)**:
        - Снова откройте тот же PNG в Squoosh (или используйте кнопку "Назад")
        - Формат **`WebP`**
        - **Качество ≈ 75-80%**
        - В **Resize** укажите **Ширину = 400px**
        - Скачайте и сохраните в папку `webp_preview` с суффиксом `_preview` (например, `основание_preview.webp`)
Формат А4 297х210 - 800 х 567рх.

## 💡 Ключевые моменты для успеха

- **Исходные PDF**: Убедитесь, что PDF-файлы, экспортированные из AutoCAD, имеют хорошее качество (рекомендуется использовать при печати настройки: формат А3/А4, масштаб 1:1 или "По размеру", стиль печати `monochrome.ctb` для ЧБ).
- **Проверка качества**: После конвертации откройте один из PNG-файлов, увеличьте масштаб до 100% и убедитесь, что все линии и надписи четкие, нет размытия.
- **Именование файлов**: Для удобства дальнейшей работы на сайте сразу давайте файлам логичные имена, отражающие содержание чертежа (например, `01_osnovanie.png`, `02_krestovina.png`).

Этот метод гарантирует получение качественных PNG без ограничений, водяных знаков и с сохранением полной конфиденциальности ваших чертежей.
