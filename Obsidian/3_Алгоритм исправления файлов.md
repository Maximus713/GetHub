# 🔄 **ПОЛНЫЙ АЛГОРИТМ ВАШИХ ДЕЙСТВИЙ**

## 📋 **ПОДГОТОВКА ПЕРЕД НАЧАЛОМ**

### **1. Подготовьте материалы:**
```
✅ Файл для исправления (например, `npk-calculators.php`)
✅ Основное ТЗ (техническое задание)
✅ Специальное ТЗ для этого файла (если есть)
✅ Эталонную архитектуру и ограничения
```

### **2. Откройте ДВА отдельных чата:**
```
ЧАТ №1: Новое окно/вкладка для анализа
ЧАТ №2: Новое окно/вкладка для исправлений
```

---

## 🔄 **ПОЛНЫЙ АЛГОРИТМ ШАГ ЗА ШАГОМ**

### **ЭТАП 1: АНАЛИЗ ОШИБОК (ЧАТ №1)**

#### **Шаг 1.1: Отправьте в ЧАТ №1**
```
Отправьте в ЧАТ №1 следующий текст:

"Я отправляю тебе файл и ТЗ. Твоя задача: найти ВСЕ ошибки, но НЕ исправлять их. 
Создай список ошибок в формате:

### ОШИБКА #[номер]
НАЙТИ: [точный текст для поиска]
ЗАМЕНИТЬ НА: [точный текст для замены]
ГДЕ: [строка X или 'везде']
ПРОВЕРИТЬ ДО: [условие проверки]
ПРОВЕРИТЬ ПОСЛЕ: [условие проверки]

НЕ предлагай исправления, НЕ анализируй код глубоко, НЕ улучшай.
Только найди ошибки и создай список замен."

Затем отправьте файлы:
1. [вставьте файл]
2. [вставьте ТЗ]
3. [вставьте специальное ТЗ]
```

#### **Шаг 1.2: Получите и проверьте список ошибок**
```
ЧАТ №1 вернёт:
✅ Список ошибок в нужном формате
❌ Или предложит исправления (это ошибка!)

Если ЧАТ №1 предлагает исправления:
Скажите: "Только список ошибок. Не исправляй. Не предлагай решения."
```

#### **Шаг 1.3: Скопируйте список ошибок**
```
Скопируйте ВЕСЬ список ошибок из ЧАТ №1.
Сохраните в отдельный документ (Блокнот, Google Docs).
Примерно так:
"""
### ЗАМЕНА #1
НАЙТИ: "new ModuleClass()"
ЗАМЕНИТЬ НА: "ModuleClass::init()"
ГДЕ: строка 45
...
"""
```

---

### **ЭТАП 2: ИСПРАВЛЕНИЯ (ЧАТ №2)**

#### **Шаг 2.1: Отправьте в ЧАТ №2**
```
Отправьте в ЧАТ №2 следующий текст:

"Я отправляю тебе файл и список точных замен.
Твоя задача: выполнить ТОЛЬКО эти замены. 
НЕ анализировать код, НЕ придумывать свои исправления, 
НЕ улучшать, НЕ оптимизировать.

Ты — автоматический редактор 'найти и заменить'.
Выполни замены, веди журнал, верни исправленный файл."

Затем отправьте:
1. [вставьте ИСХОДНЫЙ файл (неизменённый!)]
2. [вставьте список ошибок из этапа 1]
```

#### **Шаг 2.2: Получите исправленный файл**
```
ЧАТ №2 вернёт:
✅ Исправленный файл целиком
✅ Журнал выполненных замен
✅ Статистику: успешно/пропущено/откачено
```

#### **Шаг 2.3: Проверьте результат**
```
1. Откройте исправленный файл
2. Проверьте, что исправлены ТОЛЬКО ошибки из списка
3. Проверьте журнал — все ли замены выполнены
4. Убедитесь, что правильный код не изменён
```

## ⚠️ **ВАЖНЫЕ ПРАВИЛА**

### **ПРАВИЛО 1: НЕ СМЕШИВАТЬ ЧАТЫ**
```
ЧАТ №1 никогда не видит ЧАТ №2
ЧАТ №2 никогда не видит ЧАТ №1
Между ними "китайская стена"
```

### **ПРАВИЛО 2: СОХРАНЯТЬ ИСХОДНИКИ**
```
Всегда храните:
1. Исходный файл (оригинал)
2. Список ошибок от ЧАТ №1  
3. Исправленный файл от ЧАТ №2
```

### **ПРАВИЛО 3: ПРОВЕРЯТЬ ФОРМАТ**
```
Список от ЧАТ №1 ДОЛЖЕН быть:
НАЙТИ: "текст"
ЗАМЕНИТЬ НА: "текст"
ГДЕ: строка X
```

### **ПРАВИЛО 4: ИСПОЛЬЗОВАТЬ ИСХОДНЫЙ ФАЙЛ**
```
В ЧАТ №2 отправляйте ИСХОДНЫЙ файл,
а не тот, что уже изменяли!
```

## 🔄 **ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК**

### **Проблема: ЧАТ №1 предлагает исправления**
```
Решение: Скажите:
"Только список ошибок. Не исправляй. Не предлагай решения.
Нужен список в формате: НАЙТИ: ... ЗАМЕНИТЬ НА: ..."
```

### **Проблема: ЧАТ №2 начинает анализировать**
```
Решение: Скажите:
"Не анализируй. Просто выполни замены из списка.
Ты — робот для поиска и замены, не программист."
```

### **Проблема: Ошибки остались после исправлений**
```
Решение:
1. Проверьте журнал от ЧАТ №2
2. Если замены пропущены — уточните список
3. Если ошибки новые — вернитесь к исходнику
4. Начните процесс заново с исправленным списком
```

### **Проблема: Правильный код изменился**
```
Решение:
1. Вернитесь к исходному файлу
2. Проверьте список ошибок — нет ли лишнего
3. Уточните ЧАТу №1: "Только явные нарушения ТЗ"
4. Повторите процесс
```

## 💡 **СОВЕТЫ ПО ЭФФЕКТИВНОСТИ**

### **Для скорости:**
```
1. Используйте шаблоны сообщений (копировать-вставить)
2. Храните все файлы в одном месте
3. Делайте скриншоты на каждом этапе
```

### **Для качества:**
```
1. Проверяйте формат списка ошибок ДО отправки в ЧАТ №2
2. Сравнивайте исходный и исправленный файлы поблочно
3. Ведите свой журнал: что исправляли, когда, результат
```

### **Для безопасности:**
```
1. Всегда начинайте с копии файла
2. После каждого успешного исправления делайте backup
3. Если сомневаетесь — остановитесь и проверьте
```
