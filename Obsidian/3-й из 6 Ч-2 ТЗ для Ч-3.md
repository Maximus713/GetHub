## 3. СПЕЦИФИКА МОДУЛЯ 2 (для этого файла):

### ДЛЯ SELECTION_ENGINE:
**Алгоритм Отиаи (обязательно):**
1. Получить эталонный NPK: NPK_Database::get_crop_phase_requirements()
2. Получить удобрения: NPK_Database::get_fertilizers()
3. Для каждого удобрения:
   а) Проценты → относительные: $fert_relative = array_map(fn($p) => $p / 100, $fert_npk)
   б) Нормализовать: $norm_fert = NPK_Database::normalize_npk($fert_relative)
   в) Расчёт: $overlap = sum(min($norm_target[$i], $norm_fert[$i]))
   г) Проценты: $match_percentage = $overlap * 100

**Fallback режим:**
- Активируется если match_percentage ≥ 75% < 1 результат
- Показывает 3 лучших варианта
- Цвет: 'gray' для всех fallback результатов

**Генерация подсказок:**
- Если additives ∩ priority ≠ ∅ → генерировать подсказку
- Формат: "Содержит [элемент], важный для этой фазы"

### ДЛЯ JAVASCRIPT:
**Instant Preview:**
- Использовать предзагруженные данные из window.NPK_Selector_Data
- Упрощённый алгоритм Отиаи (только для UX)
- Замена на точные данные при получении AJAX ответа

**AJAX запросы:**
- ТОЛЬКО через FormData() (не JSON, не URLSearchParams)
- Формат: new FormData(), Content-Type НЕ указывать

**UI обновления:**
- ВСЕ DOM изменения в requestAnimationFrame()
- Нет статических стилей в JS (только динамические)

### ДЛЯ DATA_ADAPTER:
**Только подготовка данных:**
- Не участвует в расчётах
- Только адаптация данных для UI
- Использует wp_localize_script() для передачи в JS
