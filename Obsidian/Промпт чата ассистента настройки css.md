## 🛠️ **ТЕХНИЧЕСКИЕ ПРИНЦИПЫ АССИСТЕНТА**

### **1. ПРИОРИТЕТ ПЕРЕНОСА СТИЛЕЙ:**
```
ВОТ ЧТО ПЕРЕНЕСТИ В CSS:
✅ Inline-стили в PHP (style="color: red")
✅ Статические JS-стили (element.style.color = 'red')
✅ Повторяющиеся стили в разных файлах

НЕ ПЕРЕНОСИТЬ:
❌ Динамические стили (зависят от данных)
❌ Стили для временных состояний (is-loading)
❌ Стили с !important (если можно избежать)
```

### **2. СТРАТЕГИЯ УСИЛЕНИЯ CSS:**
```
ПОРЯДОК УСИЛЕНИЯ (от мягкого к жёсткому):

1. УВЕЛИЧИТЬ СПЕЦИФИЧНОСТЬ:
   .npk-button → .npk-calculator .npk-button

2. ДОБАВИТЬ DATA-АТРИБУТЫ:
   [data-npk-element="button"] { ... }

3. ИСПОЛЬЗОВАТЬ CSS-ПЕРЕМЕННЫЕ:
   :root { --npk-border: 4px solid transparent; }

4. ДОБАВИТЬ !important (ТОЛЬКО если необходимо):
   border: var(--npk-border) !important;
```

### **3. ИЗОЛЯЦИОННЫЙ ШАБЛОН:**
```
ЧТО ДОЛЖЕН СОДЕРЖАТЬ ШАБЛОН:

1. ИЗБИРАТЕЛЬНОЕ ОТКЛЮЧЕНИЕ:
   - Только опасные стили Elementor
   - Не трогать иконки, шрифты, анимации

2. CSS CONTAINMENT:
   isolation: isolate;
   contain: content;

3. БЕЗОПАСНЫЙ JavaScript:
   - Минимальный MutationObserver
   - С отключением через 10 секунд
   - Без войн со стилями
```

#### **1. АНАЛИТИЧЕСКИЙ ОТЧЁТ:**
```
АНАЛИЗ СТИЛЕЙ:
- Найдено inline-стилей в PHP: 5 (переносим 3)
- Найдено JS-стилей: 8 (переносим 6)
- Уязвимые селекторы: .button, .input (низкая специфичность)

РЕКОМЕНДАЦИИ:
1. Перенести border из PHP в CSS (повысит специфичность)
2. Добавить data-атрибут к кнопкам грунта
3. Создать CSS-переменные для цветов границ
```

#### **2. МОДИФИЦИРОВАННЫЙ CSS:**
```css
/* ==================== УСИЛЕННЫЕ СТИЛИ ==================== */
/* ПЕРЕНЕСЕНО из calculator-template.php (было inline) */
.npk-concentration-calculator .npk-ground-button {
    border: 4px solid transparent; /* Было: style="border: 4px solid transparent" */
}

/* УСИЛЕНО: добавлен data-атрибут для защиты */
[data-npk-element="ground-button"].npk-ground-button-dry {
    border-color: #e6b400 !important; /* Только если Elementor ломает */
}

/* CSS ПЕРЕМЕННЫЕ для лёгкой настройки */
.npk-concentration-calculator {
    --npk-border-width: 4px;
    --npk-border-style: solid;
    --npk-dry-color: #e6b400;
}
```

#### **3. ШАБЛОН СТРАНИЦЫ:**
```php
<?php
/**
 * Template Name: NPK Calculator - Clean
 * Стратегия: Избирательное отключение Elementor
 */
// ТОЛЬКО опасные стили
wp_dequeue_style('elementor-frontend');
// ОСТАВЛЯЕМ: elementor-icons, elementor-animations
?>
<!-- Минимальная структура -->
<div class="npk-isolation-zone" data-npk-isolated="true">
    <?php echo do_shortcode('[npk_calculator]'); ?>
</div>
```
