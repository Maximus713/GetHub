## 🚀 **ПЛАН-СХЕМА СОЗДАНИЯ SITE: LEDGREEN.RU**

### **📅 ЭТАП 0: ПРЕДПРОЕКТНЫЙ (1-3 дня)**
**Цель:** Собрать все материалы и принять ключевые решения

**Задачи:**
1.  **Собрать "материальную базу":**
    *   Все фото готовых систем (крупные планы, в интерьере, с рассадой)
    *   Все видео (обзоры, таймлапсы, инструкции)
    *   Логотип, фирменные цвета, шрифты
    *   Тексты (описания преимуществ, технические характеристики)
    *   Упаковка продукции (дизайн коробки)

2.  **Определить технический стек:**
    *   **Движок:** WordPress (гибкость) + **Elementor Pro** (визуальное редактирование)
    *   **Хостинг:** Времянка или Beget/Ru-Center (с поддержкой WordPress)
    *   **Домен:** `ledgreen.ru` уже есть
    *   **Доп. плагины:**
        *   WooCommerce (для корзины и конструктора)
        *   Essential Addons for Elementor (доп. виджеты)
        *   Форма обратной связи

3.  **Назначить команду:**
    *   Кто будет наполнять контентом? (Вы)
    *   Кто будет делать дизайн/верстку? (Фрилансер или вы через Elementor)
    *   Кто будет заниматься SEO? (Вы + возможно специалист)

### **🎨 ЭТАП 2: ДИЗАЙН И ПРОТОТИП (5-10 дней)**
**Инструмент:** Figma (основной), Adobe Color, Google Fonts

**1. Moodboard (Мудборд):**
*   **Цвета:** Зеленый (#27AE60 - акцент), темно-серый (#2C3E50 - фон), белый (#FFFFFF)
*   **Шрифты:** 
    *   Заголовки: Montserrat (современный, технологичный)
    *   Основной текст: Open Sans (читабельный)
*   **Стиль:** Чистый, технологичный, с акцентами на натуральность (фото растений)

**2. Дизайн-система в Figma:**
1.  **Создайте компоненты:**
    *   Кнопка "Собрать комплект" (зеленая, большая)
    *   Кнопка "Смотреть видео" (прозрачная с иконкой)
    *   Карточка преимущества (иконка + текст)
    *   Карточка товара (фото + название + цена)
2.  **Создайте прототипы страниц:**
    *   **Главная** (полная версия)
    *   **Страница продукта** (детальная)
    *   **Конструктор** (интерактивный прототип)
    *   **Мобильные версии** каждой

**3. Интерактивный прототип:**
- Сделайте кликабельные переходы между страницами в Figma
- Покажите анимации (появление блоков, hover-эффекты)

---

### **🔧 ЭТАП 3: ВЕРСТКА НА WORDPRESS (7-14 дней)**
**Инструменты:** WordPress + Elementor Pro + Essential Addons

**Пошаговый план верстки:**

#### **Неделя 1: Базовый каркас**
1.  **Установка и настройка:**
    - Установить WordPress на хостинге
    - Установить тему **Hello Elementor** (чистая, быстрая)
    - Установить плагины: Elementor Pro, WooCommerce, Essential Addons
    - Настроить базовые цвета и шрифты в Global Settings Elementor

2.  **Создание страниц:**
    - Создать все страницы из структуры (пока пустые)
    - Настроить меню (Главное меню, Футер меню)

3.  **Главная страница (самая важная!):**
    - Использовать шаблон из библиотеки Elementor как основу
    - Адаптировать под наш дизайн из Figma
    - Разместить: Герой-баннер с видео, 3 ключевых преимущества, тизер эксперимента, призыв к конструктору

#### **Неделя 2: Ключевые страницы и функционал**
1.  **Страница продукта (/system):**
    - Слева: галерея фото/видео
    - Справа: название, цена, кнопка "В конструктор"
    - Ниже: табы с характеристиками, описанием, отзывами

2.  **Конструктор (/constructor):**
    - **Сложный элемент!** Возможно, нужен кастомный плагин
    - **Вариант проще:** Сделать через форму Gravity Forms с расчетом или через WooCommerce вариативных товаров
    - Визуализация: менять картинку комплектации при выборе опций

3.  **База знаний (/knowledge):**
    - Установить плагин для блога
    - Разбить на категории: Инструкции, Статьи, Видео
    - Создать первые 3-5 полезных статьи

#### **Неделя 3: Оптимизация и наполнение**
1.  **Мобильная адаптация:**
    - Проверить и поправить ВСЕ страницы на мобильных устройствах
    - Упростить навигацию для мобильных

2.  **Наполнение контентом:**
    - Загрузить все фото (оптимизировать размер!)
    - Встроить все видео (YouTube предпочтительнее)
    - Написать все тексты (убедительные, без воды)

3.  **Формы и интеграции:**
    - Настроить форму заказа (интеграция с Telegram/Email)
    - Подключить аналитику (Яндекс.Метрика, Google Analytics)
    - Настроить чат (Telegram/WhatsApp виджет)

### **⚡ ЭТАП 4: ТЕСТИРОВАНИЕ И ЗАПУСК (3-5 дней)**
**Чеклист перед запуском:**

#### **Техническое тестирование:**
- [ ] Все ссылки работают
- [ ] Формы отправляются
- [ ] Корзина и оформление заказа работают
- [ ] Сайт быстро грузится (проверить через PageSpeed Insights)
- [ ] Адаптивность на всех устройствах
- [ ] Кроссбраузерность (Chrome, Firefox, Safari, Яндекс)

#### **Контент-тестирование:**
- [ ] Нет орфографических ошибок
- [ ] Все фото качественные
- [ ] Видео проигрываются
- [ ] Контакты корректные

#### **SEO-базовая настройка:**
- [ ] Прописаны Title и Description для каждой страницы
- [ ] Загружена карта сайта sitemap.xml
- [ ] Настроен файл robots.txt
- [ ] Установлены ЧПУ (человекопонятные URL)

### **📈 ЭТАП 5: ПОСТЗАПУСКОВАЯ ОПТИМИЗАЦИЯ (непрерывно)**
**Первые 30 дней после запуска:**

1.  **Мониторинг:**
    - Следить за статистикой посещений
    - Отслеживать конверсии (сколько посетителей стали покупателями)
    - Собирать обратную связь от первых пользователей

2.  **A/B тесты:**
    - Тестировать разные заголовки на главной
    - Тестировать цвет/текст кнопок CTA
    - Тестировать расположение блоков

3.  **Доработка:**
    - Добавить недостающие разделы по запросам пользователей
    - Улучшить конструктор на основе фидбека
    - Добавить новые видео и статьи в базу знаний

### **🎯 КРАТКИЙ ПЛАН ДЛЯ БЫСТРОГО СТАРТА (MVP-версия)**

Если нужно запустить сайт максимально быстро:

1.  **День 1-2:** Установить WordPress + Elementor Pro. Взять готовый шаблон "Technology" или "Shop" из библиотеки Elementor.
2.  **День 3:** Адаптировать шаблон: заменить текст, загрузить свои фото, поменять цвета.
3.  **День 4:** Создать 4 ключевые страницы: Главная, О системе, Конструктор (простая форма), Контакты.
4.  **День 5:** Настроить аналитику и тестово запустить.

### **📊 ОСНОВНЫЕ МЕТРИКИ УСПЕХА САЙТА:**
- **Конверсия:** >2% посетителей делают заказ
- **Время на сайте:** >3 минут
- **Глубина просмотра:** >3 страниц за визит
- **Отказы:** <40%

### **🔧 РЕСУРСЫ ДЛЯ РЕАЛИЗАЦИИ:**
1.  **Обучение Elementor:** YouTube-канал "Elementor Russian"
2.  **Бесплатные шаблоны:** templatemonster.com/elementor-templates

4.  **Формы:** плагин Gravity Forms или Formidable Forms

**Главный совет:** Начните с MVP (минимально жизнеспособного продукта) — простой сайт с основными функциями. Запустите, получите первые продажи и обратную связь. Затем улучшайте и дополняйте на основе реальных данных, а не предположений.

## 📝 **Как будем работать:**

### **Шаг 1: Начнем с Hero-секции**
Вы пишете черновик текста/идей, я:

- Помогу с расстановкой акцентов

### **Шаг 2: Блок за блоком**
Будем двигаться по структуре:
1. Герой
2. Проблема
3. Решение
4. Преимущества
5. Доказательства
6. Как работает
7. Комплектации
8. FAQ
9. Финальный CTA

### **Шаг 3: Оптимизация**
- Проверим на убедительность
- Усилим CTA
- Добавим триггеры доверия
- Адаптируем для мобильных

## 💡 **С чего начать:**

Давайте начнем с **Hero-секции**. Ответьте на вопросы:

1. **Главная боль клиента:** Что его больше всего беспокоит?
   - Слабая рассада? 
   - Нехватка места?
   - Сложность ухода?

2. **Главное преимущество:** Что важнее выделить?
   - Автоматизацию?
   - Качество рассады?
   - Универсальность?

3. **Есть ли готовые фото/видео** для героя?
