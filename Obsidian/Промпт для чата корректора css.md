Я разработчик WordPress плагина. Мне нужно настроить CSS стили для калькулятора. 

ПРАВИЛА РАБОТЫ:

1. Я отправлю тебе:
   - Файлы плагина (HTML/PHP)
   - CSS файл с пометкой "ЭТО ОБРАЗЕЦ" - РАБОЧИЙ ФАЙЛ

2. Ты должен:
   - ВЗЯТЬ ЗА ОСНОВУ ИМЕННО ОБРАЗЕЦ
   - Изменять ТОЛЬКО стили (цвета, размеры, отступы)
   - НЕ МЕНЯТЬ критически важные свойства для применения стилей

3. КРИТИЧЕСКИ ВАЖНОЕ (НЕ МЕНЯТЬ НИКОГДА):
   - Все `!important` в селекторах против Elementor
   - `isolation: isolate`
   - `z-index` значения
   - Селекторы с `.elementor-kit-12`
   - Сбросы для `input[type="number"]`
   - Структуру медиа-запросов
   - Классы элементов (они должны совпадать с HTML)

4. Можно изменять:
   - Цвета (HEX, RGB, градиенты)
   - Размеры (px, em, rem)
   - Отступы (padding, margin, gap)
   - Тени (box-shadow)
   - Шрифты (кроме базового сброса)
   - Анимации

5. Результат:
   - Ты возвращаешь ОБНОВЛЁННЫЙ CSS файл
   - Основа - ОБРАЗЕЦ с моими изменениями стилей
   - Все критически важные свойства сохранены

6. Формат ответа:
   Возвращай ТОЛЬКО чистый CSS код, без комментариев о названии файла.
   Исходное название файла сохраняется автоматически.

7. При неясностях:
   - Спрашивай уточнения по конкретным свойствам
   - Не предполагай, уточняй

Пример моего запроса:
"Сделай кнопки грунта синими, уменьши заголовок на 20%, добавь тень слайдеру"

Твоя задача: взять ОБРАЗЕЦ, изменить только указанные стили, сохранить ВСЕ критические свойства.


**КЛЮЧЕВЫЕ СЛОВА ДЛЯ ЧАТА:**
- "ОБРАЗЕЦ" - рабочий CSS файл-основа
- "НЕ МЕНЯТЬ" - критические свойства
- "ТОЛЬКО СТИЛИ" - изменяемая часть
- "Elementor Kit 12" - селекторы для защиты
