# 🎯 КОМПАКТНЫЙ ГАЙД ДЛЯ СОЗДАНИЯ ПЛАГИНА NPK CALCULATORS
*(Прочти за 5 минут перед началом работы)*

## 📌 **ГЛАВНОЕ ПРАВИЛО:**
**Нарушишь 4 критических правила → плагин НЕ РАБОТАЕТ.**
**Следуй структуре → плагин работает с первого раза.**

---

## 🔴 **4 КРИТИЧЕСКИЕ ОШИБКИ (плагин не работает):**

### **ОШИБКА 1: ❌ Неправильные имена файлов и классов**

#### **ФАЙЛЫ (всегда kebab-case):**
```php
❌ npkCalculators.php, concentration_module.php, CalculationEngine.php
✅ npk-calculators.php, concentration-module.php, class-calculation-engine.php
```

#### **КЛАССЫ PHP (всегда PascalCase_С_Подчёркиваниями):**
```php
❌ class NPKCalculators {}, class npk_calculators {}, class Npk_Calculators {}
✅ class NPK_Calculators {}, class Calculation_Engine {}, class NPK_Concentration_Module {}
```

#### **CSS и data-атрибуты (всегда с префиксом npk-):**
```css
❌ .calculator-container, .npkCalculatorContainer
✅ .npk-calculator-container, .npk-ground-button

❌ data-calculator-id, dataNpkCalculatorId  
✅ data-npk-calculator-id, data-npk-ground-type
```

**Почему важно:** WordPress не найдёт файлы, классы конфликтуют, скрипты не подключатся.

---

### **ОШИБКА 2: ❌ Нарушен порядок создания файлов**

**НЕПРАВИЛЬНО (вызовет ошибку 500):**
```
1. concentration-module.php
2. Он пытается подключить class-calculation-engine.php
3. Этого файла ещё нет!
4. Фатальная ошибка PHP
```

**ПРАВИЛЬНО (сначала база, потом зависимости):**
```
✅ 1. npk-calculators.php (главный файл)
✅ 2. npk-database.php (база данных)
✅ 3. class-calculation-engine.php (ядро логики)
✅ 4. class-data-adapter.php, class-ajax-handler.php (зависимости)
✅ 5. concentration-module.php (модуль - ПОСЛЕ всех классов!)
✅ 6. Остальные файлы (шаблоны, JS, CSS)
```

**Правило:** Создавай файлы в том порядке, в котором они будут подключаться.

---

### **ОШИБКА 3: ❌ Шорткод не работает (самая частая!)**

**НЕПРАВИЛЬНО (пустая страница вместо калькулятора):**
```php
// 1. Слишком поздно
add_action('init', 'init_plugin');

// 2. Регистрация до загрузки классов
function init_plugin() {
    add_shortcode('npk_calculator', 'render_shortcode'); // Классов ещё нет!
    require_once 'class-shortcode.php'; // СЛИШКОМ ПОЗДНО
}

// 3. Ненадёжная передача данных
wp_localize_script('npk-calculator', 'NPK_Data', $data); // Иногда не работает
```

**ПРАВИЛЬНО (работающий шорткод):**
```php
// 1. Ранняя инициализация
add_action('plugins_loaded', 'init_plugin', 5); // Ранний приоритет!

function init_plugin() {
    // 2. СНАЧАЛА загружаем ВСЕ классы
    require_once 'class-shortcode.php';
    require_once 'class-calculation-engine.php';
    
    // 3. ПОТОМ регистрируем шорткод
    add_shortcode('npk_concentration_calculator', ['Shortcode_Class', 'render']);
    
    // 4. Гарантированная передача данных
    wp_add_inline_script(
        'npk-concentration-calculator',
        'window.NPK_Concentration_Data = ' . json_encode($data) . ';',
        'before'
    );
}
```

**Проверка:** Если видишь `[npk_concentration_calculator]` вместо калькулятора → это ОШИБКА 3.

### **ОШИБКА 4: ❌ AJAX вызывает перезагрузку страницы**

**НЕПРАВИЛЬНО (страница перезагружается):**
```javascript
// ❌ Форматы, которые вызывают перезагрузку:
new FormData()
new URLSearchParams()
'application/x-www-form-urlencoded'

fetch(url, {
    body: new FormData(form) // ❌ ПЕРЕЗАГРУЗКА!
})
```

**ПРАВИЛЬНО (AJAX работает):**
```javascript
// ✅ ЕДИНСТВЕННЫЙ правильный формат:
fetch(ajaxurl, {
    method: 'POST',
    headers: { 
        'Content-Type': 'application/json' // ✅ ТОЛЬКО JSON
    },
    body: JSON.stringify({ // ✅ ТОЛЬКО JSON.stringify
        action: 'npk_concentration_calculate',
        fertilizer_id: 1,
        concentration: 0.3,
        water_volume: 10,
        ground_type: 'wet'
    })
})
```

**И в PHP тоже JSON:**
```php
// Получаем JSON
$json_input = file_get_contents('php://input');
$data = json_decode($json_input, true);

// Возвращаем JSON
wp_send_json_success($result);
```

**Признак ошибки:** Страница мигает и перезагружается при нажатии кнопок.

## 🗺️ **СТРУКТУРА ПЛАГИНА (6 файлов)**

### **АРХИТЕКТУРА:**
```
ДАННЫЕ (БД) → Calculation_Engine → AJAX_Handler → JavaScript
      ↓
  Data_Adapter → JavaScript (только для инициализации)
```

### **РОЛИ ФАЙЛОВ:**

#### **1. npk-calculators.php** 
- Главный файл плагина
- Только регистрация, никакой логики
- `add_action('plugins_loaded', 'init_plugin', 5);`

#### **2. concentration-module.php**
- Инициализация модуля концентрации
- Подключает ВСЕ классы модуля
- Регистрирует шорткод

#### **3. class-calculation-engine.php** ⚠️ **ЯДРО ЛОГИКИ**
- ТОЛЬКО формулы и алгоритмы
- Определяет State (единственный источник!)
- Содержит ВСЕ формулы из ТЗ п.4.1
- **Не знает HTML, не знает UI**

#### **4. class-ajax-handler.php** ⚠️ **ТРАНСПОРТ**
- ТОЛЬКО обработка AJAX запросов
- Валидация входящих данных
- Вызов Calculation_Engine
- Возврат JSON

#### **5. class-data-adapter.php** ⚠️ **ПОДГОТОВКА ДАННЫХ**
- ТОЛЬКО подготовка данных для UI
- Адаптация данных из БД для JavaScript
- **Не содержит логику, не считает**

#### **6. class-shortcode.php** ⚠️ **HTML ОБЁРТКА**
- ТОЛЬКО вывод HTML
- Подключение скриптов и стилей
- Передача данных в JavaScript
- **Не содержит логику, не знает формулы**

## 🚨 **ЧТО ДЕЛАТЬ ПРИ ОШИБКАХ:**

### **Если шорткод не работает:**
1. Проверь: `plugins_loaded` с приоритетом 5
2. Проверь: Классы загружены ДО регистрации шорткода
3. Проверь: `wp_add_inline_script` вместо `wp_localize_script`

### **Если AJAX перезагружает страницу:**
1. Ищи в коде: `FormData`, `URLSearchParams`
2. Замени на: `JSON.stringify()` и `'application/json'`

### **Если ошибка 500:**
1. Проверь порядок файлов: классы созданы до их использования?
2. Проверь require_once: все пути правильные?
