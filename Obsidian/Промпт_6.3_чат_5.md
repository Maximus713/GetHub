⚠️ ЕСЛИ ТЫ ПИШЕШЬ SELECTION_ENGINE:

• Используй NPK_Database::normalize_npk() — НЕ ПИШИ СВОЮ НОРМАЛИЗАЦИЮ  
• Порог 75% бери из NPK_Database::get_constants()['thresholds']['min_match_percentage']

⚠️ ЕСЛИ ТЫ ПИШЕШЬ AJAX_HANDLER:  
• МОДУЛЬ 2 → ТОЛЬКО FormData(), НИКОГДА JSON  
• Получай данные: $_POST['crop_id'], $_POST['phase_id']  
• Вызывай ТОЛЬКО Selection_Engine::find_matching_fertilizers()  
• НИКАКОЙ логики расчёта!

⚠️ ЕСЛИ ТЫ ПИШЕШЬ SELECTOR.JS:  
• AJAX: const formData = new FormData(); formData.append('action', 'npk_fertilizer_selector_calculate');  
• UI обновления: ВСЕГДА внутри requestAnimationFrame()  
• Instant Preview: предзагруженные данные из window.NPK_Selector_Data  
• НЕТ статических стилей! Только динамические width: ${percentage}%  
• НЕТ URLSearchParams! НЕТ Content-Type в fetch!

⚠️ ЕСЛИ ТЫ ПИШЕШЬ SELECTOR.CSS:  
• ВСЕ статические стили ТОЛЬКО здесь  
• ВСЕ селекторы с префиксом .npk-  
• Цвета прогресс-баров:  
- .npk-progress-green { background: #28a745; }  
- .npk-progress-orange { background: #FFD700; }  
- .npk-progress-gray { background: #6c757d; }
